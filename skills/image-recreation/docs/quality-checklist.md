# 图片参考改编质检清单

## 快速总检

- 第一眼能不能看出主体是什么。
- 画面是不是明显继承了参考图的方法，但没有落成“竞品同款”。
- 材质、结构、品牌信息和使用场景有没有明显错误。
- 这张图是否真的适合用户要投放的平台或使用位置。

## 细项检查

- 主体识别：主体外形、比例、材质和关键结构是否稳定。
- 商业重点：卖点是否被看见，主体是否仍是视觉中心。
- 风格一致：构图、光线、色调和背景复杂度是否属于同一套体系。
- 原创改写：logo、包装、人物身份、独特道具和品牌符号是否已经替换。
- 风险表达：是否暗示了未提供的功效、认证、奖项、排名或结果。

## 批量任务额外检查

- 每张图有没有清晰分工，而不是重复同一张图。
- 整组图放在一起看，是否像同一套 campaign。
- 允许变化的只有场景、角度、卖点重点等受控维度，不是整套风格跑偏。

---

## 3. 快速总检（Quick Pass）

请先进行一轮快速判断：

- [ ] 第一眼是否能看出与参考图属于同一系列
- [ ] 主体是否仍然是画面核心
- [ ] 是否存在明显崩坏、畸形、脏乱或错误信息
- [ ] 是否达到可继续精修或可直接进入下一环节的质量水平

如果上述任一项明显不通过，建议先退回修改，不进入细项检查。

---

## 4. 主体识别（Subject Recognition）

### 核心检查项
- [ ] 主体是否与参考中的主体一致
- [ ] 产品/人物/物体是否一眼可识别
- [ ] 关键识别特征是否被保留
- [ ] 是否出现主体漂移、错替换、变形或混合

### 针对产品类
- [ ] 产品外形是否正确
- [ ] 包装结构是否合理
- [ ] 瓶盖、标签、边角、接口等关键结构是否准确
- [ ] 是否出现多余结构或缺失结构

### 针对人物类
- [ ] 人物身份感是否稳定
- [ ] 发型、脸型、五官、肤质是否大致一致
- [ ] 是否出现明显换脸感或身份漂移

### 不通过示例
- 产品外形被改得无法识别
- 包装位置错乱
- 人物脸部失真、与参考不属于同一人设
- 主体被背景元素抢走焦点

---

## 5. 结构与比例（Structure & Proportion）

### 检查项
- [ ] 主体整体比例是否正常
- [ ] 局部结构是否符合物理常识
- [ ] 边缘、连接处、转折处是否自然
- [ ] 是否存在拉伸、压扁、断裂、扭曲

### 产品类重点
- [ ] 瓶身、盖子、边框、按压头等比例是否真实
- [ ] 不同部件是否仍属于同一产品逻辑
- [ ] 透视关系是否成立

### 人物类重点
- [ ] 手部结构是否自然
- [ ] 手指数量是否正确
- [ ] 面部比例是否正常
- [ ] 肢体姿态是否可信

### 不通过示例
- 瓶身变宽或变瘦过度
- 杯子把手连接错误
- 手指出现断裂、多指、粘连
- 五官比例异常

---

## 6. 材质与质感（Material & Texture）

### 检查项
- [ ] 材质是否符合主体本身属性
- [ ] 光泽、粗糙度、反射是否合理
- [ ] 纹理是否自然清晰
- [ ] 是否有塑料感、糊面、假金属、假玻璃等问题

### 常见材质专项检查

#### 金属
- [ ] 高光边界是否清晰
- [ ] 反射是否有逻辑
- [ ] 是否像金属而不是灰塑料

#### 玻璃
- [ ] 透明感是否自然
- [ ] 反射与折射是否可信
- [ ] 边缘是否干净不过脏

#### 织物
- [ ] 纹理是否连续自然
- [ ] 褶皱是否合乎结构
- [ ] 是否像真实面料而非涂抹表面

#### 液体/膏体
- [ ] 流动边缘是否自然
- [ ] 稠度是否合理
- [ ] 是否出现奇怪断层或悬浮感

### 不通过示例
- 玻璃像塑料
- 金属没有反射逻辑
- 面料纹理糊成一片
- 液体边缘不连贯、像固体块

---

## 7. 构图与画面层级（Composition & Hierarchy）

### 检查项
- [ ] 主体是否位于合理视觉焦点
- [ ] 构图是否与参考风格一致
- [ ] 前景 / 主体 / 背景层级是否清楚
- [ ] 是否保留了合适的留白区域
- [ ] 画面是否适合后续裁切或投放位适配

### 关注问题
- [ ] 主体是否被裁切
- [ ] 视觉重心是否失衡
- [ ] 次要元素是否喧宾夺主
- [ ] 画面是否太满或太空

### 不通过示例
- 主体被截断
- 主要卖点被遮挡
- 背景比产品更抢眼
- 画面没有层级，信息拥挤

---

## 8. 光线一致性（Lighting Consistency）

### 检查项
- [ ] 光线方向是否明确
- [ ] 光线方向与参考是否一致
- [ ] 阴影是否自然
- [ ] 高光是否过曝
- [ ] 暗部是否死黑
- [ ] 整体明暗关系是否统一

### 重点关注
- [ ] 是否存在多方向打光冲突
- [ ] 是否出现错误反光
- [ ] 是否有“主体亮、阴影逻辑却对不上”的情况

### 不通过示例
- 主光从左来，阴影却向左倒
- 高光爆掉导致产品边缘丢失
- 背景光和主体光完全不属于同一场景
- 阴影脏乱破坏高级感

---

## 9. 色彩控制（Color Control）

### 检查项
- [ ] 色彩是否与参考同属一个系列
- [ ] 主色调是否稳定
- [ ] 是否存在明显偏色
- [ ] 饱和度是否合理
- [ ] 冷暖关系是否统一

### 关注问题
- [ ] 是否出现脏灰
- [ ] 是否过度鲜艳
- [ ] 是否不同图之间色温跳变严重
- [ ] 品牌色是否被错误改写

### 不通过示例
- 系列图一张偏暖一张偏冷且无原因
- 产品本应米白却变成纯灰
- 背景色和主体颜色冲突严重
- 品牌主色错误

---

## 10. 背景与道具（Background & Props）

### 检查项
- [ ] 背景是否支持主体表达
- [ ] 道具是否与主体风格一致
- [ ] 道具数量是否适中
- [ ] 是否有多余元素造成干扰
- [ ] 场景是否增强卖点而不是分散注意力

### 不通过示例
- 道具太多抢走主体注意力
- 背景风格与主体完全冲突
- 场景元素无意义，只增加噪音
- 背景细节过多，导致商业可读性变差

---

## 11. 文案与品牌元素（Text / Branding）

如画面中带有文字、Logo、包装文案、品牌视觉元素，请额外检查：

### 检查项
- [ ] 文字是否清晰可读
- [ ] 是否存在乱码、错字、假字
- [ ] Logo 是否位置合理
- [ ] 品牌名称是否正确
- [ ] 包装排版是否符合真实结构

### 不通过示例
- 文案乱码
- 品牌拼写错误
- Logo 变形
- 标签排版不合理
- 包装结构与文字布局冲突

---

## 12. 人物专项检查（Human / Model Check）

如果画面中有人物或手部互动，请额外检查：

### 脸部
- [ ] 五官比例是否自然
- [ ] 双眼是否对称
- [ ] 皮肤质感是否真实
- [ ] 是否出现面部塌陷、重影、假面感

### 手部
- [ ] 手指数量是否正确
- [ ] 手指长度与弯曲关系是否自然
- [ ] 抓握动作是否合理
- [ ] 手与产品接触关系是否可信

### 姿态
- [ ] 肩颈与肢体关系是否自然
- [ ] 姿态是否支持主体表达
- [ ] 是否存在生硬、别扭、无法实现的动作

### 不通过示例
- 六根手指
- 手腕结构反常
- 眼神不对焦
- 脸部左右不一致
- 手拿产品方式不符合受力逻辑

---

## 13. 系列一致性（Series Consistency）

如果本次是多张图或一组延展图，请做跨图检查：

### 检查项
- [ ] 多张图是否看起来属于同一系列
- [ ] 主体识别是否统一
- [ ] 风格关键词是否稳定
- [ ] 光线逻辑是否一致
- [ ] 色彩系统是否一致
- [ ] 背景变化是否仍在允许范围内

### 不通过示例
- 一张像棚拍，一张像户外纪实，却没有系列过渡逻辑
- 主体长得像不同产品
- 一组图风格高度漂移
- 色彩系统完全不统一

---

## 14. 商业可用性（Commercial Usability）

### 检查项
- [ ] 这张图是否适合目标场景（电商 / 广告 / 社媒）
- [ ] 卖点是否清楚
- [ ] 信息层级是否明确
- [ ] 是否具备视觉吸引力
- [ ] 是否具备投放或上架的基本质量

### 场景专项判断

#### 电商主图
- [ ] 主体清晰
- [ ] 背景干净
- [ ] 商品辨识度高
- [ ] 适合缩略图显示

#### 详情页
- [ ] 支持卖点表达
- [ ] 可结合文案布局
- [ ] 细节足够清晰

#### 广告图
- [ ] 视觉冲击力足够
- [ ] 画面能承接文案/CTA
- [ ] 不会因过杂而影响转化

#### 社媒图
- [ ] 具有停留感
- [ ] 风格统一
- [ ] 分享感 / 品牌感足够

---

## 15. 返工判定建议（Revision Triggers）

出现以下情况时，建议直接返工而不是轻修：

- 主体身份已经漂移
- 产品结构明显错误
- 材质整体失真
- 光线方向混乱
- 画面风格不属于同一系列
- 品牌信息错误
- 人物/手部畸形明显
- 商业可用性不足

## 17. 最终放行前确认

在最终交付前，请确认：

- [ ] 已完成主体、结构、材质、构图、光线、色彩检查
- [ ] 已检查品牌元素或文字内容准确性
- [ ] 已完成系列一致性复核（如适用）
- [ ] 已确认与目标使用场景匹配
- [ ] 已记录需要保留的版本号与修改说明
