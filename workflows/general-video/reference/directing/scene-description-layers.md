# Scene Description Layers — 画面描述分层

## Activate When

- 需要把抽象 Brief、脚本或参考分析转换为可拍摄、可生成的 Shot Plan / prompt。
- 当前 work item 同时包含空间、主体、镜头、材质或运动，单句形容词不足以执行。
- 需要审查描述是否缺少关键可见证据。

单个简单 clip 已经写清主体和动作时，不为补齐层数而读取。

## Decision Test

先判断哪些层真正改变当前镜头。不要把“高级、温暖、电影感、品牌温度”等抽象标签直接当作画面事实；将其翻译为可见的空间、光线、行为、节奏或声音证据。层数可按项目删减，不要求每个 item 填满模板。

## Description Layers

1. **World / space**：地点类型、空间结构、时间、天气、背景密度和主体可活动路径。
2. **Subject / state**：人物 / 产品 / 物体数量、身份、姿态、服装、当前状态和关系。
3. **Composition / camera**：景别、视点、主体位置、前中后景、视觉重心、镜头起点与落点。
4. **Light / material / color**：可见光源方向、软硬、对比、色彩职责、材质反射或触感。
5. **Motion / time**：动作启动、过程、结果，镜头速度变化、内部切换和可承接的结束状态。
6. **Sound / text**：对白、旁白、环境声、动作声，以及用户明确要求的字幕 / 画面文字。

## Apply

- 每个层写可被镜头或麦克风验证的事实；无法验证的内容标为推断或创作选择。
- 动作写成因果链（谁在什么位置做什么，变化如何发生），而不是“慢慢地”“有氛围地”。
- 角色、产品和场景由 refs 锚定时，prompt 只补本镜头的状态、动作和关系，不重复静态档案。
- 把色调、风格和参考贡献拆成 preserve / adapt / ignore；不要用一张参考控制所有层。

## Review

- 观众能定位空间、主体和动作结果。
- 摄影机能拍到描述的关键事实，光线和材质没有与主体状态冲突。
- 声音 / 文字与画面有明确关系；没有用户要求的字幕或文字不会被偷偷加入。
- 起止状态能连接相邻 clip group，抽象词都能回溯到可见证据或已批准创作决定。

## Boundaries

本卡是描述检查框架，不是固定五层表格、镜头数量公式、风格 preset、模型锁或负向 prompt 模板；Shot Plan 的实际字段服从当前 workflow 和 validator。
