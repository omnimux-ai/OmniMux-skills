# Batch Consistency Guide

Use this reference for listing image sets, campaign batches, social series, or any request asking for multiple safe-adapted reference images.

## Build A Style System First

Define shared rules before individual prompts:

- Product identity: exact product facts that remain unchanged.
- Composition family: shared framing logic or grid rhythm.
- Lighting system: soft studio, natural daylight, dramatic spotlight, clean e-commerce light.
- Color system: palette role, background family, accent limits.
- Background rules: allowed surfaces, depth, clutter level.
- Prop rules: prop categories, scale, color compatibility, exclusion list.
- Text-space rules: where copy can sit and how much visual silence is needed.

## Assign Image Roles

Each image should have a job:

- Hero image: product clarity and category recognition.
- Feature proof: one key benefit made visible.
- Lifestyle scenario: product in credible use context.
- Detail/macro: material, texture, component, package, ingredient.
- Comparison/result: before/after, scale, set inclusion, use outcome.
- Social hook: scroll-stopping framing while staying product-led.

## Controlled Difference

Avoid making every image a new creative direction. Vary one or two axes per image:

- angle
- scene
- benefit
- crop
- prop set
- text-space position

## Consistency Check

Before final delivery, verify:

- Product shape, color, material and label remain stable.
- Lighting and background feel from the same campaign.
- Each image has a distinct role.
- No image borrows competitor-specific branding.
- The series works as a set when viewed in order.
