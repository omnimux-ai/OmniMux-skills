# Photoreal Human Texture — 真人写实质感

## Activate When

- 当前 Stage 要生成或重生真人写实 character / presenter anchor。
- 当前视频 work item 含清晰可见的真人脸部、皮肤或表演，需要在 prompt 中编译真实质感。
- 已有结果出现塑料、蜡像、磨皮、油腻、僵硬表演或渲染感，需要定位修复。

插画、动漫、卡通、风格化 3D 和主动追求超现实皮肤的项目不使用本文件。用户提供的媒介与光线参考优先。

## Decision Test

先定位问题属于哪一层：

| 症状 | 优先修正 |
|---|---|
| 皮肤过平、像蜡 | 微纹理、局部透光、自然色差 |
| 全脸油亮 | 光源大小与方向、局部高光范围 |
| 表情僵硬 | 眼睑、眉、唇、下颌与身体反应过程 |
| 人像像贴片 | 环境反光、接触阴影、头发与衣料物理反馈 |
| 过度电影滤镜 | 降低风格词，回到项目参考的成像方式 |
| 跨段脸或光线漂移 | refs 与 start/end continuity state，而非继续堆质感词 |

## Positive Texture Cues

按景别和问题选择少量可见线索：

- 特写：可见但不过度锐化的毛孔、细小绒毛、局部肤色变化、眼周和唇部真实纹理。
- 近景：鼻梁或额头的轻微局部高光、耳缘透光、自然面部不对称。
- 中景：皮肤与环境色温相互影响，面部仍保留层次而非统一磨平。
- 生活场景：轻微衣料褶皱、散发、汗湿或妆容使用痕迹，只选与人物状态一致的细节。

不要把全部线索塞入每个 prompt；一到三个针对性 cue 通常比固定锚点墙更有效。

## Skin Rendering Calibration

- **底色不是一块色板**：保留面颊、鼻翼、耳缘、眼周和下颌之间轻微但自然的肤色与血色差异，不做全脸统一粉橙覆膜。
- **透光只在薄处发生**：耳缘、鼻翼或手指边缘可出现局部暖透光；不要把 subsurface scattering 写成整张脸发光。
- **纹理服从景别**：特写可见毛孔、唇纹、眼周细纹和细小绒毛；近景只保留局部微纹理；中远景不堆 pore-level 细节。
- **高光服从皮脂与光位**：额头、鼻梁或唇部允许小范围柔和高光，脸颊和下颌保留不同粗糙度；禁止全脸同强度镜面油亮。
- **不完美必须有依据**：只选一到两个与年龄、妆容、天气或动作状态一致的细节，如轻微肤色不均、散发、衣料褶皱或局部汗湿；不主动添加密集雀斑、伤疤、色斑和衰老痕迹。

## Prompt Assembly

按当前镜头编译必要层。真人写实 H3 中人物清晰可见时，先写自然肤质、正常肤色、锐利可读细节、浅景深、大光圈与电影摄影质感；再选择一到三个由镜头实际可见的皮肤、光线、表演或物理线索：

1. **媒介**：明确是真人摄影、纪录式拍摄或其它已批准成像方式，不能同时混入 3D render / illustration 信号。
2. **皮肤**：从景别匹配的纹理、局部透光、肤色变化和高光范围中选择一到三个可见线索。
3. **光与空间**：说明主光来源、软硬、方向、暗部保留以及环境反射如何落在人脸上。
4. **表演与物理**：写眼睑、眉、嘴角、呼吸、重心、手部、头发和衣料真正发生的过程。
5. **连续性**：跨组记录身份 ref、妆容、姿态、目光、肤色基线、光位和高光位置。

## Lighting

- 大而近的柔光源能保留皮肤层次并控制高光；侧前方或侧后方光可表现面部结构与耳缘透光。
- 硬光可以用于纪实、舞台或正午场景，但要明确高光落点和阴影边缘，避免全脸同等发亮。
- 环境反射应与场景材质和色温一致，使人物真正处于空间中。
- 用户参考图的光线结构优先，不强制统一焦段、光圈或摄影机品牌。

## Anchor and Capture Discipline

- 真人六宫格 / 多视图 anchor 使用中性灰摄影棚、较大的柔和主光、弱补光、稳定白平衡与一致曝光；所有格子的肤色、高光范围和明暗关系保持一致，不加入剧情逆光、霓虹染色、烟雾或重度调色。
- 身份近景避免夸张广角透视和过浅景深遮掉五官边界；视频镜头的焦距、景深和运动方式则服从当前叙事与用户参考，不锁固定毫米数、光圈或摄影机品牌。
- 保留高光渐变、暗部细节和自然局部反差；避免过度锐化、过强降噪、全局柔焦或统一磨皮。
- 动态画面保留符合速度的自然运动模糊，但眼神、嘴部和关键表演落点仍需可读。

## Performance

用可见动作描述情绪变化：眉眼先动还是嘴角先动、视线何时重新聚焦、呼吸和吞咽如何变化、肩颈与手部怎样跟随。FACS/AU 可作为分析辅助，但执行 prompt 使用自然、可拍的表演语言即可。

高强度情绪从身体链开始：重心、呼吸、肩颈、手指和面部共同变化。克制情绪允许只有一个微小反应。

## Motion and Continuity

- 头发、衣料、饰品和皮肤高光应对动作有合理延迟与惯性。
- 同主体、同空间、连续表演优先放在一个 continuity-first clip group，减少无意义重置。
- 拆组时复用身份 refs，并记录姿态、目光、光线、高光位置和妆容状态。
- 不用固定时长或固定模型决定分组；以 vendor 能力、对白完整性和动作闭合为准。

## Review and Repair

先对照用户 refs 检查身份，再检查皮肤、光线、表演和物理反馈。只针对失败层修改：蜡感补纹理/透光，油亮改光位和高光范围，僵硬补动作过程，贴片感补环境交互。避免同时重写所有视觉维度。
