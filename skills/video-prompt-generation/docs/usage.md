# 使用说明

## 什么时候用

以下情况适合用这套能力包：

- 已经有脚本，想整理成模型提示词
- 已经有分镜或镜头清单，想压缩成可执行 prompt
- 已经有粗糙 prompt，想补齐结构、约束和连续性
- 想输出 `generic`、`Sora`、`Veo`、`Seedance` 多版本

## 什么时候不要用

- 用户还没有创意和脚本
- 用户只想分析现有视频
- 用户想直接出成片
- 用户想要完整分镜表或制作排期

## 推荐工作方式

1. 判断输入属于脚本、分镜、镜头清单、粗糙 prompt 还是混合输入。
2. 先提取主体、场景、动作顺序、镜头重点和限制条件。
3. 如果目标模型清楚，就做定向适配；不清楚就先给通用版。
4. 输出主 prompt、拆解说明和避免项。
5. 使用了假设时，把假设单独写出。

## 最小澄清规则

只在以下缺口会明显改变结果时追问：

- 用户到底要哪种模型版本
- 镜头密度和时长差距太大
- 画幅会改变镜头组织
- 必保留项和避免项互相冲突

其余情况优先声明假设并继续。
