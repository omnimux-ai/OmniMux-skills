# 3C数码广告案例库 — Casebook

> **加载时机**：Anchors 按 3C 品类卡条件选择路线母题时读取；Storyboard、Visual Gen 和 Post 不读取本文件。
> **作用方式**：案例母题库，不是强制流程。Anchors 把命中的 Case 转译为 `video_creative_route`，再通过独立视觉技法目录确定最终 `technique_plan`。
> **来源原则**：案例只保留可复用方法，不绑定会话本地视频路径；用户参考片直接消费 Research Capsule 已保存的 Visual Style DNA。

---

## 使用方法

1. 根据产品类型、卖点和品牌调性选择最接近的 Case，写入 `video_creative_route` 的视觉母题、段落模块和 Case ID。
2. 把 Case 推荐技法仅作为候选交给 `visual-techniques-library.md`；最终选中的卡片事实写入 `technique_plan`。
3. Storyboard 只消费 Anchors `constraints` 中的 Case 绑定与 `technique_plan`；Visual Gen 和 Post 不读取案例或扩展技法范围。

## Case 01 — 透明工业设计 / Lo-Fi High-Tech

| 字段 | 内容 |
|---|---|
| 适用产品 | 透明耳机、潮流手机、极客向硬件、带 LED / Glyph / 点阵语言的设备 |
| 核心视觉 | 黑白灰主基调 + 单点品牌色；透明/半透明壳体；内部元件可见；点阵字；取景器 HUD；微距材质蒙太奇 |
| 创意价值 | 把「工程样机」「硬件说明书」「极客潮流」转化为品牌美学 |
| 推荐技法 | T05 HUD 技术叠层、T06 文案图形化、T08 黑白单点色、T10 微距质感蒙太奇、T11 Logo 自发光、T14 工业说明书式参数版面 |
| 分镜段落 | 1. 黑场/极简空间产品剪影；2. 透明外壳和内部结构微距；3. 参数/部件说明书式版面；4. 点阵 Logo / 网址终帧 |
| 执行注意 | 单点色必须绑定产品核心识别件；HUD / 点阵字是构图元素，不可遮挡产品关键结构 |

### Anchors 路线落地提示

- 路线记录：`Case 01 / Lo-Fi High-Tech`；技法候选交给独立目录筛选。
- 分镜中至少包含 3 个微距部件：接口、按键、转轴、网罩、透明外壳、内部元件。
- 如果出现文字，优先作为版面构图元素，而不是字幕条。

## Case 02 — 声学配件 / 形态同构与液体声波

| 字段 | 内容 |
|---|---|
| 适用产品 | TWS 耳机、头戴耳机、音响、降噪设备、轻量化穿戴设备 |
| 核心视觉 | 抽象几何 morph 到产品；液体涟漪 / 悬浮；圆形波纹；物理弹跳卡点；人体线描拟合；多色 SKU 展示 |
| 创意价值 | 用产品形态和物理隐喻表达声学、降噪、佩戴舒适与年轻潮流感 |
| 推荐技法 | T10 微距质感蒙太奇、T15 抽象几何到产品形态蜕变、T16 液体声波 / 悬浮声学隐喻、T18 物理动力学卡点 |
| 分镜段落 | 1. 圆/球/波纹等抽象母题；2. 几何体 morph 成产品；3. 产品与液体/波纹互动；4. 线描人体工学拟合；5. 多色产品英雄定帧 |
| 执行注意 | 液体隐喻要服务「声波/降噪/轻盈」，不要变成无意义水面美术；卡点动作必须和 BGM 强拍对齐 |

### Anchors 路线落地提示

- 路线记录：`Case 02 / Acoustic Morph`；技法候选交给独立目录筛选。
- 产品核心几何形态必须在片头先抽象出现，再回收为真实产品。
- 人体工学线描适合耳廓、手腕、头部侧影等极简轮廓，不建议复杂真人表演。

## Case 03 — 高性能设备 / 表里透视科技链

| 字段 | 内容 |
|---|---|
| 适用产品 | AI PC、游戏本、高性能笔记本、专业平板、芯片/显卡/高算力设备 |
| 核心视觉 | 外观材质 → 内部结构/芯片 → 屏幕应用 → 交互细节 → 产品英雄终帧；光流表现算力；冷暖双色场景分割 |
| 创意价值 | 用「由表及里」的认知链建立技术可信度，用场景色温区分性能与日常价值 |
| 推荐技法 | T03 冷暖色温弧线、T05 HUD 技术叠层、T07 圣像光产品英雄镜头、T10 微距质感蒙太奇、T17 表里透视科技链 |
| 分镜段落 | 1. 场景人物/产品剪影；2. 外观和接口微距；3. 主板/芯片/散热/光流；4. 屏幕应用或游戏画面；5. 指纹/摄像头滑盖/电源键等交互细节；6. 卖点文案终帧 |
| 执行注意 | 性能参数优先用视觉隐喻表达；真实参数若出现必须来自官方资料，并保留合规标注 |

### Anchors 路线落地提示

- 路线记录：`Case 03 / Inside-Out Tech Chain`；技法候选交给独立目录筛选。
- 冷色段承载性能、游戏、算力；暖色段承载办公、创作、质感和日常。
- 交互细节镜头至少 2 个：接口、指纹、电源键、隐私滑盖、键盘、摄像头模组等。
