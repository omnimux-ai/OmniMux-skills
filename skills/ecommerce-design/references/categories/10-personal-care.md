# 10. 洗护用品 (Personal Care / Bath)

> **优先质量维度**: Visual Appeal + Brand Consistency
> **权重覆盖**: 走六维默认权重（含功效宣称的洗护需提防 Trust 失分）
> **组图建议张数**: 6–8
> **核心转化驱动**: 质地感知 + 效果证明

## 二、整体风格与质感

| 维度 | 要求 |
|------|------|
| **风格** | 清爽洁净感；浴室/洗手台场景要干净整洁。蓝色/绿色/白色系为主流 |
| **色调** | 明亮清新；色温 5000-5500K；与产品包装色系协调 |
| **背景** | 白色/浅色系；场景图用浴室/厨房等相关场景 |
| **光线** | 柔光为主；泡沫/液体需要通透光感 |
| **道具** | 水滴、气泡、花瓣、毛巾 —— 与"清洁""滋养"关联 |

## 六、易错点（Watch For）

- 透明瓶中液体颜色与气泡的真实感
- 系列感 —— 同一光线、同一角度、同一阴影衰减
- **【合规红线】功效百分比 / 抗菌率 / "X 天见效" / 成分含量 AI 不编造** —— 洗护品类常踩"99% 抑菌"、"24h 保湿"、"4 周改善 X%"等带数字的功效宣称坑。这类宣称必须有真实第三方检测依据，AI 仅可做版式呈现，不可凭"听起来像样"自己编。**没真数据 → 改为感性描述（"清新滋润")或不画功效图**。
- **效果对比图（前 vs 后）的合规风险** —— 前后对比图本身在化妆品 / 个护监管下属高风险表现形式（涉嫌虚假宣传），需配合真实使用周期 + "效果因人而异"声明，AI 不可单凭参考图凭空合成"使用后"图像。
