# AI 换装审阅排错

## 排错顺序

遇到问题时，优先按这个顺序排查：

1. 输入是否清楚
2. 保留项是否写清
3. 服装细节是否可见
4. 提示里是否存在互相冲突的目标
5. 质检标准是否和用途一致

## 常见问题

### 人物不像原人

常见原因：

- 人物图分辨率低或遮挡重。
- 提示没有明确要求保留身份。
- 风格词过强，压过了身份保持。

处理方式：

- 补更清晰的人物图。
- 明确写保留面部、发型、肤色和年龄感。
- 减少容易导致换脸的强风格词。

### 服装不像参考图

常见原因：

- 参考图只拍到局部。
- 关键结构没有单独描述。
- 提示把氛围感放在了服装保真前面。

处理方式：

- 列清楚颜色、材质、廓形和关键细节。
- 把看不见的部分标成“合理补全”。
- 对品牌敏感元素加人工复核提醒。

### 商业表达有误导风险

常见原因：

- 画面里新增了不存在的版型、面料或配件。
- 过度显瘦、增高或改色却没注明。
- 让效果图承担了真实销售证明的角色。

处理方式：

- 回到真实可见信息。
- 把变化项和保留项分开写。
- 输出里单独标记需要人工确认的真实性风险。

### 批量变体不统一

常见原因：

- 每个版本都在同时改太多变量。
- 没有固定共同的服装特征和画面基线。

处理方式：

- 先固定服装关键特征。
- 每轮只改变一个主要变量，例如模特、场景或角度。
