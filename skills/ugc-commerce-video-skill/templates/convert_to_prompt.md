# Convert to Prompt Template

## Use Case
Use this template when the user wants to:
- convert a script into an AI video prompt
- turn a storyboard into a generation-ready prompt
- adapt a selling concept for Veo, Sora, Seedance, or a generic video model
- transform a rough short-video idea into model-usable instructions
- create prompt variants for testing different visual directions

This template is built for short-form ecommerce video generation, not generic cinematic prompting.

## Template Rules
1. Do not turn selling logic into vague cinematic language.
2. Always preserve product clarity.
3. Always convert abstract benefits into visible actions or outcomes.
4. Always define proof visually when the claim requires it.
5. Keep product identity stable across scenes.
6. Match the prompt style to the intended format, especially for UGC realism.
7. Use camera language only when it improves clarity or generation reliability.
8. Avoid overloaded prompts with too many conflicting instructions.
9. Keep the sequence understandable for short-form viewing.
10. If the user has a target model, adapt the prompt format to that model's likely strengths.
