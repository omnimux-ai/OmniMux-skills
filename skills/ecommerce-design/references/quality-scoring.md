# 电商六维质量评分模型 + 14 品类权重覆盖

> **何时 read**：每张电商图生成后 evaluation 阶段。**评分是 mandatory，不可跳过**——见 `iron-laws.md` Meta-3。
> 本文件是**电商场景专属**的 6 维加权评分体系。其它非电商场景请走通用质量基线。

## At-a-Glance（六维默认权重）

| # | Dimension | Core question | Default weight |
|---|-----------|---------------|----------------|
| 1 | **Product Clarity** 产品清晰度 | shopper 能否一眼识别"这是什么产品"? | 0.25 |
| 2 | **Visual Appeal** 视觉吸引力 | 在搜索结果九宫格里能否抓住眼球? | 0.20 |
| 3 | **Information Delivery** 信息传达力 | 图本身能否传达核心卖点（不靠文字 overlay）? | 0.20 |
| 4 | **Trust / Realism** 真实可信度 | shopper 会相信收到的产品和图里一样吗? | 0.15 |
| 5 | **Brand Consistency** 品牌一致性 | 看起来像同一店 / 同一品牌的吗? | 0.10 |
| 6 | **Technical Compliance** 技术合规性 | 通过平台硬规范吗？不被下架? | 0.10 |

> 品类权重覆盖（如美妆把 Trust 抬到 0.30、珠宝把 Clarity 抬到 0.30）见末尾「14 品类权重覆盖表」。

## 1. Product Clarity（产品清晰度）

**原则**：shopper 有 3 秒决定"这是什么"。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 产品占比 | 60–85% of frame | 太小，或被裁掉 |
| 锐度 | 边缘清晰，支持放大 | 模糊 / 低分辨率 / 失焦 |
| 完整性 | 产品完整可见 | 被裁切或遮挡 |
| 背景克制度 | 不与产品争抢 | 杂乱 / 撞色 |
| 可识别性 | 一眼看出品类 | 看不出是啥 |

**1–10 评分**：
- 9–10：Hero 级清晰，完美占比、对焦，瞬间识别
- 7–8：清晰且构图好，背景克制略有瑕疵
- 5–6：能识别但视觉弱（小 / 软 / 占比差）
- 3–4：识别需要努力
- 1–2：完全看不出是啥

---

## 2. Visual Appeal（视觉吸引力）

**原则**：在 2×3 搜索结果网格里，这张图必须赢得眼球。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 配色和谐 | 协调、有意图 | 撞色 / 浑浊 |
| 光质 | 均匀或有目的的塑光 | 平 / 死白 / 欠曝 |
| 构图 | 三分法 / 黄金分割 / 有意中心构图 | 随便摆 / 地平线斜 |
| 差异化 | 在品类平均水平之上 | 看起来和每个竞品一样 |
| Mood | 唤起情绪 / 联想 | 冷漠 / 通用 / 无生命感 |

**1–10 评分**：
- 9–10：奖项级——构图、光、色全在线
- 7–8：吸引力强，一项小弱点
- 5–6：及格，无明显缺陷但记不住
- 3–4：业余 / 刺眼 / 无聊
- 1–2：主动反向劝退

---

## 3. Information Delivery（信息传达力）

**原则**：好图会"说话"——卖点通过视觉传达，不靠 overlay 文字。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 卖点视觉化 | 核心 USP 是被"展示"的，不是被"陈述"的 | 只是漂亮产品图，没有信息 |
| 使用场景 | shopper 能想象自己用 | 产品孤立悬浮 |
| 功能可解读 | 关键功能从图里看得出来 | 复杂产品没有 demo |
| 尺寸感 | 有比例锚让大小一目了然 | 大小模糊 |
| 图上文案 | 简洁 / 数字 / 具体 | 长 / 空 / 该有时没有 |

**1–10 评分**：
- 9–10：一图一信息，完美视觉化
- 7–8：信息清楚，略有冗余
- 5–6：信息存在但次于颜值
- 3–4：通用——可以是该品类任何产品
- 1–2：完全看不出卖点

---

## 4. Trust / Realism（真实可信度）

**原则**：shopper 必须相信看到的就是收到的。这一维度同时驱动转化率和退货率。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 颜色保真 | 与真实产品一致 | 看得出色偏 |
| 材质真实 | 材质看起来就是该材质 | 布料像塑料、金属像漆 |
| 光线一致性 | 跨元素阴影方向统一 | 阴影互相矛盾 / 产品悬浮 |
| 比例 | 产品 / 模特 / 场景比例正确 | 沙发比房间大、手表比手腕大 |
| 边缘完整 | 干净合成，无 halo / 重复 | 看得出抠图边缘、纹理重复 |

**1–10 评分**：
- 9–10：和顶级棚拍无差
- 7–8：一处小破绽（边缘 / 色调微飘）
- 5–6：可信但明显是修图 / 合成的
- 3–4：多处可见瑕疵动摇信任
- 1–2：看着假 / 明显错，会触发退货

---

## 5. Brand Consistency（品牌一致性）

**原则**：一店 / 一线产品的所有图看起来像一家人。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 色调对齐 | 一致的白平衡 / 调色 | 每张图情绪不同 |
| 构图风格 | 跨产品类型同一构图逻辑 | 角度乱七八糟 |
| 调性匹配定位 | 高端产品 → 高级感 | 高端产品被拍成地摊货 |
| 系列内聚 | 同系列产品看起来相关 | 同系列像三个品牌 |

**1–10 评分**：
- 9–10：可以做品牌手册参考
- 7–8：基本一致，小幅漂移
- 5–6：看得出家族脸，体系弱
- 3–4：不一致到让 shopper 困惑
- 1–2：完全没有视觉体系

---

## 6. Technical Compliance（技术合规性）

**原则**：平台硬规范。这一项失败 = 下架或降权——总分救不了你。

| Sub-criterion | Pass | Fail |
|---|---|---|
| 分辨率 | 达到或超过平台最低要求 | 低于最低，会被拒收 |
| 文件格式 / 大小 | 在平台限制内 | 格式错或超大 |
| 背景规则 | 符合平台要求（如 JD/Amazon hero 纯白）| 违反白底 / 背景规则 |
| 禁用元素 | 无水印 / 无关文字 / 无边框 | 含任何禁用元素 |
| 产品占比 | 达到平台最低（如 Amazon ≥ 85%）| 太小 |

> 本维度**精神上是二元的**——任一子项 fail，分数应直接降到 ≤ 4，不论艺术上多好看。**详细平台规范见 `platform-specs.md`**。

total = Σ (dimension_score × dimension_weight)

## Quality Bars（出图能否上线）

> **评分是 mandatory，不可跳过** —— 见 `iron-laws.md` Meta-3。

| Bar | Score | 含义 |
|---|---|---|
| Hero image | ≥ 8.5 | 批准用作主图 / 封面 |
| Listing supporting image | ≥ 8.0 | 批准进组 |
| Below 8.0 | regenerate | 在 brief 上迭代，不是只换 seed |
| 任一 severe AI defect | fail regardless | 见 `ai-pitfalls.md`（完整 S1-S10 + Mitigation）|

> 三轮 stop 条件 / "何时回到策划阶段" 等 evaluation 流程步骤走 `ec-quality-model`（保留的工作流 skill）STEP 6，本 reference 不重复流程，避免双源漂移。

## 14 品类权重覆盖表

不同品类对六维的权重不同。下面是覆盖项（未列出的维度走默认权重）。

| # | 品类 | 优先维度 | 权重覆盖 | 核心转化驱动 |
|---|------|----------|----------|--------------|
| 1 | 女装 | Visual + Trust | Trust 0.20, Visual 0.25 | 色彩还原 + 面料质感 + 穿着代入 |
| 2 | 家装家居 | Information + Visual | Information 0.25 | 空间比例 + 尺寸准确 |
| 3 | 日用品 | Clarity + Information | （走默认）| 功能可视化 + 使用便利 |
| 4 | 宠物 | Visual + Information | （走默认）| 萌宠情感 + 安全 |
| 5 | 母婴 | Trust + Brand Consistency | Trust 0.30, Visual 0.15, Information 0.20 | 安全第一 + 功能便利 |
| 6 | 数码 3C | Clarity + Information | Clarity 0.30, Information 0.25, Visual 0.15 | 科技感 + 参数说服 |
| 7 | 饰品珠宝 | Visual + Clarity | Clarity 0.30, Visual 0.25, Trust 0.10 | 美感 + 工艺信任 |
| 8 | 美妆护肤 | Visual + Trust（颜色）| Trust 0.30, Visual 0.25, Information 0.10 | **颜色精度是生命线** |
| 9 | 保健品 | Trust + Information | （走默认 + Trust 优先）| 成分透明 + 权威认证 |
| 10 | 洗护用品 | Visual + Brand Consistency | （走默认）| 质地感知 + 效果证明 |
| 11 | 男装 | Clarity + Brand Consistency | （走默认）| 版型 + 做工品质 |
| 12 | 鞋靴 | Clarity + Information | （走默认）| 颜值 + 舒适暗示 |
| 13 | 箱包 | Clarity + Information | （走默认）| 尺寸感知 + 收纳 |
| 14 | 运动户外 | Visual + Information | （走默认）| 动态活力 + 功能证据 |

> **没列出权重覆盖的品类走六维默认权重**（Clarity 0.25 / Visual 0.20 / Information 0.20 / Trust 0.15 / Brand 0.10 / Compliance 0.10）。
