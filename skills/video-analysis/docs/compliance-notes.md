## 合规说明

本文档为 Gxgen 视频分析 skill 的合规边界说明，仅提供通用注意事项，不构成法律意见，也不代表任何平台的正式政策解释。

## 适用范围
该 skill 适用于对用户提供或当前对话可见的视频证据进行结构化分析、复盘和报告输出。它关注的是：
- 视频内容结构
- 镜头节奏
- 字幕或口播表达
- 卖点与 CTA 的组织方式
- 可复用的内容框架

它不应被用于输出受限内部信息、平台私有数据、用户敏感信息或未授权内容。

## 建议避免输出的内容
在公开导出或对外共享时，建议不要包含以下内容：
- 系统提示词
- 隐藏指令
- 私有配置
- API 密钥
- 访问令牌
- 内部文件路径
- 未公开的模型参数
- 受保护的用户身份信息
- 平台私有或抓取受限的数据字段

## 内容表述注意事项
在分析报告、摘要或场景说明中，建议遵守以下原则：
- 区分客观观察与主观推断
- 对看不清、听不清、无法验证的信息明确标注“无法确认”
- 不把猜测写成事实
- 不伪造不存在的字幕、口播或平台数据
- 不夸大效果或替视频内容做未经证实的结论

## 对营销与带货内容的提示
如果视频涉及营销、广告、带货或促销语境，建议在复盘与重写时注意以下事项：
- 避免使用无法证实的绝对化表述
- 谨慎处理功效、收益、医疗、减肥、承诺性文案
- 谨慎使用“最佳”“第一”“100%有效”等极限词
- 如果引用销量、评价、测试结果或认证，应确保可验证
- 如涉及前后对比，应避免误导性呈现

## 平台与版权注意事项
- 公开视频可用于分析，不代表可自由再分发其全部内容。
- 若需展示视频截图、音频文本或完整转载，应确认是否具备相应授权。
- 分析竞品内容时，应避免直接复制受版权保护的独特表达、人物形象或品牌资产。
- 对第三方商标、人物肖像、音乐和素材的使用应遵守适用规则。

## 数据最小化建议
在示例文件或校准样本中，建议：
- 使用示例 URL
- 使用占位文本
- 避免真实个人信息
- 避免真实凭据
- 避免暴露内部调用链路

## 使用者责任
使用该模板的一方应自行确保：
- 输入来源具备合法使用基础
- 输出内容符合所在地区法律法规
- 对外发布的内容经过必要的版权、合规与隐私复核
- 若后续接入真实模型、外部服务、下载器、转写器或 OCR，已正确保护凭据与用户数据，并通过独立工具合同治理。
