# 坐标运镜可视化分镜规范

## 目标

坐标运镜不能只停留在文字 prompt。每次完整使用本 skill 时，应把运动逻辑可视化，并遵守以下硬规则：

1. 场景运动轨迹总图必须使用 `GPT Image 2` 最高质量档，输出 `3840x2160 / 4K`，因为坐标、速度曲线、节点、cut 标注属于高信息密度内容，1K 容易生成错误或糊掉。
2. 场景路径图可以带风格色彩：允许使用城市色块、冷暖速度线、分层色带和视觉化图例增强可读性，不要求黑白。
3. 分镜图同样必须使用 `GPT Image 2` 最高质量档，输出 `3840x2160 / 4K`；默认必须是黑白线稿草图 / pencil storyboard thumbnails / rough animation storyboard，禁止彩色、霓虹和复杂上色，避免污染后续视频生成。
4. 场景路径图和分镜图必须是两个独立资产，不要画在同一张图上。
5. 如果用户要求“9 个 cut 在一张图上 / 总分镜 / 9 格 = 9 个 cut”，必须生成**单张 3×3 总分镜图**，9 个 panel 分别对应 9 个 cut；不要拆成 9 张图。
6. 只有用户明确要求“每个 cut 单独拆动作子帧”时，才为每个 cut 生成一张独立 `3840x2160` 九宫格动作分镜图。
7. 每个 panel 必须参考场景路径图设计，绑定路线节点、坐标/高度、速度曲线、镜头机位、场景物件和景别，禁止生成与路线/场景物件无关的泛泛动作展示。
8. 进入视频生成时，路径图和分镜图只能作为隐藏规划参考；必须明确禁止可见箭头、路线线条、坐标框、速度曲线、cut 编号、九宫格边框、草图辅助线、分镜纸张和标注文字出现在最终画面。
   **关键执行规则**：不要把带规划标注的路径图 / 分镜图作为视频模型的视觉参考直传；它们只能先被转译成文字坐标参数。视频阶段只传干净角色参考、干净场景参考或无标注首帧。若需要场景风格一致性，必须先用 `GPT Image 2` 最高质量档，基于路径图生成一张无箭头、无坐标、无光带、无编号、无路线、无分镜格的 `3840x2160 / 4K` 干净场景参考图，再把这张干净图传给视频模型。
9. 视频生成 prompt 不能退化成普通动作描述；每个 cut 必须保留 `[L,T,W,H]` 坐标控制层，至少包含主体框、镜头关注框、目标框 / 事件框。
10. 必须区分人物坐标和相机坐标，并为每个 cut 标注 `camera_mode`：跟随、领先跟随、环绕、俯视跟随、低位上摇、拉远等。
11. 必须为每个 cut 标注速度函数类型和差值：linear / ease-in / ease-out / ease-in-out / burst-stop / stop-burst / peak-mid / impact-freeze。
12. 最终视频默认使用 `Seedance Pro` 最高质量档、最高可用分辨率，优先输出 `3840x2160 / 4K`；除非用户明确指定其它模型或平台能力不支持，禁止降到低清、快速预览或普通质量档。

默认图像模型：`GPT Image 2` 最高质量档。默认视频模型：`Seedance Pro` 最高质量档。

## 场景与运动轨迹总图

### 画布

- 尺寸：`3840x2160`
- 比例：`16:9`
- 类型：导演动作预演图 / blocking diagram / storyboard overview

### 必须画出

- 场景空间：地面、墙体、障碍物、远景目标、重要遮挡物。
- 角色初始位置：用框和标签标出。
- 角色运动路径：用箭头和编号标出。
- 镜头运动路径：用另一种颜色或虚线箭头标出。
- 撞击点 / 爆炸点 / 落点：用醒目标记标出。
- cut 编号：C1、C2、C3……
- 关键坐标框：只保留短标签，避免文字拥挤。

### 不要做

- 不要做成最终海报。
- 不要只画漂亮场景却没有轨迹。
- 不要把文字写满画面。
- 不要让箭头和坐标遮挡主体。

## 黑白线稿 3x3 总分镜图

### 画布

- 尺寸：`3840x2160`
- 比例：`16:9`
- 布局：`3x3`
- 每格：一个 cut，默认 9 格对应 C1-C9。
- 风格：黑白线稿草图 / pencil storyboard thumbnails / rough animation storyboard，禁止彩色和复杂上色。

### 九格功能

1. C1：路线起点，主体与起始场景关系。
2. C2：第一组街道障碍和运动方向。
3. C3：低姿滑行、钻入、穿越或第一处关键障碍。
4. C4：转角、急刹、变向或车辆/大型障碍互动。
5. C5：短暂 wall step / tic-tac 或关键借力点。
6. C6：天桥、栏杆、人群或中段高度变化。
7. C7：屋顶落地、膝盖缓冲、肩滚卸力。
8. C8：边缘加速、广告牌/屋顶边缘或最后起跳前蓄势。
9. C9：断桥/高架缺口/天际线收束，为视频结尾服务。

只有用户明确要求“每个 cut 单独拆动作子帧”时，才额外为单个 cut 生成独立 3x3 子帧九宫格。

## GPT Image 2 任务模板

### 轨迹总图

```text
model: gpt-image-2
quality: highest
aspect_ratio: 16:9
resolution: 3840x2160
任务：生成一张动作场景与运动轨迹总图。
风格：导演分镜预演图，清晰线稿或半写实概念草图。
内容：画出完整场景空间、角色初始位置、目标位置、撞击点、运动箭头、镜头运动箭头、cut 编号和坐标框标注。
注意：重点是位置、轨迹、顺序清楚，不要做成电影海报。
```

### 黑白线稿 3x3 总分镜

```text
model: gpt-image-2
quality: highest
aspect_ratio: 16:9
resolution: 3840x2160
任务：生成一张黑白线稿 3x3 总分镜图，9 个 panel 对应完整路线的 9 个 cut。
内容：每格展示一个 cut 的关键构图、场景物件、主体位置、运动方向、镜头机位和速度曲线；保持同一角色、同一路线空间和连续运动方向；每格只使用短编号 C1-C9 和极短动作标签；只用黑白线稿，不要彩色上色。
```

## 检查标准

- 轨迹总图是否能让人一眼看懂角色从哪里到哪里。
- 九宫格是否每一格都有动作进展，而不是重复构图。
- 坐标框是否和画面位置对应。
- 镜头箭头是否和主体运动关系一致。
- 每个 cut 是否都有可用于视频生成的关键首帧候选。
