# Visual Style Presets — 可选视觉方向样本

## Activate When

- 用户没有明确视觉方向，且希望看到少量可比较的风格路线。
- Brief 需要把“温暖、科技、真实、梦幻”等抽象词展开为可执行的色调、光线、质感、构图、运动和氛围。
- 用户明确要求风格候选或预设参考。

已有参考视频 / 图片或用户已批准风格时跳过；不要为了完整性加载本卡。

## Decision Test

默认提出一个有依据的推荐方向。只有用户要求对比、输入证据形成真正互斥的路线，或一次方向会不可逆改变身份 / 归属 / 叙事立场时，才展示多个选项。预设只是语言样本，不是模型锁、固定 prompt 或必选菜单。

## Six Dimensions

每个方向至少说明：

1. 色调：主色、饱和度、明度和保护色。
2. 光线：光源类型、方向、软硬和对比。
3. 质感：媒介、颗粒、清晰度、表面和细节密度。
4. 构图：主体位置、留白、空间层次和视觉重心。
5. 运动：镜头稳定度、速度、变速和转场倾向。
6. 氛围：前五项共同形成的可感知情绪，不只写形容词。

## Direction Samples

| 方向 | 可执行线索 | 适用倾向 |
|---|---|---|
| 电影感写实 | 自然光、层次暗部、轻颗粒、平滑跟随、真实但经过取舍 | 叙事、生活方式、质感展示 |
| 极简高级 | 低饱和、精确边光 / 全局光、大留白、静止或极慢运动 | 克制、编辑感、空间与产品展示 |
| 街头活力 | 高对比霓虹、混合光、紧凑构图、手持跟拍、快节奏切换 | 年轻、运动、UGC 感 |
| 梦幻柔光 | 粉彩、扩散光、柔焦、前景虚化、漂浮或溶解 | 温柔、浪漫、生活方式 |
| 科技未来 | 深色底、冷色发光元素、精确机械运动、反射与数据层 | 科技、概念、系统展示 |
| 复古胶片 | 褪色与颗粒、可用光、轻微不完美、纪实运动 | 怀旧、日常、音乐与生活 |
| 纪录片真实 | 自然色、现场光、手持微晃、偶发失焦、观察式构图 | 信任、人物、真实记录 |
| 超现实概念 | 非现实空间、媒介混合、比例或光源异常、明确的运动规则 | 概念、意象、实验性表达 |

## Capture and Finish Calibration

“画面质感”必须拆成可观察的成像结果，不能只写高清、电影感或高级：

| 成像方向 | 质感校准 |
|---|---|
| 电影感写实 | 高光平滑过渡、暗部有层次、局部反差克制、轻微颗粒、自然运动模糊；不是统一青橙、黑边或强锐化 |
| 干净数码 | 边缘清楚、低噪点、白平衡稳定、材质分离明确、亮部受控；干净不等于塑料、磨皮或无纹理 |
| 纪录 / Vlog | 现场光、轻微手持、允许短暂曝光或对焦呼吸、肤色和环境色自然；不能故意做成低清或失控抖动 |
| 复古胶片 | 与年代相符的颗粒、轻微 halation、柔和高光和褪色黑位；不做全屏棕黄滤镜、随机划痕或过强漏光 |
| 梦幻扩散 | 柔和局部反差、光源周围有限 bloom、前后景扩散和清楚的主体落点；不把整帧统一模糊发白 |
| 编辑 / 极简 | 精确轮廓、受控材质高光、留白和少量色彩层级；不靠纯白背景、无阴影和过曝制造“高级” |

同一项目选择一个主成像方向，再记录少量可变化项。镜头景别、动作速度和光线变化可以改变颗粒可见度、锐度、运动模糊与局部反差，但不能无理由更换媒介。

## Apply

- 从样本中挑选会改变当前项目的维度，不整段复制 preset 文案。
- 一个项目通常一条主方向即可；副方向只有在段落、时间或世界切换有明确依据时使用。
- 参考图 / 视频中的主体、logo、文字和独特布局只有被对应 role 指定时继承；风格迁移不偷换内容身份。
- 最终 Brief / prompt 写可见的颜色、光线、空间、材质和运动证据；不依赖“cinematic”“高级”等孤立标签。
- 在 Brief 中记录主成像方式、细节密度、高光/暗部处理和颗粒/清晰度基线；Shot Plan 只写有意变化，Visual Gen prompt 继承基线并聚焦当前可见差异。
- 锐度、颗粒、柔焦、bloom、halation 和镜头光晕都应有局部作用范围；禁止把单一效果均匀铺满全片。

## Review

- 风格方向可以在没有 preset 名称时复述和执行。
- 新主体身份、用户指定颜色和产品事实没有被风格样本覆盖。
- 不因预设而新增 gate、asset、Stage、model lock 或固定 negative boilerplate。
- 肤色、织物、金属、玻璃、墙面和天空仍有不同纹理与高光行为，没有被统一调色或过度降噪抹平。
- 高光不过早剪白、暗部不是无细节死黑、主体没有因全局锐化出现硬边，也没有因全局柔焦失去关键纹理。

## Boundaries

本卡不把样本名称变成必选菜单，不强制 1 主 + 1 副的组合，不替代 `style-migration.md` 或当前项目的 Brief。
