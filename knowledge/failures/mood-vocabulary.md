# mood-vocabulary -- semantic mood ambiguity risk

## Activate When
The user gives a broad mood/aesthetic word that could support several distinct visual directions.

## Decision Test
If you can list three plausible visual treatments with different materials, density, palette intent, or era, ask. If refs anchor mood, name the non-color anchor; textify palette only when user-named or approved.

## Action
- Ask by dimensions, not menu labels: material richness, whitespace density, saturation, era, companion object, medium.
- If mood words collide, ask which one leads.
- When proceeding, translate mood into concrete visual levers: lighting, texture, composition density, typography tone, and user-approved palette only.

## Calibration
Examples like premium minimalism or healing sunlight are common samples, not defaults.
