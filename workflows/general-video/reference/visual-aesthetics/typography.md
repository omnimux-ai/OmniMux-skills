# 文字与排版（Typography）

## Activate When

- 用户明确要求片中文字、字幕、标题卡、招牌、包装、界面或其它可读文字。
- 文字的语言、层级、出现时机或与载体的关系会影响镜头。

## Decision Test

先判断文字是 **叙事信息**、**环境中的实体文字**，还是 **后期叠加层**。未要求文字时不主动添加；无法核实的装饰文字也不应成为关键信息。

## Define the Text

- **内容与语言**：逐字记录批准文本，保留大小写、标点、数字和多语言顺序。
- **职责**：标题、说明、说话人、地点、操作提示或环境信息分别承担什么。
- **层级**：通过字号、字重、位置、对比和留白区分主次，不要求每个画面都有多级文字。
- **阅读条件**：考虑画幅、平台、观看距离、运动背景、出现时长和安全区域。
- **视觉语气**：字体类别、字形宽窄、笔画、间距与项目世界一致，不以具体商业字体名替代判断。

## Choose a Rendering Path

- 精确标题、字幕、名称、数字和关键信息优先使用确定性后期排版，确保拼写与可读性。
- 场景内招牌、雕刻、印刷、屏幕或手写字需要生成时，描述物理载体、制作方式、透视、光照、遮挡和磨损。
- 生成路径难以稳定复现精确文字时，可先生成无字或留白载体，再在 Post 合成批准文本。
- 跨镜头重复文字保持内容、位置逻辑、载体状态和视觉层级连续。

## Boundaries

- 不把字幕、logo、水印、CTA 或片名当作默认交付。
- 不强制三层排版、固定字号比、固定安全边距或整段 prompt block。
- 不用长字体黑名单解决设计问题；优先明确语言、层级和载体。
- 本卡不添加品牌审核门槛或额外 stage。

## Check

- 在真实输出尺寸与预期停留时间内，关键信息可一次读懂。
- 文字与主体不碰撞，背景对比在整个出现区间稳定。
- 拼写、语言、顺序、时间点和载体透视均已核验。
