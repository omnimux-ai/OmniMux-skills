# T03 — 冷暖色温弧线叙事

> 仅在索引命中 T03 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户希望用冷暖、明暗或单色域递进表达情绪变化。
- 路线存在可识别的前后状态或转折事件。

## Anchors

- 在 `technique_plan` 记录色彩起点、转折点、结束状态，以及色彩变化对应的剧情 / 产品事件。
- Style Master 决定具体色相、饱和度和材质表现，不套固定 Kelvin 数值或固定镜头区间。

## Generation Strategy

- 全局基准先声明色彩弧线；各镜头只写当前阶段的主色、光源方向、主体受光与向下一阶段的变化。
- 色温变化跟随已确认事件，主体身份色和品牌色保持可辨。
- 相邻镜头需要连续时保留环境光逻辑，不因换景别随机改变色调。
