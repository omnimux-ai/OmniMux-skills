# 短剧剧本创作参考

> 规划短剧单集或系列大纲时读取：选择题材、设计开篇、布置 hooks 和付费点、设计爽感、搭建反派阶梯，并守住内容红线。对白节奏、镜头拆分和镜头组划分使用 `storyboard.md`，本文不重复这些规则。

## 创作大纲

用户没有可用剧本时，必须先完成两轮轻交互，再撰写完整剧本。

用户已经明确表达的设定直接采用；agent 根据平台、题材惯例或上下文推断的内容只能作为推荐项，不得标记为用户已确认。不要询问能够从用户输入可靠提取的信息，也不要在本阶段询问画幅、分辨率、字幕或 BGM 等生产参数。

### 第一轮：方向选择

调用一次 `question`，确认以下三个故事决策；每项使用独立 question 对象，给出 2–3 个互斥选项，最匹配的选项放在第一位并标记推荐：

| 决策 | 询问目标 |
|---|---|
| 题材方向 | 确认故事的主导题材，不超过一个主类型 |
| 主角路线 | 确认主角身份、行动方式和成长路线 |
| 核心情绪 | 确认作品主要提供爽感、情感拉扯或悬念反转 |

选项必须根据用户输入动态生成，不要机械复用固定题材表。允许用户在输入框补充人物、故事前提或禁用方向。

用户明确表示“你决定”“直接出”“都行”等授权词时，采用各项推荐值并继续，不停下等待。

### 第二轮：大纲确认

根据第一轮结果起草一份简短创作大纲，在普通对话中展示，不落 canvas。创作大纲必须包含：

- 暂定剧名
- 一句话故事
- 主角身份与行动路线
- 核心冲突
- 前三集钩子
- 整体走向与结局方向

展示后直接询问用户。

## 剧本落画布

- 创作大纲确认后，按已确认内容撰写完整剧本，不得擅自改变主角路线、核心冲突或结局方向。
- 文档名用 `剧本 — <episode/scope>`。
- 写完后回填真实 `document_node_id`。
- 只有按下方格式撰写完成的剧本文档才能落 canvas；推理草稿和未确认的创作大纲不落画布。

```markdown
# 剧本 — <项目名/集数>
## 基础信息：类型 / 集数 / 时长 / 风格 / 受众
## 故事梗概：一句话主线 + 核心冲突
## 角色：姓名 / 身份 / 目标 / 关系
## 场景级剧本
### 场景<序号>｜<时间>｜<地点>｜<人物>
画面：只写观众看得到的动作和环境
对白：角色名：逐字台词
情绪/时长/剧情标记：<情绪>｜<秒数>｜<钩子/反转/推进>
```

## 题材（Genre）

每部短剧都建立在少数成熟题材上。每个题材都隐含目标观众、观众期待的核心爽感，以及能快速传达题材的常用设定。先选题材；它会约束开篇、hook 组合、爽感类型和反派形态。

| 题材 | 观众 | 核心爽感 | 常用设定 |
|---|---|---|---|
| 都市甜宠 | 女性 18-30 | 心动、吃醋、公开偏爱 | 同居、办公室、契约情侣 |
| 霸总豪门 | 女性 25-40 | 占有式保护、阶层压制 | 联姻、隐秘继承人 |
| 甜蜜恋爱 | 女性 16-25 | 初吻、告白被发现 | 校园、青梅竹马、异地 |
| 重生穿越 | 20-35，男女混合 | 预判布局、惩治恶人、改写命运 | 重生到关键转折前、穿回过去 |
| 战神归来 | 男性 25-40 | 隐藏身份揭示、一对多、逼对方道歉 | 退伍特种兵、弃子归来 |
| 宫斗宅斗 | 女性 22-38 | 以牙还牙、揭穿阴谋、翻身 | 古代后宫、民国大宅 |
| 逆袭翻身 | 20-35，偏男性 | 打脸嘲笑者、阶层跃升、反转 | 赘婿、草根创业者 |
| 家庭伦理 | 30-50，偏女性 | 惩治渣男、真相大白、恶有恶报 | 婆媳矛盾、婚外情、遗产争夺 |
| 萌宝亲子 | 女性 25-40 | 萌娃金句、团圆、认亲 | 秘密孩子、单亲爸爸、DNA 匹配 |
| 悬疑推理 | 22-35，男女均衡 | 真凶反转、线索链、揭示 | 密室、连环案件、复仇追查 |
| 轻科幻 | 18-30，偏男性 | 能力觉醒、技术压制、生存 | AI 苏醒、时间循环、基因编辑 |
| 末世重生 | 20-35，偏男性 | 囤货兑现、弱胜强、基地建设 | 丧尸、资源崩塌、异能者 |
| 喜剧搞笑 | 全年龄 | 反差梗、连环误会、翻转 | 穿越闹剧、情侣日常、家庭喜剧 |

类型叠加：最多叠加三种，一种主导，其余辅助。避免互相打架的组合，例如甜宠硬接高密度悬疑就很难。成熟组合包括：霸总 + 萌宝，重生 + 逆袭，战神 + 甜宠，宅斗 + 重生，悬疑 + 重生。

出海改编：把中国题材映射到海外可理解的类似类型（霸总 → billionaire romance，战神 → ex-military/secret agent，宫斗 → royal court，萌宝 → secret baby/single dad），并本地化文化 beat：家宴可改成 charity gala，下跪磕头可改成公开道歉，彩礼可改成 trust fund。注意出海陷阱：西方观众希望主角尽快反击而不是默默忍受；反感无条件服从长辈；不接受把善良当软弱借口；比国内更能接受开放结局而不是强行大团圆。英语对白更短、更口语，重潜台词，少用直译成语。

## 系列节奏骨架

系列级情绪由四段上升波浪承载。下面的骨架用于放置 hook、付费点、爽感和反派 beat。

| 阶段 | 占比 | 情绪强度 | 核心任务 |
|---|---|---|---|
| 起势 | 前约 15% | 1 → 2.5 | 建立主角、核心冲突、关键关系和第一个小高点 |
| 攀升 | 约 15-45% | 2.5 → 3.5 | 打开支线、推动主角成长、升级对手、推进感情线；每 5-8 集一个小高点 |
| 风暴 | 约 45-80% | 3.5 → 4.5 | 最终反派浮出、最大危机爆发、联盟破裂；每 3-5 集一个高点 |
| 决战 | 最后约 20% | 4 → 5 | 最终对决、所有伏笔兑现、情绪抵达顶点 |

每个阶段都要保持推进：开头不要长时间纯铺垫；风暴段不要引入新的主线；决战段不要新增主角级人物或新支线。节奏下坠时，用短场景、交叉剪辑、倒计时，或直接时间跳跃到冲突来提速；情绪需要沉淀时，在峰值后用对白场、闪回或安静日常片段降速。

## 开篇

前约 5 秒决定观众是否留下，所以开篇要用有冲击力的画面或台词，而不是背景介绍。前 30 秒内建立三件事：核心冲突（这部剧讲什么）、主角处境（强、弱或危险要清楚）、第一个让观众想看下一秒的 hook。给观众一个可依附的情绪锚点。旁白、内心独白和“三年前”闪回只留给确实需要的开篇；重生冷开通常是例外。

选择符合题材的开篇策略：

- 直接打脸：配角嘲笑或羞辱主角；一句话或一个动作反转全场。适合逆袭、战神、霸总。
- 身份反转：主角看似无力，隐藏身份浮出，所有态度 180° 反转。适合重生、霸总、逆袭。
- 极致危机：先用生死场景抓住观众，再通过营救、重生或转折翻转。适合悬疑、末世、战神。
- 闪回悬疑：先展示高冲突结尾，再切到“X 小时前”，让观众带着结果看原因。适合悬疑、重生、家庭伦理。
- 甜蜜钩子：强制亲近或误会引发尴尬心动，建立 CP 感。适合甜宠、校园。
- 重生开局：快速闪过前世悲惨结局，猛然醒来，发现回到关键节点。适合重生。

## 钩子和悬念结尾

单集结尾 hook 要落在本集情绪峰值上，留下开放问题，并在下一集前 30 秒内回答。让观众等太久的 hook，或答案令人失望的 hook，会消耗信任。五类 hook：

- 悬疑：埋未解之谜，例如不该出现的访客、被打断的揭示、不该存在的物件、身份线索。
- 反转：抛出颠覆本集的事实，例如帮手隐藏恶意、本集“真相”在最后一秒被推翻、计划其实是陷阱。
- 情感：让情绪达到峰值或反转，例如告白被打断、误读场景导致心碎、牺牲征兆。
- 信息：释放改变棋盘的信息，例如第三方到来、秘密传到错误的人那里、更大威胁取代已解决威胁、倒计时。
- 危机：把角色推入危险，包括生命、关系、信任或整个计划的危险。

按阶段调整 hook 权重：起势偏悬疑和信息；攀升偏反转和情感；风暴偏危机和反转；决战偏终极反转和情感。某些组合能放大（悬疑 + 反转、情感 + 危机、信息 + 悬疑），某些组合会互相抵消；悬疑配过重信息会淹没观众，同类双 hook 放在同一个结尾会分散注意力。任何一个 hook 家族不要连续跑超过三集结尾。

## 付费点

付费点只有在情绪峰值、未解问题距答案只差一步、且观众已经投入足够时间产生沉没成本时才转化。按总集数比例放置，而不是按固定集数：

| 付费点 | 位置 | 功能 |
|---|---|---|
| 第一个 | 约 8-12% | 关键首次转化 |
| 第二个 | 约 18-25% | 留存 |
| 第三个 | 约 35-45% | 深度锁定 |
| 最后 | 最后 3-5 集 | 收尾收割 |

付费集大约控制在总集数的 15-20%。付费点 beat 是某类 hook 推到最强不可回头处：身份即将曝光、性命悬在一线、情感爆发被切断、反派计谋落地、真相只差一步浮出。它只有在真正紧张处切断才有效；不能切在平铺叙事、下集 30 秒就散掉的“悬念”、答案已经在切断前泄露、或轻松喜剧 beat 中间。免费集用中速建立依恋；付费集快速加热到峰值并停止；付费点后的下一集快速兑现，再打开新的 hook，让下一次付费点已经在蓄力。

## 爽感

爽感是题材承诺的情绪释放。每个爽感家族都从铺垫走向释放，并从轻量版本逐步升级；强度要按阶段分级，不要每次都开最大。

- 身份碾压：被嘲笑或看低 → 隐藏高身份揭示 → 全场震惊 → 加害者低头。轻量 = 一张卡拍在桌上；升级 = 一个电话、靠山下跪、全城震动。
- 打脸复仇：被羞辱 → 忍耐并布局 → 以其人之道干净反击 → 加害者崩溃。轻量 = 语言反击；升级 = 公开曝光、身败名裂、连环反转。
- 逆袭翻盘：被逼入角落 → 灵光一现或及时支援 → 反转棋盘 → 嘲笑者僵住。轻量 = 小胜；升级 = 人生级翻身。
- 情感爆发：长期压抑或误会 → 触发点 → 情绪倾泻 → 真相、和解或决裂。轻量 = 落泪；升级 = 崩溃、牺牲。
- 悬疑揭秘：线索累积 → 关键证据落地 → 真相串起每条线 → “原来如此”。轻量 = 一条线索；升级 = 全盘揭开、双重反转。

按弧线分配爽感：起势每 2-3 集承载低到中强度的身份碾压和打脸；攀升承载翻盘和情感；风暴混合所有家族；决战几乎每集落终极翻盘和悬疑揭秘。爽感只有被铺垫过才有重量：反派越可恨，打脸越甜；胜利越来自主角努力而不是纯外部外挂，余味越长；带情感的爽感高于单纯爽感。任何一个爽感家族不要连续出现超过三次。

## 反派

反派按四层阶梯上升，每层同时提高压力和与主角的关系深度。

- T1 小反派，前约 15%：傲慢，远弱于主角，通常背后有 T2。用于让主角先见血，给观众早期爽感；1-3 集内干净解决，然后给 T2 让路。说话直白、公开傲慢。
- T2 中反派，约 15-45%：有真实资源和真实动机，不是为了坏而坏。三轮击败：第一轮主角吃亏、威胁落地；第二轮双方均势、主角成长显现；第三轮主角获胜。退场要有记忆点。说话多用隐性威胁。
- T3 大反派，从约 45% 开始：权力和触手超过所有前置反派，与主角有深层关联（血缘、师徒、旧债），分层揭示，同时在情感和道德层面以及物质层面制造威胁。观众应既恨他，又不得不承认其强。说话沉稳优越。
- T4 隐藏 Boss，最后约 20% 揭示：此前一直以友好或中立身份出现。至少埋三个伏笔：早期一个不显眼细节，中段一个怪异行为，后段一个明显矛盾，让揭示时所有“巧合”扣合。动机必须有深度。说话温和友善，形成最大反差。

守住阶梯逻辑：不要跳层；击败每层反派都要暴露更大的手；每层压力和关系深度都要超过上一层。反派通过欺压弱者、背叛旧联盟、双标、嘲讽或拆散恋人来积累仇恨；观众越恨，反派倒下越爽。

## 合规

远离硬红线：政治敏感（歪曲历史或英雄、主权、邪教、民族分裂）、血腥暴力（详细酷刑、歌颂残暴、真实自伤方法、儿童或动物虐待）、露骨或剥削性性内容及任何性化未成年人内容、会教学或美化的犯罪（毒品、赌博、作案方法）。

灰区按“展示代价，不展示光环”处理：出轨、小三关系、骚扰、霸凌和家暴都需要道德清算和纠偏，绝不浪漫化；权力不平等关系（年龄差、师生、上下级、任何“强迫”亲密）需要明确同意和透明；财富和物质主义不能替代成功或价值；角色可以有偏见，但剧情必须纠正它。整体价值导向要正确：正义获胜、反派受罚，主角成功包含自身努力，爱情建立在平等尊重上，角色寻求合法途径，善有善报。

平台审核最看重标题、封面、前三集、对白洁净度和整体价值导向。出海时尊重各市场约束：东南亚关注宗教和王室；中东有严格伊斯兰规范和保守性别互动；西方对种族主义零容忍，且强关注儿童保护和性别平等；日韩注意敏感历史和校园霸凌；拉美重视宗教和家庭价值。按严重度处理：红线内容立即重写，价值导向漂移重塑剧情，灰区处理不当则补正向框架，细节润色最后做。
