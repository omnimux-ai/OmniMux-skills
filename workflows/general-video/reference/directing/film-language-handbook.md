# Film Language Toolkit — 视听语言工具箱

## Activate When

需要把 brief、脚本、讲解或现场行为转成 shot plan，并且景别、视点、运镜或剪辑关系会影响表达时读取。单个已明确 clip 不需要为了完整性读取。

## Decision Test

先确定镜头的首要任务：建立空间、展示行动、传递信息、观察反应、强调细节或制造节奏。镜头选择服务该任务和用户参考，不以题材名称套固定范式。

## Shot Scale

| 景别 | 主要价值 | 常见选择理由 |
|---|---|---|
| 远景 / 全景 | 世界、空间、路径、群体关系 | 新地点、复杂调度、尺度或孤独感 |
| 中景 / 中近景 | 动作与关系兼顾 | 交谈、演示、人物与环境互动 |
| 近景 | 注意力与语气 | 关键说明、选择、细微反应 |
| 特写 / 极特写 | 单一细节或感官冲击 | 手、眼神、材质、证据、动作落点 |

标注景别时同时写拍摄对象和表达目的；环境镜头可写空间对象。重要信息不必一律特写，只有当细节、情绪或可读性确实需要时才靠近。

## Viewpoint and Camera Motion

| 选择 | 能产生的体验 |
|---|---|
| 固定 / 稳定观察 | 克制、客观、让表演或构图主导 |
| 推近 / 拉远 | 逐步聚焦或揭示人物与环境关系 |
| 跟拍 / 横移 | 陪伴行动、展示空间路径 |
| 摇摄 / 升降 / 环绕 | 发现新信息、改变关系或展示尺度 |
| 手持 / 轻微漂移 | 现场感、身体感或不稳定 |
| 主观 / 过肩 / 反打 | 进入视点、组织对话和注意力 |

运镜写起点、路径、速度变化和落点。没有信息变化时，静止通常比无理由运动更清楚。

## Sequence Patterns

按内容自由组合，不要求每组齐全：

- 建立 → 行动 → 细节：先让观众定位，再靠近关键动作。
- 触发 → 反应 → 后果：适合选择、发现、冲突和笑点。
- 问题 → 过程 → 结果：适合教程、演示和产品行为。
- 观察对象 → 观察者反应：让观众同时理解看见了什么和如何理解。
- 长句 → 听者或相关动作 → 回到说话者：保持声音连续并提供新信息。
- 重复构图 → 有意义的变化：用前后差异表达时间、情绪或结果。

## Opening and Ending

开场可从空间、正在发生的动作、反常细节、问题或人物视点进入；选择最能建立观看承诺的一种。结尾可落在结果、未完成动作、反应、回声画面或开放空间；是否留钩子由用户目标决定，不把悬念当默认。

## Continuity

- 相邻镜头记录人物位置、朝向、动作阶段、道具状态、光线、声音和视线。
- 同地点、同主体、连续动作和一致声音意图的 beats 优先合成 continuity-first clip group。
- 只有场景/时间硬切、refs 不兼容、刻意蒙太奇或时长/对白溢出时拆组。
- 相似景别与同一对象连续出现时，改变视点、构图或信息焦点；变化需要可感知但不套固定角度数值。
- 对白保持用户确认文本；镜头可在说话者、听者、动作和环境之间移动，只要口型与音轨意图清楚。

## Shot-plan Fields

每个 shot 或 clip group 至少说明：叙事/信息目的、可见动作、主体与空间关系、景别/视点、镜头运动、声音或台词、起止连续性、预计时长及 refs。字段可以适配项目，不要求固定表头。

## Review

顺序检查：观众能否定位；每次切换是否带来新信息；关键动作是否可见；视线与动作是否连续；镜头节奏是否匹配内容；开头和结尾是否兑现用户想要的体验。发现问题时优先调整镜头目的与顺序，再补技术词。
