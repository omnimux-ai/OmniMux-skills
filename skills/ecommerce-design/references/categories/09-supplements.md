## 二、整体风格与质感

| 维度 | 要求 |
|------|------|
| **风格** | 专业可信 + 健康活力；色调清新自然；传递"科学 + 健康"双重信号 |
| **色调** | 暖白或中性色温 5000-5500K；绿色/蓝色系传递健康自然感 |
| **背景** | 白色/浅色系为主；成分图可搭配天然食材/植物元素 |
| **光线** | 明亮均匀，传递"干净"和"安全"感 |
| **道具** | 成分原料实物（蓝莓、鱼油、花瓣等），增强"天然"认知 |

## 六、易错点（Watch For）

- **【合规红线】包装上所有文字必须是 ground-truth（监管红线）** —— 永远不要让 AI 编造保健功效说明面板。任何 on-image 文字避免绝对化宣称（监管红线）。
- **【合规红线】认证 LOGO / 编号 / 检测数字 AI 不生成** —— 保健品是合规最高危品类，FDA / SFDA / GMP / 蓝帽子 / 有机 / 检验合格 等任何认证标识 / 批号 / 检测数字必须用用户提供的真实证书 / 包装素材，AI 仅做版式呈现。**没有真实素材 → 留空或不画**——伪造 = 监管直接处罚 + 平台下架 + 品牌信任崩塌。
- **【合规红线】成分含量 / 临床数据 / "见效"宣称 AI 不编造** —— "含 1000mg DHA"、"30 天见效"、"临床证明"等需要有真实第三方测试报告依据。
