# Infographic Publication Governance

## Decision

`image/infographic` remains a public business skill because its primary value is information architecture, visual hierarchy, prompt planning, and infographic diagnosis.

It is not treated as a code-execution skill.

## Runtime Boundary

Runtime-readable files:

- `SKILL.md`
- `references/layout-gallery.md`
- `references/style-pairings.md`
- `references/checklist.md`

Generation is optional and only applies when the user explicitly requests an image artifact.

## Public Use Conditions

- Use for infographic plans, data-to-visual mapping, copy compression, reference breakdown, prompt-only work, generated infographics, variants, and diagnosis.
- Do not invent facts, figures, dates, citations, rankings, or claims.
- Do not generate an image for planning, prompt-only, reference-breakdown, or diagnosis requests.
- Do not claim an image artifact unless a visible generation tool returns one.
