# T20 — 感官母题互译链

> 仅在索引命中 T20 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要把气味、触感、温度、轻盈、清新、品牌情绪或精神图腾转成可见画面。
- 路线已有 verified 产品属性或用户确认的品牌情绪，并能选择一个主感官母题贯穿环境、人物与产品。

## Anchors

- 在 `technique_plan` 记录感官命题、事实依据、母题的色彩 / 形状 / 材质 / 运动不变量、承载对象、适用位置和产品回收点。
- 只选择一个主母题；环境、人物、微观材质和产品每次出现都提供新的感官信息，不重复空洞的唯美构图。
- 分开登记 verified 产品事实、用户确认的品牌情绪和创意隐喻；创意隐喻不得写成 `selling_point_binding` 的功效证明。
- 动物作为精神图腾时，另记录物种、外观、行为基线、象征含义和目标市场文化边界；跨镜保持身份与行为连续，只通过姿态、视线、运动、色彩、形状、材质或声音连接人物 / 产品，不做无关动物插镜。

## Generation Strategy

- 从环境建立、人物接触 / 反应、微观材质代理、完整产品或使用结果中选择路线需要的节点，不套固定顺序或段落占比。
- 相邻节点使用色彩、形状、运动或材质的可见连续性完成互译，并分别写清初始状态、触发动作和结束状态。
- 动物图腾的力量、速度、稀有性或环境适应性只属于创意隐喻，不得被 Prompt 表述为产品性能、安全、功效或事实证明。
- 出现真实产品、皮肤或质地时，以 verified refs、包装色、产品比例和肤色事实覆盖隐喻风格；效果不得遮挡产品识别面或 Logo。
- 意象链结束前回到可识别的产品、使用结果或品牌记忆点；准确品牌文字和正式 Logo 按 `confirmed_text_timeline` 与 verified refs 进入对应视频单元，不交给 Post。
