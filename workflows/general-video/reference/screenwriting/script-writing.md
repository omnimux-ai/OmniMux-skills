# Script Writing — 故事与剧本写作

## Activate When

需要把用户目的、原创想法或来源内容写成故事、剧情、场景或角色对白时读取。

## 故事骨架

1. 明确主角的初始状态、可见目标和当前关系。
2. 用一个事件打破常态，迫使主角采取行动。
3. 让行动遇到具体阻力，并产生新信息或代价。
4. 让每个关键事件改变目标、关系、风险、信息或结果，形成前后因果。
5. 逐步提高压力，在关键选择处完成转折。
6. 用结尾行动兑现开场承诺，呈现结果、变化或余韵。

忠实改编沿用来源事实、人物关系、事件结果和揭示顺序；原创或自由改编围绕用户指定的主题与核心设定发展。非线性、循环、碎片化和开放结构也要保持核心关系可追踪。

## 人物

- 为主要角色写清 `Want`：正在追求的可见结果。
- 用习惯、恐惧、误判或关系制造阻力。
- 让压力迫使角色作出有代价的选择。
- 用结尾的决定、行动或关系状态呈现改变、坚守或失败。
- 极短内容聚焦一次清楚可见的状态变化。

## 场景

- 地点、时间、时间线或戏剧单元变化时建立新场景。
- 每场写清人物、环境、可见行动、可听声音和事件结果。
- 每场推动信息、目标、关系、风险、情绪或观看体验中的至少一项。
- 情绪通过选择、动作、停顿、物件和环境反馈呈现。
- 场景只写故事事实；景别、运镜、镜头数量和模型参数交给后续分镜与视频提示词。

## 对白

- 先确定每个角色此刻想从对方获得什么，以及对方提供的阻力。
- 让对白改变信息、关系、决定或风险。
- 用句长、词汇、节奏、提问方式和压力反应区分角色声音。
- 用动作、沉默、中断、回避和反向表达承载潜台词。
- 逐句朗读，保留符合人物、关系和目标语言习惯的表达。
- 用户确认的台词逐字保留，并补充必要的动作、停顿和表演信息。

## 输出格式

```markdown
# 剧本 — <标题>
## 故事梗概
<主角、目标、冲突、转折和结果>

## 角色
<姓名｜身份｜目标｜关系或限制>

## 场景
### 场景 <序号>｜<地点>｜<时间>｜<人物>
画面：<可见行动与环境变化>
声音：<对白、旁白、环境声或声音事件>
结果：<本场改变了什么，并如何推动下一场>
```
