# T08 — 黑白画面中的单点色彩

> 仅在索引命中 T08 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要黑白、低饱和、色彩克制或一个明确的品牌色爆点。
- 路线存在值得释放色彩的产品、Logo 或事件节点。

## Anchors

- 在 `technique_plan` 记录黑白基调、色彩释放对象、释放时机、品牌色值和恢复后的状态。
- 默认只保留一个主要释放点；是否增加第二个由路线和用户方向判断。

## Generation Strategy

- 全局基准声明黑白 / 低饱和范围；普通镜头保持材质层次和主体可读，不出现无意的彩色干扰。
- 释放镜头写清唯一有色对象、具体颜色、发光 / 反射方式和事件意义。
- 相邻镜头连续时保持曝光与空间关系，色彩变化跟随事件而不是随机滤镜切换。
