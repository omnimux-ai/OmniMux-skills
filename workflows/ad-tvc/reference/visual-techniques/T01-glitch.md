# T01 — Glitch 热成像转场

> 仅在索引命中 T01 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要 glitch、热成像、夜视、数据故障或短促的科技感断点。
- 路线中存在一个明确的情绪或节奏转折，且该效果与品牌调性相容。

## Anchors

- 在 `technique_plan` 记录适用位置、延续的主体 / 场景、红色热成像基调、网格 / 扫描线 / film burn 取舍和切换目的。
- 效果只服务一个清楚的转折，不把整条路线改成持续故障风格。

## Generation Strategy

- 对应镜头延续前一状态的主体、位置和动作，只改变为深红热成像、边缘暖橙灼烧、细网格、轻微水平位移与扫描线。
- 切入和切出跟随已确认事件，持续时间由该事件决定；Prompt 写清效果建立、保持和结束状态。
- 声音只写与切换同步的失真环境声或短促 SFX；BGM 仍由 Audio / Post 处理。
