# 色彩（Color）

## Activate When

- 用户、brief 或参考素材明确表达了色调、配色、饱和度、冷暖、情绪变化或颜色连续性。
- 色彩会影响主体识别、信息层级、场景关系或跨镜头一致性。

## Decision Test

先区分三类事实：用户明确要求、参考中可见的规律、为当前叙事提出的创作选择。不要把参考里偶然出现的颜色升级成全片规则。

## Build a Color System

- **主色**：承担世界、时间或总体情绪，覆盖大面积环境。
- **辅色**：分隔层次、补充材质与空间，不与主色平均竞争。
- **点缀色**：引导视线、标记角色/物体或提示转折，使用位置比色名更重要。
- **明度结构**：明确视觉焦点相对背景更亮、更暗或对比更强。
- **饱和度结构**：决定哪里鲜明、哪里克制；不要把“电影感”自动翻译成统一高饱和或低饱和。
- **保护色**：肤色、品牌/产品识别色、事实性标记和用户指定颜色不随全局调色漂移。

## Apply

- 从场景目的出发描述颜色职责，例如“冷色环境承载距离感，人物附近的暖色只用于情绪锚点”。
- 冷暖、明暗和饱和度可以单独变化；只选择真正服务当前镜头的维度。
- 跨镜头复用相同主体和地点时保持基线稳定；昼夜、观点或情绪改变时，记录变化起点与方向。
- 参考素材只贡献被指定的色彩角色；主体、构图和光线是否继承分别判断。
- 提示词写可见的颜色分布与关系，少用孤立色名和抽象风格标签。

## Boundaries

- 不强制固定电影锚点、调色 preset、色值清单或主辅色比例。
- 不用大段 negative prompt 代替清楚的色彩职责。
- 不为了统一色调抹掉自然肤色、材质差异、时间变化和重要信息色。
- 本卡不能自行增加风格 gate、模型锁或额外交付物。

## Check

- 缩小画面后，视觉焦点仍由明度、饱和度或色相关系清楚支持。
- 相邻镜头的变化要么连续，要么对应明确叙事变化。
- 颜色在主体、环境和材质上有来源，不像后期统一覆膜。
