# T17 — 表里透视科技链

> 仅在索引命中 T17 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要展示芯片、主板、散热、风道、电池、电驱或其它内部技术链路。
- 内部结构与性能信息有 verified 来源；没有结构证据时只使用抽象技术隐喻。

## Anchors

- 在 `technique_plan` 记录外观入口、内部结构、激活路径、回到使用价值的出口，以及每段所需产品 / 结构 refs。
- 只选择能解释核心卖点的链路，不为完整感展开全部部件。

## Generation Strategy

- Prompt 按外观可见细节、进入内部、结构 / 光流响应、使用结果的认知顺序组织实际镜头。
- 写清相机如何沿接口、缝隙或光流进入内部，以及内部动作如何对应 verified 功能。
- 未验证结构改写为抽象材质、光流或能量隐喻，不呈现为真实工程剖面。
