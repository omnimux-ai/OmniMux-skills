# 合规与表达边界

## 营销表达

- 不写未经证实的疗效、减肥、收益、排名或官方背书。
- 不把主观体验写成确定事实。
- 不把产品效果写成所有人都会得到的结果。

## 版权与主体边界

- 不直接复刻受保护的角色、名人肖像、竞品广告或知名 IP 画面。
- 如果用户引用参考内容，只提炼结构和方法，不照搬独特表达。

## 真实感边界

- 不新增用户没有提供的品牌承诺、人物身份或场景细节。
- 不把模型适配建议写成“已经验证通过”的结果。
- 不把“适合某模型”说成“某模型一定能稳定生成”。

## 交付边界

- 本 skill 的终点是 prompt 包，不是视频成片。
- 如果用户继续要求生成视频，应切换到公开视频生成入口，并只报告真实生成证据。
