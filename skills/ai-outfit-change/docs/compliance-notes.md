# AI 换装风险说明

## 目的

这份文档用于内部审阅时快速判断一项换装请求能不能继续、需要补什么确认、以及哪些点必须人工复核。

## 核心原则

- 不把未授权人物换装成商业素材。
- 不把 AI 结果包装成真实试穿证明。
- 不生成羞辱、骚扰、成人化或明显误导的内容。
- 不把看不见的服装细节写成确定事实。
- 不把品牌元素、机构身份或职业身份处理成可引发混淆的表达。

## 高风险场景

以下场景应直接拒绝或升级人工判断：

- 非授权人物、偷拍图、私密图或带报复性质的请求。
- 未成年人或疑似未成年人的成人化换装。
- 故意夸大身材、暴露程度或羞辱意味的编辑。
- 暗示真实代言、真实穿着、真实职业身份的商业素材。

## 需要先确认的场景

- 公众人物、达人、品牌主理人等可识别身份人物。
- 带明显品牌 logo、联名图案、角色元素的服装。
- 电商场景下会影响消费者判断的颜色、材质、版型变化。
- 需要把职业制服、机构标识、证件元素放进画面的请求。

## 可以继续但要留痕的场景

- 常规电商模特换装。
- 社媒风格图、Lookbook、广告测试图。
- 同一服装的多场景、多模特、多颜色变体规划。

继续时应记录：

- 人物来源和授权状态。
- 服装来源和是否含品牌敏感元素。
- 输出用途。
- 哪些细节是真实可见，哪些属于合理补全。

## 审阅输出建议

每次内部审阅至少给出四类信息：

- 风险等级：拒绝 / 先确认 / 可继续。
- 关键原因。
- 需要人工复核的点。
- 继续时的提示约束。
