# 构图与空间（Composition and Depth）

## Activate When

- 镜头需要明确主体位置、视觉重心、留白、视角、透视、景深或前中后景关系。
- 参考素材的空间组织会影响 Reference Brief、Shot Plan 或生成提示。

## Decision Test

先确定观众第一眼看什么、第二眼看什么，以及画面需要亲近、疏离、压迫、开阔、稳定还是失衡。构图规则只是实现手段，不是默认清单。

## Compose

- **主体位置与占比**：根据叙事关系选择居中、偏置、边缘或被环境包围，并保护动作和视线所需空间。
- **视觉重心**：用明暗、色彩、尺度、方向和留白平衡画面，不必机械套三分法或对称。
- **视角**：平视更中性，俯仰或倾斜会改变权力、脆弱与不安；只在语义需要时强调。
- **空间层**：用前景遮挡/框景、中景主体、背景线索形成深度；不是每个镜头都必须三层齐全。
- **透视感**：用“前景被夸张、背景被压缩、平行感、消失点明显”等可见结果描述，不虚构精确器材参数。
- **焦点策略**：说明哪些对象清晰、焦点何时转移、背景信息保留多少；景深服务注意力而非装饰。
- **引导关系**：道路、视线、动作、建筑边缘、光线或物体排列应把注意力带向叙事目标。

## Across Shots

- 同场景连续镜头保护屏幕方向、主体相对位置、视线和空间轴线。
- 景别变化应提供新信息或情绪距离；避免只为“丰富”随机跳远近。
- 有意打破轴线、比例或平衡时，在 Shot Plan 中写明预期感受和恢复方式。

## Boundaries

- 不强制焦距、光圈、主体百分比或固定构图法。
- 不把浅景深当作高级感默认；环境信息重要时允许深焦或多平面同时可读。
- 不用模糊背景掩盖错误透视、比例或主体漂移。
- 本卡只细化视觉语言，不增加镜头数量或输出单元。

## Check

- 主体、动作方向和关键环境信息一眼可读。
- 前后景的尺度、遮挡、清晰度和大气关系彼此一致。
- 连续镜头的空间变化能被观众理解，除非不理解正是创作目的。
