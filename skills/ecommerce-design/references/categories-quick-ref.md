# 电商 14 品类要点速查（高密度）

> **何时 read**：开始 brief 时快速判断本品类的重点 + 高危雷区。详细 playbook 走 `categories/{NN}-{name}.md`。
> **合规红线**：母婴 / 保健品 / 美妆 / 个护 / 运动等品类有合规红线，详见 `compliance-redlines.md`。

| 品类 | 重点 | 高危雷区 |
|---|---|---|
| 女装 | 性别 + 版型 + 廓形显式英文写出 | 训练先验拉向男装 / 中性 |
| 男装 | 同上 + 男士肩线 / 直腰 / 男性 drape | 拉向女装剪裁 |
| 鞋靴 | 成对（双鞋）+ 紧凑多角度；上脚镜头**不带脸** | 过度拆细节、单只鞋显廉价 |
| 箱包 | 全包 + 内部结构图 | logo 裁切、内部不交代 |
| 珠宝 | 比例锚（手腕 / 颈 / 耳）+ 反射逻辑 | 大小失真（耳环像拳头）、反射不合周围 |
| 美妆 | 真实色号 + 膏体质感 + 中性灰卡 | 色号偏差（首要退货原因）；编造功效宣称（"焕白""紧致 30%"） |
| 保健品 | 必须真包装 + 真成分表 | 编造成分 / 含量 / 认证编号 / 检测报告（合规高危） |
| 个护 | 真包装 + 材质质感 | 包装文字胡编；编造功效宣称（"99% 抑菌""24h 保湿"） |
| 家装家居 | 比例锚（人 / 房间） | 沙发比房间大 |
| 数码 3C | 屏幕用纯色或样机图；暗底 hero 可破"自然光默认" | 真实 UI / 编造按键不能搞；伪造能效标识 / 3C 认证 logo |
| 母婴 | 真照片合成 > 全 AI 生成；**认证 / 检测图必须用用户真实素材** | 婴儿脸 uncanny valley；编造安全认证标识 / 检测报告（合规高危） |
| 宠物 | 物种 / 品种锁定 + 毛色精准 | 猫被画成狗、品种漂移 |
| 日用品 | 单图焦点 | 太多杂物分散注意力 |
| 运动户外 | 动作 + 场景一致性；功能演示用**视觉证据**（水珠滚落 / 折叠对比）而非**功能标识** | 动作脱离场景（沙滩跑步穿登山靴）；伪造 UV / 防水等级 / SPF 等数字宣称 |
