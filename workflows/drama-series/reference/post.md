# 短剧后期 / 精剪参考

> `post` 阶段把已生成 clips 合成为成片前读取。先读取制作计划的音频和 `bgm_policy` 锁项，再读取 Visual Gen Stage 的 `execution_locks.subtitle_policy`。字幕策略没有明确锁定时阻塞，不得默认不加字幕。

## 声音层

保留适用的声音层，不要重复叠加。

- **对白层**：Mode A 和 Mode B 均保留 clip 生成时自带的原生视频音频；不要在 post 里重新生成对白音频，也不要叠第二条人声音轨。
- **音效层**：每个 clip 生成时携带环境、动作和空间声音（clip prompt 会写明）。不要重新生成 clip 已有的音效，避免双层叠加。
- **BGM 层**：`off` 时不生成、不混入；`provided` 时只使用用户音轨；`generate` 时为当前集生成一条完整 BGM。生成 prompt 必须读取剧本题材、时代地域、世界观和分镜情绪曲线，明确指定匹配的音乐风格、核心乐器、禁用音色和 `intro → build-up → climax → outro` 情绪结构；在换场景、情绪变化的时间点改变乐器、节奏、音色或能量，使音乐与新场景的空间、情绪和叙事功能匹配；生成后按本集总时长裁切，结尾处淡出，并与视频原生音频混音；整体需要 BGM 比对白低 10 dB。生成 clips 始终不带 BGM。

## 字幕层

按 Visual Gen Stage 的 `execution_locks.subtitle_policy` 执行：`不加字幕` 保持干净画面；`生成并烧录字幕` 先准备可信时间轴，再格式化并烧录；`只生成字幕文件` 只输出字幕文件，不把字幕烧进视频。Post 不得根据对白存在、模型默认值或缺少字幕文件自行改变策略。

## 整集情绪曲线（仅 `bgm_policy=generate`）

一条 BGM 内部应形成 `intro → build-up → climax → outro` 的完整起伏；按分镜时间轴设计情绪变化，不按镜头分别生成音乐。相邻情绪变化用音乐结构和动态自然衔接，集尾可保留 1.5-2 秒 stinger。

## 短剧精剪原则

- **前 30 秒必须有 hook**：开场镜头 ≤8s 定调，30s 内落到冲突爆发 / 反转 / 关键信息揭示。如果缺失，调整顺序让 hook 镜头组前置。
- **每 60 秒一个节奏点**：节奏点可以是景别跳变（≥2 级）、信息密度峰值（关键台词）或情绪尖峰（冲突 / 反转）。如果 60s 内空白，用特写反应或反转镜头补上。
- **冲突 / 反转段快切**：冲突镜头可降到约 3s 快切并承载更密集对白；反转段景别跳变 3 级以上。
- **结尾收束**：每个最终合成视频结尾固定追加 0.5s 黑场；黑场前保留最后一个情绪定格，且仅 `generate` 时添加 stinger BGM 段。
- **按情绪转场**：同地点硬切；跨地点 0.5-1s 溶解；时间跳跃 0.3s 白闪 + 色温变化；情绪转折 0.3s 定格；集尾 0.3-0.5s 淡出到黑。不要全部硬切（粗糙），也不要全部溶解（拖沓）。

## 精剪自检

- 前 30 秒存在 hook；开场镜头 ≤8s。
- 每个 60s 窗口都有节奏点。
- 结尾收束：最终合成视频末尾固定 0.5s 黑场；仅 `generate` 时检查 stinger 段。
- 转场分类正确（不是全程同一种）。
- BGM 服从制作计划：`off` 无 BGM；`provided` 只用用户音轨；`generate` 的整集情绪曲线与分镜时间轴一致。
- **零屏幕文字**：OCR 清理字幕 / caption / watermark，且音频底里**没有残留 Seedance BGM**。如果某个 clip 混入 BGM 或文字，重生成或裁掉该 clip。

## 时间轴

场景顺序与剧本一致；总时长服从剧本完整性。用户提供剧本时，自然超过 90-120s 是可以接受的，上限约 5 分钟；超过 5 分钟才提示用户。
