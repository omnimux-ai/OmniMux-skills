> **何时 read**：写 prompt / 评估出图 / 跨平台分发同一商品时——把 aspect / background / file 三项写入 prompt 的 spec block。**没说平台时主动问**——同一张产品图发淘宝（3:4）和发 Amazon（1:1 + 纯白）出 prompt 完全不一样，押错平台 = 重做。

## 跨平台同款分发的常见坑

同一商品发多平台时高频翻车点：

- **PDD 主图横版陷阱**：照淘宝 1:1 标准做 → PDD 拒收 / 显示扭曲。**必须重做横版**。
- **Amazon 纯白容差**：用 RGB(250,250,250) 的"近白" → Amazon 算法判定 non-white → 主图被降权。**必须**精确 RGB(255,255,255)。
- **Lazada 主图带文字**：照淘宝习惯加大字号促销文字 → Lazada 多语种环境下显示混乱 / 触发审核。**改为视觉传达**。
- **Tmall 透明 PNG 漏交**：只交了白底图没交透明 PNG → campaign 报名被卡。**透明 PNG 是必选项**。
- **京东 #1 非白**：场景图当 #1 主图传 → 系统强制替换为商品库白底图 / 直接退回修改。
- **Instagram 4:5 安全区**：把 logo 放在画面顶 / 底 → 被 Instagram UI 遮挡（顶 ~250px / 底 ~340px）。**关键元素居中**。
- **Etsy 4:3 缩略图陷阱**：1:1 主图在搜索结果会被裁成 4:3 → 上下被切掉 → 重要内容必须在中间 75% 区域。

## 各平台核心规则速记（prompt 阶段必知）

具体 spec / 文件大小 / 详情页宽度等深度信息直接到该平台官方说明页查；本节只列 prompt 阶段必须知道的硬约束：

- **Taobao / Tmall / 1688**：1:1 主流；Tmall 强制透明 PNG + 白底各一张
- **JD**：Image #1 强制纯白；产品 ≥ 85%（京东全球购）
- **PDD**：Home main 750×352 **横版** + ≤ 100 KB；白底图严格无 logo / 水印 / 文字
- **Douyin / Kuaishou**：真实照 > 精修；多角度强制；短视频权重高于静态
- **Xiaohongshu**：3:4 vertical 1080×1440；UGC / 真人分享 > 品牌精修
- **Amazon**：纯白 RGB(255,255,255) hero + 产品 ≥ 85%；推荐 2000×2000 zoom
- **Shopify**：自由度最高，2048×2048 推荐
- **Shopee / Lazada**：东南亚多语种环境，避免依赖文字传达卖点
- **TikTok Shop**：短视频 9:16 才是销售主驱动；UGC > 精修
- **Instagram**：4:5 竖版赢 feed；Reels 权重远高于静态
- **Pinterest**：2:3 竖版 = 最佳 feed 占地；视觉搜索引擎，Image SEO 有意义
