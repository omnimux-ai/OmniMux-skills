# Montage — 蒙太奇设计

## Activate When

多个镜头需要通过顺序、时长、运动、调性或概念碰撞产生额外意义时读取。连续表演或完整动作更适合单个 continuity-first clip 时，不为丰富度强加蒙太奇。

## Decision Test

先写清这组镜头为何要并置，再选择驱动逻辑：

| 驱动 | 观众体验 | 适用问题 |
|---|---|---|
| 节拍 Metric | 切点形成稳定、加速或减速脉冲 | 需要音乐卡点、倒计时或能量变化 |
| 韵律 Rhythmic | 切点跟随画面内部运动 | 动作速度和方向主导节奏 |
| 调性 Tonal | 光影、色彩、构图形成情绪弧 | 氛围需要逐步转冷、转暖、变亮或变暗 |
| 复合 Overtonal | 时长、运动和调性共同变化 | 高潮、释放或刻意不安 |
| 概念 Intellectual | 两个画面并置产生第三层含义 | 隐喻、因果、对比或观点表达 |

可以混合，但每组保留一个主要驱动，避免所有技巧同时抢注意力。

## Build the Sequence

1. 写一句组接命题：观众在 A 与 B 并置后应理解或感到什么。
2. 为每镜分配独立信息，不让多个镜头重复同一画面价值。
3. 选择切点依据：节拍、动作落点、视线、形状、色彩、声音或概念。
4. 设计能量曲线；快切、长镜、停顿和静止都可成为节奏。
5. 让最后一镜完成揭示、反转、释放或问题延伸。

## Match and Contrast

- Match cut 可匹配形状、构图、运动方向、视线、光线或声音，前后镜不必来自同一空间。
- Contrast cut 可对照尺度、速度、颜色、材质、人物处境或声音密度。
- 因果组接让动作与结果相邻；若时间或空间并不连续，在 shot plan 中标明这是推断关系。
- 概念碰撞应让目标受众有足够线索理解；信息不足时增加一个桥接镜头，而不是用旁白解释全部。

## Rhythm with Sound

切点可以跟随音乐强拍，也可以故意提前、滞后或让声音跨画面延续。先确认 BGM、对白和环境声在叙事中的优先级，再决定卡点；不要因为有音乐就让每个切点机械对拍。

## Work-item Notes

对每组记录：主要蒙太奇类型、镜头顺序、每镜功能、切点证据、声音关系、开端/收束状态及 refs。需要跨多个生成 clip 时，把匹配构图或运动方向写入相邻 work item 的 end/start continuity state。

## Review

检查并置是否真的产生新意义、切点是否有可见或可听证据、节奏是否符合内容、概念是否可理解、相邻 clip 是否能完成预定匹配。若效果只是随机快切，删减镜头或重新确定唯一驱动。
