# Poster Image Recipe

## Activate When
用于单张独立海报 / KV / 主视觉 / 活动海报 / 招聘海报 / 节庆海报 / 电商大促海报 / 餐饮饮品海报 / 美妆海报 / 新品发布海报 / 课程公益海报 / 音乐演出海报 / 电影剧集海报。

保持 Simple Direct Path。读取本卡后直接编译一个 `hub_generate_image` prompt；海报本身不升级为 planner task、canvas plan 或 Stage Execution Plan。

## Decision Test
- 最终产物是一张图片，或几张互相独立、可以立即生成的海报变体。
- 单图编辑 / 优化已有海报时，用同样方法写 edit prompt，并锁定用户要求保留的版式、主体和文字意图。
- 多镜头视频、短剧、多阶段资产流水线、长脚本规划、需要先产出角色 / 场景 / 声音等依赖资产的任务，走对应项目流程。

## Core Rule
生图模型已经具备强海报品类先验。海报 recipe 的任务是保留用户原始 brief，并补充少量模型容易不稳定的确定性信息；它不是内容扩写器、不是设计执行清单。

优先级：
1. 保留用户原始要求：品类、文案、主体、品牌/平台、配色、尺寸、构图、氛围、信息优先级。
2. 补确定性视觉控制：比例/尺寸感、投放语境、色彩比例、明暗对比、宽泛版式方向、文字排版关系。
3. 仅在用户明确主体需要材质稳定时，补一句材质/光影锚点。

用户没给的商业事实、额外文案、价格、优惠规则、导流方式、联系方式、品牌承诺、人物、地点和故事线保持空缺或中性占位。用户没有要求排除的内容不扩展成负向约束。

用户明确给出的平台名、品牌名、活动名不是风险项，要作为可读文字身份保留。品牌安全只处理未提供素材的 logo 图形、真实商品包装和可识别商标外观，不把用户给出的平台/品牌文字抽象掉。

色彩比例是高价值增强：用户给出明确配色或氛围时，增强尾句必须落成近似数值分配，写出主色约 60-70%、辅色约 20-30%、高光约 5-10%，并补明暗层次和高光集中位置；这类增强不属于过度设计。

## Prompt Assembly
输出给 `hub_generate_image` 的 prompt 从成品画面开始，不写元说明标题。完整 brief 使用“原始 brief 段 + 增强尾句”：

1. **Original brief paragraph**：首段尽量沿用用户原句序、语气和开放表达。保留“可以加点”“几组”“都来点”“别糊一块”“要醒目点”“类似某种氛围”这类会激发模型先验的词。
2. **Enhancement tail**：尾部只追加比例/尺寸感、色彩比例、明暗层次、短安全句或短文字排布句。增强尾句不重新枚举用户已给文案，不展开版式楼层，不把自然 brief 改成位置槽位。
3. **Sparse brief handling**：用户 brief 稀疏时，只补视觉方向；如果缺失内容会改变商业含义，询问用户或使用中性占位。

## What To Add
只添加以下确定性增强，且每项最多一句：

| 增强项 | 何时添加 | 写法粒度 |
|---|---|---|
| 比例尺寸 | 用户给了尺寸、平台、竖横方向或没说清比例 | `9:16 竖屏海报，1080×1920 方向感` |
| 投放语境 | 用户说主会场、KV、门店、展架、社媒 | `手机屏主视觉 KV` / `线下展架海报` |
| 色彩关系 | 用户给了色彩或情绪 | 必补近似数值比例：主色约 60-70%、辅色约 20-30%、高光约 5-10%，并写明明暗层次、主体和文字对比 |
| 版式方向 | 用户没说清结构但任务需要基本版式 | 只补一个宽泛词：信息阶梯 / 商品分区 / 三分留白 / 上图下文 / 中心对称 |
| 文字排版 | 用户给了多个文案、信息多、按钮/时间/利益点等层级 | 文字合理排布，层级和留白自然 |
| 品牌安全 | 用户明确要求无品牌、不要 logo、避免商标，或涉及具体第三方商品包装 | 用通用无品牌商品、抽象包装图案；保留用户给出的平台/品牌文字 |
| 材质光影 | 用户明确冷饮、玻璃、美妆、食物、产品包装等主体 | 只写 2-4 个关键材质词，如凝水、折射、接触阴影、边缘高光 |

## Boundaries
保持 prompt 像用户 brief 的增强版，而不是设计规范文档：

- 局部排布交给模型，只保留用户要求的结构和宽泛版式方向。
- 商业事实以用户给出为准；缺失事实使用中性占位或询问用户。
- 文字质量用短句承接：文字合理排布，层级和留白自然。不展开成版式说明或文字校对任务。
- 品牌安全不默认进入生成 prompt；仅在用户明确要求或具体商品包装存在商标风险时，用一句短安全句处理，并保留用户给出的平台/品牌文字。
- 品类知识只提供方向词。模型知道电商、咖啡、美妆、招聘、演出、电影海报的常见视觉。

## Category Hints
只在用户 brief 稀疏、需要稳定方向时使用；完整 brief 通常不读这一段，不展开成清单：

- 电商大促：尺寸感、色彩比例、节庆明暗层次、通用无品牌商品。
- 餐饮饮品：产品 hero、食欲/冷饮材质、菜单式或包装式文字。
- 美妆个护：产品 hero、留白/细框、玻璃/金属/膏体/丝绸/水滴质感。
- 产品发布：packshot 轮廓、材质反射、边缘高光。
- 活动节庆：仪式感构图、主色氛围、活动文字身份。
- 招聘课程公益：文字主导、清晰网格。
- 音乐演出：舞台感、追光/轮廓光、动势。
- 电影剧集：按用户题材选一个宽泛电影海报构图方向。

## Before Generation
内部确认：prompt 以用户 brief 为主体；只追加确定性增强；商业事实来自用户或中性占位；安全要求保持一句话；最终 prompt 像一段可执行海报 brief，而不是设计规范文档。
