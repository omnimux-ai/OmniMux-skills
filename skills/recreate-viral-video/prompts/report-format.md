# 报告组织方式

推荐按下面顺序组织复刻报告，保证分析、判断和交付能顺着读下来：

1. **项目概览**
   - 用户目标
   - 证据等级
   - 目标平台 / 市场 / 时长
2. **参考结构拆解**
   - hook
   - 节奏
   - 卖点顺序
   - 证明方式
   - CTA
3. **商品或主题画像**
   - 核心卖点
   - 受众
   - 使用场景
   - 不能说的内容
4. **适配等级**
   - A/B/C/D
   - preserve / replace / rewrite / avoid
5. **原创方案**
   - 脚本方向
   - 分镜骨架
   - 提示词包
6. **风险与后续**
   - 版权 / 品牌 / 主张风险
   - 还需补充的输入

写法要求：

- 观察与判断分开写。
- 先解释原因，再给建议。
- 低适配或证据不足时，把限制写在前面。
