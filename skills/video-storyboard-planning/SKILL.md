# Skill

## Overview
这个 skill 用于把“视频创意想法”转化成“可执行的视频分镜图方案”。

它适合以下输入场景：
- 用户只有一个产品或链接，希望做一条带货视频
- 用户只有一个粗略方向，希望生成完整分镜
- 用户已有脚本，希望拆成镜头
- 用户已有参考视频，希望提炼为新分镜结构
- 用户需要为 AI 出图 / AI 视频生成准备逐镜头提示词
- 用户需要为真人拍摄准备标准化镜头执行表

运行时先读 `references/runtime-guide.md` 和 `references/output-template.md`。其它目录是发布包支撑素材与测试资产，不能假设 Agent 运行时会自动读取。

它适合以下输出目标：
- 分镜脚本
- 镜头清单
- 节奏设计
- 逐镜头画面说明
- 逐镜头提示词
- 拍摄 / 出图 / 剪辑执行备注

## Publication Governance

这个 skill 是公开业务方法论 skill，不是代码执行 skill。

- `tools/` 里的脚本只用于离线作者校验、导出或样例资产处理，不属于 Agent runtime 的核心能力。
- `workflows/` 里的 Markdown 是方法模板，不是强制工作流、固定阶段机或 required-next tool。
- `schemas/`、`templates/`、`examples/`、`rubrics/` 只作为合同校准材料；默认运行时只读取 catalog 配置里的 `SKILL.md` 与 `references/` 文件。
- 不要因为本 skill 被激活就调用视频生成、图片生成、Canvas 持久化或导出工具。只有用户明确要求下游交付，且对应工具可见并满足前置条件时，才进入下游工具。
- 与 `canvas/video-storyboard` 的关系：本 skill 面向商品短视频、UGC、电商转化和 AI 出图前置规划；`canvas/video-storyboard` 是更轻量的通用镜头表方法。不要把两者叠加成重复输出。

## When to Use
在以下情况使用本 skill：

1. 用户明确要求：
   - 做视频分镜
   - 出一版分镜图方案
   - 把脚本拆成镜头
   - 给视频做 storyboard
   - 做镜头表 / shot list
   - 输出 AI 出图前的分镜规划

2. 用户提供以下任一输入并希望转成视频结构：
   - 产品信息
   - 商品图片
   - 商品链接
   - 卖点列表
   - 一段口播文案
   - 一个广告脚本
   - 一个参考视频
   - 一种视频风格要求

3. 用户最终想要的是“结构化分镜结果”，而不是直接成片生成。

---

## When NOT to Use
以下情况不要单独使用本 skill：

1. 用户要的是最终视频生成，而不是分镜方案
   - 应交给更完整的视频生成流程处理

2. 用户只想要一句文案、一个标题、几个 hook
   - 不必启用完整分镜流程

3. 用户只需要把现成脚本改写成某个视频模型专用 prompt
   - 更适合走视频 prompt 转换流程

4. 用户只要求分析一个已有视频内容
   - 更适合视频分析类流程

- 产品信息
- 视频主题
- 脚本草稿
- 参考视频结构

### Optional Inputs
- 产品名称
- 产品链接
- 产品图片
- 品牌名
- 用户画像
- 平台（TikTok / Reels / Shorts）

- 卖点列表
- 使用场景
- 竞品参考
- 禁止出现的表达
- CTA 目标（下单 / 点击 / 收藏 / 关注）

## Output Goals
本 skill 的标准输出包括：

1. 视频定位摘要
2. 分镜结构总览
3. 逐镜头镜头表
4. 每个镜头的画面描述
5. 台词 / 字幕建议
6. 运镜 / 景别 / 节奏建议
7. AI 出图提示词（如需要）
8. 拍摄执行备注（如需要）
9. 后期剪辑提示（如需要）

## Output Format
默认输出应为结构化 Markdown，建议包含以下模块：

### 1. 项目摘要
- 视频目标
- 目标受众
- 风格方向
- 时长建议
- 核心转化点

### 2. 分镜结构总览
按视频逻辑拆分：
- Hook
- 痛点
- 产品出现
- 卖点演示
- 证据/信任
- CTA

### 3. 逐镜头分镜表
每个镜头建议至少包含：
- 镜头编号
- 时长
- 画面内容
- 景别
- 运镜
- 人物动作
- 台词 / 字幕
- 卖点目标
- 执行备注

### 4. Prompt Pack（可选）
若用户需要 AI 出图 / AI 视频前置提示词，则补充：
- 单镜头 prompt
- 统一风格约束
- 产品一致性要求
- 负面提示词

## Core Workflow

### Step 1: Clarify the Objective
先识别用户到底要什么：
- 带货转化
- 品牌种草
- 产品讲解
- 爆款模仿结构
- AI 分镜图准备
- 真人拍摄执行

若目标不明确，优先从用户原话中提炼，不轻易打断追问。
只有当缺少最基本任务信息时才补问。

### Step 2: Identify Available Inputs
盘点用户已提供的信息：
- 是否有产品
- 是否有卖点
- 是否有脚本
- 是否有参考视频
- 是否有平台/时长/风格要求

如果信息不完整，先按“最小可执行方案”输出，再说明哪些补充信息能进一步提高质量。

### Step 3: Choose a Story Structure
根据视频目标选择结构：

#### 电商带货常见结构
- Hook → 痛点 → 产品解决方案 → 卖点演示 → 信任背书 → CTA

#### UGC 口播结构
- 开场观点 → 个人体验 → 功能展示 → 使用结果 → 推荐理由

#### 高级感广告结构
- 氛围开场 → 产品特写 → 功能细节 → 场景融合 → 品牌收束

#### 对比测评结构
- 问题场景 → 对比对象 → 实测过程 → 差异结果 → 推荐结论

### Step 4: Expand into Shot-Level Storyboard
把结构层级拆成逐镜头：
- 每个镜头只承载 1 个主要信息点
- Hook 区域节奏更快
- 卖点镜头尽量可视化
- CTA 简洁直接
- 尽量让镜头具备可拍摄性 / 可出图性 / 可剪辑性

### Step 5: Add Execution Layers
根据用户用途增加附加层：
- 如果用于 AI 出图：补 prompt
- 如果用于真人拍摄：补机位/动作/道具说明
- 如果用于剪辑：补转场/字幕/BGM 节奏建议

### Step 6: Review for Platform Fit
最后检查是否符合短视频平台特征：
- 前 3 秒是否有钩子
- 信息密度是否足够
- 镜头切换是否快
- 卖点是否清晰
- CTA 是否明确
- 是否适合竖屏表达

## Storyboard Design Principles

### 1. Single Shot, Single Job
每个镜头尽量只完成一个任务：
- 抓注意力
- 展示痛点
- 展示卖点
- 建立信任
- 引导转化

避免一个镜头塞入过多信息。

### 2. Visual First
分镜必须优先考虑“看见什么”，不是只写“想表达什么”。

弱：
- 表达产品很好用

强：
- 近景拍摄用户单手 3 秒内完成操作，画面同步出现“3秒搞定”字幕

### 3. Conversion-Oriented
带货视频分镜不是电影脚本。
每个镜头都应服务于：
- 提升停留
- 提升理解
- 提升信任
- 提升点击/下单

### 4. Shootable / Generatable
输出的镜头必须可执行：
- 真人能拍
- AI 能生成
- 剪辑能落地

避免抽象空泛表述。

### 5. Consistency
如涉及产品、人物、空间、光线，需保持一致性：
- 产品外观一致
- 人物形象稳定
- 场景不跳脱
- 风格统一

## Recommended Default Output Template

### 项目摘要
- 视频类型：
- 目标平台：
- 目标时长：
- 核心受众：
- 核心卖点：
- 转化目标：

### 分镜结构
1. Hook
2. 痛点引入
3. 产品出现
4. 卖点演示
5. 使用结果 / 信任证明
6. CTA

### 镜头表
每个镜头包含：
- Shot ID
- Duration
- Scene Purpose
- Visual Description
- Camera Framing
- Camera Movement
- On-screen Text
- Dialogue/VO
- Selling Point
- Production Notes

## Optional Output Modes

### Mode A: 简洁版
适合用户只想快速拿到结构：
- 6~8 个镜头
- 每镜头 1~2 句描述
- 不展开 prompt

### Mode B: 标准版
默认推荐：
- 完整分镜结构
- 逐镜头说明
- 台词/字幕建议
- 节奏建议

### Mode C: 生成就绪版
适合 AI 出图 / AI 视频：
- 完整分镜
- 逐镜头 prompt
- 风格统一约束
- 负面提示词
- 一致性要求

### Mode D: 拍摄执行版
适合团队拍摄：
- 分镜表
- 道具/场景/人物动作
- 机位/运镜/收音/转场建议

---

## Quality Bar
输出应满足以下标准：

1. 有明确的视频目标
2. 有清晰的起承转合
3. Hook 足够快、足够强
4. 产品卖点是“被看见”的，不只是“被说出”
5. 分镜具备执行性
6. 不空泛，不堆砌形容词
7. 适配短视频平台节奏
8. CTA 清楚且不拖沓

---

## Failure Modes to Avoid
避免以下问题：

- 只有文案，没有镜头
- 只有概念，没有执行细节
- 镜头顺序混乱
- 卖点与画面脱节
- 过度 cinematic，忽略转化
- 过多抽象描述，无法出图或拍摄
- 平台感弱，不像短视频
- 缺少 Hook 或 CTA

---

## If Inputs Are Weak
当用户提供信息很少时：

1. 不要直接拒绝
2. 先基于常见电商视频逻辑给出“基础版分镜”
3. 明确标注哪些地方是合理假设
4. 再告诉用户，如果补充以下信息可进一步优化：
   - 产品图
   - 用户画像
   - 核心卖点
   - 时长
   - 风格参考

---

## Compliance Notes
如果输出涉及广告表达、功效承诺、对比宣传、用户见证、销量/排名/认证等内容：
- 避免擅自编造不可验证结论
- 对强功效、医疗、极限词、前后对比等表达保持谨慎
- 必要时提示用户替换为更稳妥表达

---

## Handoff Suggestions
当分镜完成后，可交付到下游流程：
- 图像生成：按镜头生成 storyboard frame
- 视频 prompt 生成：把每个镜头转成模型可读 prompt
- 真人拍摄：导出 shot list
- 剪辑执行：补字幕、音效、转场节奏表

## Example Trigger Phrases
以下用户表达通常会触发本 skill：
- 给我做一版视频分镜
- 帮我拆成镜头
- 输出一套 storyboard
- 做个带货分镜图
- 把这段脚本转成分镜
- 帮我做 15 秒 TikTok 分镜
- 根据这个产品做视频镜头表
- 给 AI 出图准备逐镜头画面提示

---

## Final Rule
优先输出“能直接拿去执行”的结果。
不要把分镜写成空泛创意提案。
如果用户没要求长篇解释，就先给结构化成品，再补可选优化建议。
