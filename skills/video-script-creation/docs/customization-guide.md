# 视频脚本创作自定义指南

本指南用于调整视频脚本创作 skill 的输出口吻、行业重点、平台节奏和交付格式。

## 口吻

可按品牌或场景调整：

- 朋友分享
- 专业顾问
- 强转化带货
- 生活方式种草
- 理性测评
- 轻幽默
- 极简直接

建议同步维护禁用表达和推荐表达，避免脚本出现夸张承诺、过度广告腔或不符合品牌调性的 CTA。

## 行业重点

不同品类应优先强调不同证据：

- 美妆护肤：使用场景、肤质限制、效果边界和前后对比风险。
- 服饰鞋包：版型、材质、尺码、搭配场景和上身限制。
- 家居日用：使用前后、收纳效率、耐用性和真实空间尺度。
- 食品饮料：口味、成分、适用人群和健康宣称边界。
- 数码家电：功能场景、参数解释、兼容性和售后风险。

## 平台节奏

- TikTok / Reels / Shorts：前 3 秒钩子、口语化、强画面动作和字幕可读性。
- 小红书：场景代入、真实体验、避坑和选择理由。
- 电商详情视频：卖点清晰、证据明确、CTA 克制。

## 交付格式

可以按后续使用方式选择输出：

- 口播脚本：重点放在真人说得顺不顺。
- 拍摄脚本：补画面动作、道具、景别和字幕。
- 改写版本：保留主卖点，只调整语气、时长或平台。
- 下游交接：整理主体、场景、镜头语言、旁白摘要和必须保留的产品细节。

## 质量标准

- 一个脚本只围绕一个主卖点展开。
- 每个卖点都要有可展示的场景或证据。
- 开头要具体，不用空泛口号。
- CTA 要和前文逻辑一致。
- 无法证明的效果必须降级成假设、体验或待验证信息。
