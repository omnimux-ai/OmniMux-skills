# 模型映射提示

## 目标

这份提示用于帮助判断：同一份输入在不同模型上，应该调整哪一层表达，而不是换掉业务目标。

## 通用处理流程

1. 识别输入类型：`script`、`storyboard`、`shot-list`、`rough-prompt`、`mixed`
2. 提取主体、场景、动作顺序、镜头重点、限制条件
3. 清理彼此打架的指令
4. 再按目标模型重写表达

## `generic`

- 适合未指定模型或需要高兼容性的情况
- 优先保证主线清楚
- 少用平台专属术语

## `sora`

- 强调连续动作和稳定世界状态
- 让环境、主体和动作像一件事自然发生
- 少用彼此分离的镜头标签

## `veo`

- 强调商业质感、构图、光线和产品可见性
- 镜头语言要更明确
- 产品和主体一致性要写在明面上

## `seedance`

- 强调钩子、节奏和短时长可读性
- 让首屏就出现看点
- 每段镜头都要有清晰目的
