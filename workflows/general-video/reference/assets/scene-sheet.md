# Scene Sheet — 可复用场景身份

## Activate When

同一地点要跨多个依赖镜头保持可识别，且现有图片、视频或 ref capsule 不足以稳定空间身份时读取。一次性背景、泛化地点、纯 mood/world 信号或已有 scene base 足够时跳过。

## Decision Test

- Scene base 锁的是地点身份，不是每个镜头的光照和构图。
- 同一物理空间的不同景别、机位、时段和天气通常共享一个 scene identity。
- 先复用用户场景 ref。新建 scene base 只发生在跨镜复用和一致性收益明确时。
- 爆炸、坍塌、被洗劫等不可逆结构变化形成状态派生；普通昼夜、灯光或临时布置只写在 shot prompt。

## Action

场景身份至少记录：

| Dimension | Content |
|---|---|
| Geometry | 空间边界、入口、层级与主要纵深 |
| Landmarks | 不移动的视觉地标和固定设施 |
| Materials | 墙、地面、建筑或自然表面的主要材质 |
| World | 时代、地域、用途和生活痕迹 |
| Baseline light | 只记录身份相关的固定光源，不冻结每镜氛围 |
| State | 正常、损坏或其它持续结构状态 |

- 每个新生成的 scene base 是一张 16:9 图片和一次图片调用，包含同一物理空间的 2×2 四视图网格：左上为正面视图（主摄像机面对主要纵深），右上为背面视图（沿同一空间纵深轴反向拍摄），左下为从左侧拍摄，右下为从右侧拍摄；它不是四张图或四次调用。
- 四个视图必须读起来是同一空间：布局、入口/出口、固定家具或地标、建筑/自然材质、照明器具、场内文字标识、光线方向/时段、尺度、时代/地域设计和持续状态保持一致；外景按同一空间结构等价处理。
- 允许细分割线，但不添加面板标题、方向标签或水印。
- 不把临时道具、镜头专属天气或光效写进地点身份。
- 只有场景锚点的尺度或站位依赖角色时才使用角色 refs，地点身份本身仍须可读。
- 在 Stage Execution Plan 中把 scene anchor 作为可复用 runtime ref；每个 work item 只在地点实际出现时引用，并另写本镜头动作、机位和光照差异。
- 不可逆变化状态各生成一张四视图锚点，引用基础 / 前一状态并只描述结构性变化。

## Review

确认输出是一张 16:9 的 2×2 四视图图，正面 / 背面 / 左侧 / 右侧位置正确；检查入口、地标、固定物、材质、尺度、光源方向和持续状态是否一致；确认 shot plan 的机位在该空间中成立，不同状态的变化有 source 依据，一次性美术没有误升为地点身份。

## Boundary

本卡是 reusable scene anchor 的唯一主输出；其他场景约束只服务同一 Assets work item，不创建额外场景图片。

共享 Asset Pipeline 决定是否创建 scene base；Semantic Judgment 决定参考的 world / layout / style 贡献。本文件只规定 general-video 场景锚点的四视图形态和身份连续性，不规定模型路由或视频 vendor。
