# 输出格式提示

建议按以下顺序交付：

## 1. 优化后提示词

- 给一段可直接复制使用的主 prompt
- 保留用户原始意图
- 把主体、动作、场景、风格和限制写完整

## 2. 提示词拆解

建议说明：

- 主体与场景
- 动作顺序
- 镜头重点
- 风格处理
- 模型适配理由
- 哪些变量后续还能改

## 3. 建议避免项

聚焦最相关的失败风险，例如：

- 主体外观漂移
- 手部异常
- 材质失真
- 背景抢主体
- 节奏过碎
- 夸张且不可信的表达

## 4. 假设说明

如果结果用了默认模型、时长、比例或镜头密度假设，要单列出来，避免把假设伪装成用户已确认事实。
