# Write Script Template

## Use Case
Use this template when the user wants to:
- write a short-form ecommerce video script
- create a UGC selling script
- turn product information into a TikTok-style ad script
- generate hook, body, proof, and CTA structure
- create multiple script directions for testing
- build a script before storyboard or prompt conversion

This template is optimized for commercial short-form video, not general storytelling.

## Template Rules
1. Do not write scripts as feature lists.
2. Always define one dominant message.
3. Always make the first few seconds count.
4. Always connect important claims to proof.
5. Always consider buyer hesitation.
6. Always make the script speakable, not just readable.
7. Always think about what is shown, not only what is said.
8. Keep the CTA connected to the strongest benefit or proof.
9. Prefer a few strong beats over too many weak ones.
10. If the product needs stronger proof than explanation, design the script around proof first.
