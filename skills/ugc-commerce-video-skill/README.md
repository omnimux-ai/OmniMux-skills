# UGC Commerce Video Skill

## Overview
UGC Commerce Video Skill is a reusable workflow package for analyzing, planning, and structuring short-form ecommerce videos for platforms such as TikTok, Instagram Reels, and YouTube Shorts.

This skill is designed for commercial content creation rather than general entertainment video writing.
Its primary focus is conversion-oriented short video workflows, including:
- content analysis
- hook diagnosis
- UGC selling script creation
- storyboard planning
- video prompt conversion
- reference-video adaptation
- CTA design
- creative variation planning

The skill helps transform product information, reference content, or existing scripts into practical outputs that can be used by:
- creators
- editors
- marketers
- performance teams
- AI image/video generation systems
- ecommerce operators

---

## Core Use Cases

### 1. Video Analysis
Break down an existing short-form video and explain:
- how it is structured
- what the hook is doing
- how the product is being sold
- where the proof appears
- what objections are handled
- how the CTA works
- what could be improved

### 2. UGC Selling Script Planning
Turn product information into a conversion-focused short video script with:
- hook
- body structure
- proof
- objection handling
- CTA
- visual guidance

### 3. Storyboard Planning
Transform a script or selling angle into a scene-by-scene visual storyboard suitable for:
- creator filming
- in-house production
- AI video workflows
- outsourced editing teams

### 4. Video Prompt Conversion
Convert a script, storyboard, or rough idea into a model-ready prompt for AI video generation systems.

### 5. Reference Video Adaptation
Analyze a reference video, extract its useful selling logic, and rebuild it as an original concept adapted for another product or brand.

### 6. Creative Testing Support
Produce multiple hook options, angle variations, CTA alternatives, and scene adjustments for testing.

## What This Skill Is Designed To Optimize
This skill prioritizes:
- conversion clarity
- short-form retention logic
- product understanding
- proof-based persuasion
- platform-native communication
- execution readiness

This skill does **not** optimize for generic brand-copy writing, abstract storytelling, or long-form editorial scripting unless the user's commercial objective clearly requires it.

## Core Workflow

### Step 1: Identify the task type
Determine whether the user needs:
- video analysis
- script planning
- storyboard planning
- prompt conversion
- reference adaptation
- creative testing
- production planning

### Step 2: Clarify the commercial objective
Understand whether the goal is:
- conversion
- product education
- awareness
- creator-style recommendation
- objection reduction
- comparison-based persuasion
- UGC authenticity

### Step 3: Structure the problem
Organize the request into:
- audience
- product promise
- friction points
- proof requirements
- visual needs
- CTA direction

### Step 4: Apply the right output logic
Different workflows require different outputs.
Do not apply the same format to all requests.

### Step 5: Produce execution-ready deliverables
Outputs should be usable by either:
- a human production team
- a creator
- an editor
- an AI generation toolchain

## Design Principles

### 1. Conversion first
The skill must always optimize for why a viewer would stop, understand, trust, and act.

### 2. Platform-native language
Outputs should sound appropriate for short-form ecommerce content, not like generic ad copy.

### 3. Product clarity over decorative creativity
Creativity is useful only if it supports product understanding and persuasion.

### 4. Proof matters
A strong script or analysis must account for demonstration, believability, and skepticism reduction.

### 5. Hooks must work fast
The opening should establish relevance, curiosity, pain, result, or surprise quickly.

### 6. CTA must feel earned
The call to action should emerge naturally from the proof and selling logic.

### 7. Outputs must be shootable or generatable
If a script or storyboard cannot realistically be executed, it is incomplete.
