# 电商图七条防翻车铁律 + 三条工作流 meta 约束

> **何时 read**：写任何电商图 brief 之前必读。任何一条违反都会直接拉低 CTR 或触发退货 / 合规风险——prompt 设计阶段就要规避，post 阶段也要按这七条 inspect。

## 七条防翻车铁律

### 1. 不捏造事实（Prime Directive）

电商图是商业承诺。每个可见元素必须满足：物理真实、用户明确 brief、或来自参考图——三者居其一。

- 包装文字、成分表、认证 logo、规格数字、容量标识 → **必须**来自真实 reference 图
- 不允许凭训练先验生成"看起来像样"的文案 / 规格（保健品 / 母婴 / 3C 是合规高危区——详见 `compliance-redlines.md`）
- 文字密集的包装：先用占位空白生成场景，真 logo / 标签后期合成
- 不确定就问用户或留空，**禁止**用"看起来像样"的发明填补

### 2. 产品至上（Subordination）

产品是这张图唯一的存在理由。**模特、姿势、视线、表情、场景、道具、灯光、色调、构图——一切都为产品服务**，不为自己服务。

- 模特不是主体，模特穿戴产品；场景不是主体，场景烘托产品；背景不是主体，背景让产品被看见
- 任何元素若开始与产品争夺注意力 → 压制 / 调整 / 裁切 / 移除
- 评判标准：构图、姿势、灯光、色调时反复问"这个元素是为产品服务，还是为它自己服务？"——若是后者，改
- **一张漂亮但找不到产品的图 = 失败**，不论多有杂志感

### 3. 一图一职（One Image, One Job）

不要试图一张图干三件事。

- main / hero 图卖点击（视觉钩子 + 产品识别度）
- detail / macro 图卖信任（材质 / 工艺 / 真实感）
- scene / lifestyle 图卖向往（使用场景 / 情绪共鸣）
- size-ref 图卖准确预期（比例锚 / 不退货）

每张图选**一个**核心任务。同时塞两个职责的图，两边都做不到位。

### 4. 框定完整性（Framing Integrity）

关键元素**要么完整、要么干净裁切**，禁止下列尴尬截断；并且产品要占主导。

**禁止截断的位置**：

- 品牌 logo：边缘裁切 / 被遮挡 / 折叠 → 全部禁止
- 全身模特：脚踝 / 小腿中段裁切 → 禁止；必须**带鞋带脚**，3:4 或 4:5 画幅，上下各留 5% 净空（**禁止 1:1**）
- 半身 / 腰上 / 胸上模特：眼 / 鼻 / 嘴 / 发际线裁切 → 禁止；**必须带完整头部 + 头顶 5% 留白**，画幅同样 3:4 / 4:5
- 手部：手指中段 / 手掌中段 / 指节中段 → 禁止；要么完整手、要么干净腕部裁切
- 产品边缘：hero / 白底 / 细节图必须完整带留白；除非裁切本身是设计点

**产品占比与位置**：

- hero / 白底 / detail：产品占 **60–85%** 画面
- lifestyle：产品占 **40–60%**，但绝不低于 40%
- 位置：中心或三分点；不浮空、不贴边

如果当前画幅 + 姿势装不下这些，**先改画幅或拆多张**，不要靠 prompt 硬挤。

### 5. 背景-产品对比度（Contrast Discipline）

追求"优雅分离"，不是"高反差海报"。

- 禁止同色调溶进：white on cream / black on charcoal / 暖木 on 暖木
- 禁止极端反差：cream on black / white on pure black / 中性产品 on 饱和色
- 默认做法：同色族基础上，明度或饱和度位移**一档**
  - 米 / 象牙产品 → 柔自然白或微冷未漂白亚麻（不是黑色）
  - 黑色产品 → 暖浅灰或柔燕麦（不是纯白）
  - 暖木产品 → 偏冷柔灰（不是钢蓝或黑）
  - 饱和色产品 → 去饱和的柔和互补色
- **服饰例外**：服装 detail / macro / 工艺特写 + 纯展示图（flat-lay / 衣架 / 假人 / 产品独立棚拍）默认**自然柔白底**——白 / 米 / 象牙服饰用微离纯白的柔白，靠柔和接触阴影定边缘
- **平台硬性白底例外**（Amazon / 京东主图）：纯白 RGB(255,255,255)，不走对比度规则

### 6. 细节图三规则（Detail Shot Trinity）

微距 / 工艺 / 材质特写**必须**满足：

- **单一焦点**：一张图只突出一个细节；多细节拆多张
- **不带人**：negative 必加 `no human skin, no hands, no body parts, no fingers`
- **统一背景**：整组细节图用**完全相同**的中性表面（哑光布 / 原木 / 中灰纸）——shot 1 用米色棉布 → shot 2/3 必须同款米色棉布，不能换木板或换灰

> 紧凑产品例外（鞋 / 表 / 小首饰 / 墨镜 / 小配件）：不要硬拆 per-feature 细节图，**改用多角度展示**（前 / 侧 / 后 / 3-4 / 顶 / 鞋底）+ 1-2 张真有差异的工艺特写。

### 7. 默认参数

无明确指示时，按 `defaults.md` 的默认参数表出 prompt。**核心**：分辨率 1K / 灯光自然光中性日光 / 默认禁止相机机身 / 胶片 / 电影色调 / 默认禁止图上叠加文字。

## 三条工作流 meta 约束（必读）

七条铁律之外，还有三条贯穿整个工作流的 meta 约束。它们不属于"单张图怎么写 prompt"层面，而是"整个 dispatch 链路怎么不出错"层面。任一违反 = 流程性 bug。

### Meta-1. 每次 dispatch 前都需要确认门 — 但只确认一次

每次生成（pilot / 全集 / regen / 单张 ad-hoc）前必须有一次用户确认。但**绝不二次确认**：如果上一个 phase gate 已经覆盖（属性卡确认 / 模特 pilot gate / 重生确认），不要重复 confirm。已确认即 dispatch，重复确认会让用户重新审同一份内容，浪费一个 round-trip。

### Meta-2. 复用而非重做（honor what already exists）

每个 gate / dispatch 之前快速过一遍一句话："这个槽位是否已被填过？" — 用户参考图、之前已生成的图、approved pilot 都算"已填"。已填则**复用**，不要再生成或再问：

- 模特 pilot 图就是模特白底图——Shoot Plan 里"图 1: 模特白底"应直接用 pilot，不二次生成
- 已 approved 的 set 成员图就是该场景的 canonical reference——后续同 sub-set 派发应附它，不再 text-only 重写场景描述
- 用户给的产品参考图就是产品 source-of-truth——所有派发应附它，不要每次叫 image agent "想象产品"
- 接近不完美的图：走 regen 局部修（参照 `regen-clauses.md`），**不要**全图 text-to-image regen

**填过的槽位再次发问 / 再次生成 = bug，不是安全检查**。

### Meta-3. 评分是 mandatory，不可跳过

每张图生成后**必须**按 `quality-scoring.md` 六维评分一遍。**没评分等于没出图**，不能 ship 给用户。

- 六维加权分低于 Quality Bar → regen（具体阈值定义走 `quality-scoring.md`）
- 任一 severe AI defect 命中（见 `ai-pitfalls.md`）→ **fail，分数作废**，必须重做

> 三轮 stop 条件 / "何时回到策划阶段" 等评分流程步骤走 `ec-quality-model`（保留的工作流 skill）STEP 6，本 reference 不重复流程。

跳过评分直接 ship = 让用户帮你 QC，每次都会被反提"这张不行"——浪费 round-trip 又掉信任。
