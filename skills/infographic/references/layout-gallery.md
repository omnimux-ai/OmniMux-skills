## Sequential Layouts

### linear-progression

Sequential steps, timeline, or chronological events in a line.

- **Structure**: Linear arrangement (horizontal/vertical), nodes at key points, connecting path, directional flow, clear start/end
- **Variants**: Timeline (dates + period labels) | Process (step numbers + action icons)
- **Best For**: Tutorials, historical timelines, project milestones, onboarding, workflows
- **Prompt Keywords**: `linear progression infographic, sequential steps along a horizontal/vertical line, numbered nodes connected by arrows, clear start point and end point, [N] steps evenly spaced`

### winding-roadmap

Curved path with milestones showing a journey or long-term plan.

- **Structure**: S-curve or winding path, milestone markers along the road, start and destination points, side elements (obstacles/helpers)
- **Best For**: Project roadmaps, career paths, customer journeys, learning paths, strategy timelines
- **Prompt Keywords**: `winding road map infographic, S-curve path with milestone flags, journey from start to destination, scenic route with checkpoints, progress indicators along curving road`

### comic-strip

Sequential narrative panels telling a story or explaining a concept step by step.

- **Structure**: Multiple panels in reading order (left→right, top→bottom), characters in scenes, speech/thought bubbles, clear panel borders
- **Best For**: Storytelling explanations, user journey narratives, scenario illustrations, before/during/after
- **Prompt Keywords**: `comic strip infographic, sequential narrative panels, speech bubbles, characters with expressions, panel borders, story sequence from left to right`

## Comparison Layouts

### binary-comparison

Side-by-side comparison of two items, states, or concepts with a vertical divider.

- **Structure**: Vertical divider splitting image in half, mirrored layout for easy comparison, clear visual distinction between sides
- **Variants**: Before-After (temporal change) | A vs B (feature contrast) | Pro-Con (balanced evaluation)
- **Best For**: Before/after transformations, product comparisons, pros-cons, old vs new
- **Prompt Keywords**: `split comparison infographic, vertical divider, left side [A] right side [B], mirrored layout, contrasting colors per side, VS symbol in center`

### comparison-matrix

Grid-based multi-factor comparison across multiple items and criteria.

- **Structure**: Table/grid layout, rows = items, columns = criteria, cells = scores/checks/values, clear header row and column
- **Best For**: Product feature comparisons, tool evaluations, multi-criteria decisions, specification sheets
- **Prompt Keywords**: `comparison matrix infographic, grid table layout, checkmarks and X marks in cells, color-coded scores, header row with criteria, items listed in rows`

## Hierarchy Layouts

### hierarchical-layers

Nested layers showing levels of importance, influence, or priority from core to periphery.

- **Structure**: Multiple layers (3-7), core/top = most important, outer/bottom = decreasing importance, clear boundaries
- **Variants**: Pyramid (triangle, vertical, top-down) | Concentric (rings, radial, center-out)
- **Best For**: Priority levels, spheres of influence, organizational structures, stakeholder analysis
- **Prompt Keywords**: `hierarchical pyramid infographic, [N] layers from top to bottom, widening tiers, distinct color per level, most important at apex, icons per tier`

### tree-branching

Hierarchical structure branching from root to leaves showing categories and subcategories.

- **Structure**: Root at top or left, branches splitting into sub-branches, leaves as terminal nodes, clear parent-child relationships
- **Best For**: Taxonomies, decision trees, org charts, file structures, classification systems
- **Prompt Keywords**: `tree branching diagram, root node at top branching downward, parent-child connecting lines, category colors per branch, leaf nodes as terminal items`

### funnel

Narrowing stages showing conversion, filtering, or refinement from wide input to narrow output.

- **Structure**: Wide top (input), narrow bottom (output), horizontal layers for 3-6 stages, progressive narrowing, width indicates volume
- **Best For**: Sales/marketing funnels, conversion processes, filtering, recruitment pipelines
- **Prompt Keywords**: `funnel infographic, wide top narrowing to bottom, [N] stages with distinct colors, percentage or numbers per stage, conversion flow visualization`

## Relational Layouts

### hub-spoke

Central concept with radiating connections to related items like a wheel.

- **Structure**: Prominent central hub (main concept), spokes radiating outward, nodes at spoke ends (related concepts), even or weighted distribution
- **Best For**: Central theme with components, product features, ecosystem mapping, mind maps
- **Prompt Keywords**: `hub and spoke diagram, central circle with radiating connections, spoke lines to surrounding nodes, icons at each node, central concept prominently labeled`

### circular-flow

Cyclic process showing continuous or recurring steps in a ring.

- **Structure**: Circular arrangement, steps around the circle, directional arrows, no clear start/end (continuous), optional center concept
- **Best For**: Recurring processes, feedback loops, lifecycle stages, continuous improvement, natural cycles
- **Prompt Keywords**: `circular flow diagram, ring of steps with directional arrows, evenly spaced nodes around circle, continuous cycle, center element with cycle name`

### venn-diagram

Overlapping circles showing relationships, commonalities, and differences between concepts.

- **Structure**: 2-3 overlapping circles, each circle = one category, overlaps = shared elements, center = common to all, unique areas for exclusives
- **Best For**: Concept relationships, skill overlaps, market segments, comparative analysis
- **Prompt Keywords**: `venn diagram infographic, [N] overlapping translucent circles, distinct colors per circle, shared elements in overlap regions, labels inside each zone`

### jigsaw

Interlocking puzzle pieces showing how parts fit together into a whole.

- **Structure**: Puzzle pieces that interlock, each piece = one component, connections show relationships, assembled or exploded view, missing piece highlights gaps
- **Best For**: Component relationships, team/skill fit, strategy pieces, integration concepts
- **Prompt Keywords**: `jigsaw puzzle infographic, interlocking puzzle pieces, distinct colors per piece, icons or labels inside pieces, assembled to show complete picture`

## Spatial Layouts

### isometric-map

3D-perspective spatial layout showing locations and relationships through space.

- **Structure**: Isometric 3D perspective (30° angle), locations as buildings/landmarks, paths connecting locations, bird's eye view
- **Best For**: Office/campus layouts, city/ecosystem maps, system architecture, process landscapes
- **Prompt Keywords**: `isometric map infographic, 3D birds eye view, buildings and landmarks at locations, pathways connecting places, consistent isometric angle, floating labels above objects`

### bento-grid

Modular grid layout with varied cell sizes, like a Japanese bento box. Useful for mixed-topic overviews when the information shape is genuinely modular.

- **Structure**: Grid of rectangular cells (1x1, 2x1, 1x2, 2x2 mixed), hero cell for main point, supporting cells around it, no strict symmetry
- **Best For**: Multiple topic overviews, feature highlights, dashboard summaries, portfolio displays, mixed content
- **Prompt Keywords**: `bento grid infographic, modular rectangular cells of varied sizes, hero cell prominent, clear cell boundaries, icons per cell, visual hierarchy through cell size`

### dashboard

Multi-metric display with charts, numbers, and KPI indicators in a data-dense layout.

- **Structure**: Multiple data widgets (charts, graphs, gauges, big numbers), grid or modular layout, key metrics prominent, status indicators
- **Best For**: KPI summaries, performance metrics, analytics overviews, status reports, data snapshots
- **Prompt Keywords**: `dashboard infographic, multiple chart widgets (bar/line/pie/gauge), big KPI numbers, trend arrows, color-coded status indicators, clean data visualization grid`

## Metaphor Layouts

### iceberg

Surface vs hidden depths — small visible tip above waterline, large mass below revealing hidden factors.

- **Structure**: Waterline dividing visible/hidden, tip above water (obvious/surface, smaller/brighter), larger mass below (hidden/deep, darker), proportional to emphasize hidden depth
- **Best For**: Surface vs root causes, visible vs invisible work, symptoms vs underlying issues, known vs unknown
- **Prompt Keywords**: `iceberg infographic, clear waterline dividing surface and depths, small tip above water in bright colors, large mass below water in deep blue tones, wave texture at waterline, depth gradient`

### bridge

Gap-crossing structure connecting problem to solution or current state to future state.

- **Structure**: Left side = current state/problem, right side = desired state/solution, bridge element spanning the gap, bridge components = steps/methods
- **Best For**: Problem→solution journeys, current vs future state, gap analysis, transformation strategies
- **Prompt Keywords**: `bridge infographic, two platforms with gap between them, bridge structure connecting problem side to solution side, stepping stones or planks labeled with methods, visible chasm below`

### story-mountain

Plot structure arc showing rising action, climax, and resolution like a mountain shape.

- **Structure**: Mountain/arc shape, rising slope (build-up), peak (climax, visually emphasized), falling slope (resolution), start and end at base level
- **Best For**: Narrative structures, project lifecycles, tension/release patterns, emotional journeys, campaign arcs
- **Prompt Keywords**: `story mountain infographic, arc-shaped path rising to peak and descending, climax at mountain top prominently marked, milestone points along slope, start and end at base level`

### periodic-table

Grid of categorized elements with consistent cell formatting, inspired by the chemical periodic table.

- **Structure**: Rectangular grid, each cell = one element, color-coded categories, consistent cell format (symbol + name + brief info), optional grouping gaps
- **Best For**: Categorized collections, tool/resource catalogs, skill matrices, reference guides
- **Prompt Keywords**: `periodic table style infographic, uniform grid of cells, each cell with symbol abbreviation and name, category colors, legend showing color meaning, organized collection display`

## Deconstructive Layouts

### structural-breakdown

Internal structure visualization with labeled parts, layers, or components via exploded or cutaway view.

- **Structure**: Central subject (object, system, body), parts/layers clearly shown, callout lines with labels, exploded or cross-section view, optional zoomed detail sections
- **Variants**: Exploded (parts separated outward) | Cross-section (sliced/cutaway view)
- **Best For**: Product teardowns, anatomy explanations, system components, material composition
- **Prompt Keywords**: `structural breakdown infographic, exploded view with parts separated, callout lines with label boxes, numbered components, central subject clearly rendered, layer boundaries visible`
