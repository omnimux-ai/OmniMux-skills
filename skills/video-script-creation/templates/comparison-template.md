

# Comparison Template

## 用途
用于短视频脚本中的“对比型内容”创作，适合做产品对比、方案对比、新旧版本对比、使用前后对比、不同价位对比、不同场景适配对比等。目标是帮助观众更快做判断，同时突出某个选择更适合特定需求。

---

## 对比型内容的核心原则

1. 对比必须对用户决策有帮助
2. 对比维度要具体，不要只说“更好”
3. 尽量比较“适合度”，而不是简单贬低另一方
4. 对比应建立在真实可感知差异上
5. 结论最好是“适合谁选什么”，而不是绝对化裁决
6. 避免无法验证的夸大比较、排名、第一、吊打式表达
7. 如果涉及竞品，尽量聚焦特征、场景、体验差异，而非攻击

## 常见对比类型

### 1. 同类产品对比
适合：
- 两个产品选哪个
- 同品类不同款式怎么选
- 高低配差异怎么看

### 2. 新旧版本对比
适合：
- 升级值不值得
- 新版解决了什么问题
- 老用户是否需要换新

### 3. 使用前后对比
适合：
- 使用产品前后的变化
- 改用新方法后的效率变化
- 问题改善过程展示

### 4. 场景适配对比
适合：
- 不同人群适合不同方案
- 不同预算怎么选
- 不同需求下各自优势

### 5. 认知反差对比
适合：
- 看起来差不多，实际区别很大
- 价格接近但体验差异明显
- 常见误解 vs 实际体验

## 标准结构

1. 抛出选择题
2. 说明为什么难选
3. 给出对比维度
4. 逐项比较
5. 总结适合人群
6. 行动引导

---

## 1. 抛出选择题

目标：让用户快速进入“我也在纠结这个”的状态。

可用句式：
- 这两个到底怎么选？
- 如果你正在纠结 ____ 和 ____，先看这个
- 看起来差不多，但实际差别还挺明显
- 我把这两个放在一起比了下
- 很多人卡在这一步：到底选 A 还是 B

填写模板：
- 两个对象：
- 用户纠结点：
- 开场语气：

## 2. 说明为什么难选

目标：承认用户困惑合理，降低说教感。

可用句式：
- 难选的点就在于它们看起来都不错
- 表面上差别不大，但用起来会很不一样
- 不是谁更“高级”，而是谁更适合你
- 价格/定位接近时，最容易选错
- 真正要看的不是 ____，而是 ____

填写模板：

- 常见误区：
- 真正该看什么：

## 3. 给出对比维度

目标：建立判断框架，而不是主观下结论。

常见维度：
- 价格
- 外观/材质
- 使用门槛
- 功能细节
- 适用场景
- 耐用度
- 舒适度
- 效率
- 便携性
- 性价比
- 适合人群

可用句式：
- 我主要从 3 个点来比
- 如果你要选，重点看这几个维度
- 真正拉开差距的是下面这几点
- 不用看太复杂，抓这 2–4 个点就够了

## 4. 逐项比较

目标：用最短的话讲清差异，不堆信息。

### 写法 A：一项一项比
示例结构：
- 先说价格
- 再说体验
- 再说适用场景
- 最后说综合结论

### 写法 B：一方一方讲
示例结构：
- A 适合什么人
- B 适合什么人
- 决定因素是什么

### 写法 C：优缺点并列
示例结构：
- A 的优势 / 不足
- B 的优势 / 不足

可用句式：
- A 的优点在于 ____，但它更适合 ____
- B 更强的是 ____，不过如果你在意 ____，要注意
- 如果只看 ____，A 会更合适
- 如果你更看重 ____，那 B 体验会更好
- 它们不是谁完全替代谁，而是侧重点不同

- B 在维度 2 的表现：

## 5. 总结适合人群

目标：帮助用户做出“适合我”的判断。

可用句式：
- 如果你更在意 ____，选 A
- 如果你属于 ____ 这类人，B 会更适合
- 预算有限但想要 ____ 的人，可以优先看 A
- 想一步到位、在意 ____ 的，更推荐 B
- 不是谁更强，而是谁更对你的需求

填写模板：
- A 适合谁：

- 不建议谁选 A：
- 不建议谁选 B：

## 6. CTA 行动引导

目标：推动用户继续了解或进入购买决策。

可用句式：
- 你可以按自己的需求对号入座
- 如果你也在纠结这两个，先把这几点记住
- 不确定的话，先看你最在意哪一点
- 想少踩坑的话，优先从需求倒推
- 适合你的那个，往往不是最贵的那个

填写模板：

## 常用对比句式库

### 中性客观型
- 这两个不是谁绝对更好，而是侧重点不同
- 真正决定你选哪个的，是你更在意什么
- 表面看差不多，细节决定体验
- 用法相近，但适配人群不一样
- 不同需求下，答案可能完全不同

### 强调差异型
- 最大差别其实在 ____
- 真正拉开体验的是这个细节
- 看参数可能差不多，但实际感受会不一样
- 最容易被忽视的，反而是最影响使用的点
- 一旦放到真实场景里，差异就很明显

### 分人群推荐型
- 适合新手的是 ____
- 适合高频使用的是 ____
- 如果你预算有限，优先看 ____
- 如果你在意长期体验，建议看 ____
- 如果只是轻度需求，其实 ____ 就够了

## 适合短视频的画面建议

可以搭配以下镜头：

- 双画面对比
- 左右分屏
- 价格/尺寸/步骤字幕对照
- 同场景轮流使用
- 同动作、同环境下测试
- 特写展示关键差异
- 最终“适合谁”总结页

---

## 风险表达规避建议

避免：
- “全面碾压”
- “完胜”
- “第一名”
- “谁买谁知道”
- “100%更好”
- 无依据的性能/销量/排名/认证比较

尽量替换为：
- “更适合 ____ 场景”
- “在 ____ 这一点上更有优势”
- “如果你更看重 ____，会更推荐这个”
- “综合体验上更偏向 ____ 人群”

## 自检清单

发布前检查：

- 是否明确说明了“在比什么”？
- 对比维度是否足够具体？
- 是否避免空泛地说“更好”？
- 是否帮助用户做出选择，而不是制造混乱？
- 是否尽量客观中性，而不是攻击式表达？
- 是否说清了不同人群的适配差异？
- 是否避免违规比较、夸大结论、无依据排名？
- 是否适合短视频节奏和信息密度？

---

## 备注
好的对比型内容不是为了“赢”，而是为了“帮用户更快选对”。当你把“谁更适合什么场景”说清楚，信任感和转化率通常都会更高。
