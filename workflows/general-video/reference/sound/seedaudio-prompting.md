# 场景化音频提示（Scene-based Audio Prompting）

## Activate When

- 生成的不是中性朗读，而是带角色表演、对白关系、环境与声音事件的音频。
- 同一音频内存在清晰的时间顺序或声场变化。

## Decision Test

若内容只需要一句稳定旁白，使用简洁的文本与表演方向即可。只有听觉事件之间存在关系时，才写场景化提示。

## Prompt Order

按听众实际听到的顺序描述：

1. **场景与距离**：空间大小、室内外、听觉视点以及角色离听众的远近。
2. **角色与意图**：谁在说、对谁说、此刻想达成什么，而非只列抽象情绪词。
3. **表演变化**：能量、速度、犹豫、压抑、爆发或转折发生在何处。
4. **批准文本**：对白或旁白逐字保留，角色归属清楚。
5. **声音事件**：动作、环境和音效按时间出现，并说明与语言的遮挡关系。
6. **声场重点**：前景、背景、左右或远近关系，以及最终必须清楚的主导声音。

## Writing Rules

- 使用可听见的动作与因果，如“说到名字时压低声音，门外脚步随后靠近”，少用无法听见的视觉形容词。
- 一个段落只维持一个主要视点；视点变化时明确时间与原因。
- 情绪写成表演行为：呼吸、速度、音量、咬字、距离和对话关系，而不是堆叠形容词。
- 不要求时不要自行增加台词、旁白、背景音乐或戏剧音效。
- 提示保持内容级、供应商无关；可用字段和参考输入以当前选定工具能力为准。

## Boundaries

- 不把电影分镜、镜头参数或视觉布光当成音频控制词。
- 不在一段提示里混合互相冲突的空间、角色身份或时间顺序。
- 不用长负面清单替代清晰的主导声音与事件关系。

## Check

- 不看画面也能判断谁在何处、做了什么、情绪如何变化。
- 批准台词完整且可懂，环境与音效没有遮蔽核心信息。
- 音频的开始、转折和结束都对应明确事件，而非随机氛围堆叠。
