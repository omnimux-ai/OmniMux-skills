# 光线（Lighting）

## Activate When

- 光源、阴影、反射、冷暖、对比、曝光或氛围会改变镜头含义与主体可读性。
- 参考素材提供了可复用的光线规律，或跨镜头需要保持时间与空间连续。

## Decision Test

先找光的动机：太阳、窗、灯、屏幕、火焰、招牌或不可见但合理的场外光。若说不清光从哪里来、为什么存在，就不要继续堆“电影感”效果。

## Describe the Light

- **来源与方向**：主光从哪里来，主体和背景分别如何受光。
- **软硬与衰减**：阴影边缘、亮暗过渡和距离变化是否符合光源大小与位置。
- **对比与曝光**：哪里保留暗部，哪里允许高光溢出，关键脸部、动作或物体是否可读。
- **颜色关系**：光源与环境可以同色、冷暖对照或局部染色，但应有场景来源。
- **分离与层次**：必要时用轮廓、背景明度或局部光池分离主体，不把所有平面照得一样亮。
- **介质**：雾、尘、雨、烟、泛光或镜头光晕只在环境与情绪支持时使用，不是所有氛围镜头的必选项。

## Direction and Shape

| 选择 | 画面作用 | 使用判断 |
|---|---|---|
| 前侧柔光 | 五官与主体信息清楚，阴影过渡自然 | 日常人物、采访、温和叙事；避免无方向的正面平光 |
| 侧光 / 掠射光 | 强化体积、纹理和材质起伏 | 人物结构、织物、木石、静物特写；暗侧仍保留必要信息 |
| 逆光 / 背侧光 | 分离轮廓、表现透明边缘和空气层次 | 光源与介质确实存在时使用；脸部需要合理环境补光，不能默认黑成剪影 |
| 顶光 | 强化正午、舞台、压迫或空间高度 | 明确场景动机，并检查眼窝、鼻下与下颌阴影是否符合目标 |
| 低位光 | 制造火光、屏幕反射、异常或不安 | 只在画面内有合理低位光源时使用，不作为“高级感”默认项 |

## Intent Calibration

把抽象感受翻译成可见关系，以下是校准方向而非整段 preset：

| 目标观感 | 可见光线关系 |
|---|---|
| 温暖、亲近 | 有来源的暖侧光或窗光、柔和衰减、暗部保留少量环境冷色或中性色 |
| 清冷、孤独 | 冷环境光占主导、选择性光池、远处少量有动机的暖点，不做全屏蓝色覆膜 |
| 戏剧、悬疑 | 单一主导方向、明确明暗分界、低调曝光与可读暗部；介质只在光路需要可见时加入 |
| 清新、可信 | 大面积漫射自然光、低到中等反差、肤色和白色高光不过曝 |
| 梦幻、柔和 | 大光源、轻扩散、光源附近局部 bloom、前后景柔和分离；不能全画面失焦发白 |
| 夜景、霓虹 | 每种颜色对应真实招牌、窗、车辆或屏幕，湿地反射与空气散射服从这些光源 |
| 纪录、Vlog | 现场光逻辑优先，允许适度曝光与色温不完美，但脸部和关键动作仍可读 |

## Spatial Depth

- 前景、中景、背景至少两层应有不同明暗职责：前景可框景或压暗，中景主体通常承担主光，背景用局部光池、渐暗或空气透视建立距离。
- 主体分离优先使用有来源的亮度差、颜色差或局部轮廓，不默认添加强 rim light。
- 同一空间内，光随距离衰减；背景不能比靠近光源的主体更亮，除非画面明确是剪影或过曝窗口。
- 接触阴影、投影方向、镜面反射和透明材质中的光源位置必须互相吻合。

## Apply

- 先选择一个主导光线逻辑，再添加最少的补光或环境反射来保护信息。
- 阴影方向、接触阴影、反射内容和材质高光保持物理一致；多光源时明确各自职责。
- 光线应揭示材质：掠射光显示纹理，背侧光揭示透明与轮廓，柔光保护皮肤或细腻表面。
- 同一场景跨镜头维持时间、天气、主光方向和色彩基线；变化必须对应移动、时间流逝或叙事转折。
- 用可见结果写提示，如“窗边人物最亮、房间向深处逐渐变暗”，而非只写抽象气氛词。

## Subject Calibration

- **真人**：先保护眼神、肤色和面部结构，再决定戏剧性；皮肤高光必须局部且柔和，按需联合 `photoreal-skin.md`。
- **场景**：用门窗、灯具、天空、火焰或屏幕建立光池与空间层次；空镜也要有主导方向，不能前中后景等亮。
- **材质 / 静物**：用掠射、背侧或大面积反射光揭示表面；高光形状应反映光源形状，物体下方保留接触阴影。
- **多光源**：明确谁负责塑形、谁补暗部、谁分离背景；不同色温必须有各自来源，不能平均染满主体。

## Boundaries

- 不强制色温数值、光比、电影摄影师/影片锚点或整段 preset。
- 不要求每个镜头都有体积光、镜头光晕、反色点光或强轮廓。
- 不用复杂灯效遮盖主体漂移、材质错误或空间不连续。
- 本卡不能引入广告棚拍标准、品牌门槛或额外用户 gate。

## Check

- 光源、阴影、反射和高光能组成同一个空间。
- 主体信息可读，同时亮暗关系仍表达预期情绪。
- 相邻镜头的光线连续；有意变化时，原因能在画面或 Shot Plan 中找到。
- 画面不靠“cinematic、氛围感、高级”等词独立成立；遮掉这些标签后，仍能从光位、明暗层次、颜色来源和空间衰减执行。
- 若结果平、脏、假，先按单点修复：平面感修主次与空间层，油亮修光源大小和高光范围，剪影修脸部补光，霓虹贴片修环境反射与空气散射，阴影混乱修光源职责。
