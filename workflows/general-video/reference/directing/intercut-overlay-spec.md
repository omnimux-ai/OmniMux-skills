# Intercut and Overlay — 辅助画面编排

## Activate When

讲者、旁白或主叙事需要资料图、产品细节、操作画面、B-roll 或屏幕内容辅助理解时读取。没有辅助素材需求或主画面已经完整表达内容时不读取。

## Decision Test

| 方式 | 适用判断 |
|---|---|
| Overlay / picture-in-picture | 主体需要持续可见，辅助素材只解释一个局部信息 |
| Intercut | 辅助素材本身需要完整画幅、细节或动作空间 |
| Split screen | 两个画面需要持续比较或同步观察 |
| Full-screen main footage | 辅助内容已成为当前叙事主体，不再把它当装饰层 |

用户指定形式时直接采用。否则根据注意力中心、可读性和素材比例选择，也可以在同一视频中有理由地混用。

## Evidence Map

每段辅助素材都要绑定：

- 对应的台词、论点、动作或时间范围。
- 素材角色：证据、示范、空间建立、情绪补充或转场。
- 进入与退出的视觉理由。
- 主音轨在该段的处理。
- 素材来源与裁切安全性。

先形成素材到内容的映射，再安排时间线；不要按搜索顺序或文件名顺序铺素材。

## Visual Rules

- Overlay 放在不遮挡脸、手、产品、字幕和关键 UI 的安全区域；尺寸随画幅、素材可读性和构图调整，不使用固定像素模板。
- 图表、文字和界面以可读为先；必要时减少同屏信息、放大重点或改用 intercut。
- Intercut 期间给主画面保留足够回归时间，让观众维持与讲者或主叙事的关系。
- 单个素材停留到观众能读懂即可；快节奏也不能短到信息不可辨认。
- 相邻素材可用动作、形状、视线、色彩或声音连接；没有连接理由时用清楚的切换。

## Audio Continuity

主讲、对白或既有同步音轨通常保持连续。覆盖画面时不改变其起点、速度或时长；需要替换声音、插入停顿或重排对白时，必须在 shot plan / post work item 中明确说明，而不是由合成阶段猜测。

## Source Selection

优先使用用户素材和可验证的真实证据。搜索或生成的素材要逐项检查内容相关性、语言、授权/品牌风险、画幅裁切和水印。证据性内容不能用看似真实但未经确认的生成图替代。

## Post Work Item

为每段写清 source ref、目标时间范围、呈现方式、位置/比例意图、进入退出方式、音轨策略和预期视觉重点。执行细节由当前 postprocess capability 决定，不在 reference 中固定命令。

## Review

检查素材是否逐段对应内容、主音轨是否连续、口型同步是否保留、overlay 是否遮挡、文字是否可读、主画面是否被辅助素材淹没，以及切换是否有叙事原因。只返修失败段，不重排无关时间线。
