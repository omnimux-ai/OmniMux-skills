# Safety And Originality

Use this reference when the source is a competitor image, recognizable campaign, branded visual, model-heavy image, or any request that sounds like exact copying.

## Recreation Boundary

Allowed to migrate:

- Composition relationship.
- Information hierarchy.
- Lens and crop logic.
- Lighting mood.
- Product-to-scene relationship.
- Selling-point visualization method.
- Text-space placement.
- Batch rhythm and image roles.

Must change:

- Competitor logo, package design, slogan, typography system, campaign motif.
- Unique props that make the image identifiable as the competitor's creative.
- Specific model identity, celebrity likeness, or distinctive pose tied to a person.
- Brand-exclusive color blocking or trademarked visual devices.
- Any scene that would imply a false product capability or certification.

## Commercial Adaptation Check

Before writing the final plan, answer:

1. Which part is a reusable commercial method rather than a protected expression?
2. Which elements would make the new output look like the competitor brand?
3. Which user-product facts must override the reference image?
4. Does the recreated scene imply a result, ingredient, usage, certification, or claim the user has not provided?

## Replacement Tactics

- Replace brand-coded elements with category-neutral props.
- Change camera distance or crop while preserving the hierarchy.
- Keep the lighting family but change palette, surface, and prop set.
- Convert a specific model pose into a generic user interaction.
- Keep the before/after logic but change the visual metaphor.
