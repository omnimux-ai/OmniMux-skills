# KOC Creative Route Reference — 卖点 / 钩子 / 人设 / CTA

> Planner 编写或修改 Brief 提案的创意部分（卖点 / hook / persona / CTA）时读取，并在同一轮按本文件物化进 brief 文档。

## 卖点提炼（先决定讲什么，再决定怎么开场）

- **一条视频一个信息**：从产品事实（用户文字、refs、已批准 placeholder）中选一个主打卖点。多个卖点是多条视频的理由，不是一条视频塞满的理由。
- 卖点 → 证据形态映射：功能类卖点用**演示**（实际使用过程），效果类卖点用**对比**（前后状态），口碑类卖点用**转述**（"我朋友/评论区都说"）。选定的证据形态直接进入 shot plan 的 continuous product action。
- 卖点必须可溯源。功效、价格、规格、before/after 只能来自用户输入或 refs；见 `<workflowsDir>/koc-video/reference/product-grounding.md` 的 claim 溯源规则。

## 钩子 vs 能力（认知铁律）

| 维度 | 钩子 | 能力 |
|---|---|---|
| 是什么 | 创意角度（讲什么故事 / 什么情绪） | 生产手段（怎么拍 / 怎么生成） |
| 决定 | 前 3 秒留人 | 视频质感 |
| 冲突 | 一条视频一个钩子 | 可叠加，不冲突 |

博主风格、运镜、试穿是能力，不是钩子。

## 10 钩子决策表（A 口播 6 + B 情景 4）

> **第 5 列写「开场意图」，不要写台词。** Planner 在 Production author 时按本产品、本场景和真实语境编写逐字口播，并写入最终 prompt。不要照抄示例句式；应用 `shot-vo-craft.md` 的尬开场黑名单。
>
> **A 类 = 口播钩子**（前 3 秒"有人在说话"）；**B 类 = 情景钩子**（前 3 秒"发生一个事件"，对滑动用户更抓眼）。B 类母题源自 UGC 视觉 hook 调研，**学母题不抄演法**，演法由 agent 临场设计。

| # | 钩子 | 触发关键词 / 何时适配 | 适合产品 | 开场意图（禁照抄措辞） | 反模式 |
|---|---|---|---|---|---|
| 1 | 真香反转 | 没想到 / 起初嫌弃 / 后来真香 | 起初不被看好但用完真香（彩妆 / 食品 / 小家电） | 从一个具体的低预期状态切入，落到真实转变；用本产品的真实场景，别用"我之前一直觉得X不行"这种通用句 | 不要用"震惊 / 看完震惊"等标题党包装反转 |
| 2 | 闺蜜吐槽 | 闺蜜 / 朋友 / 同事 | 日常吐槽 / 朋友推荐视角（美妆 / 服装 / 配饰） | 以熟人视角自然带出产品（关系词可按真实语境换：朋友/同事/室友均可）；**禁止**"我闺蜜疯狂安利我""我闺蜜看到我第一句"这类套版开场 | 关系视角是形式不是台词；关系词与句式都随真实语境重写，不套固定句 |
| 3 | 无声对比 | 对比 / 之前 vs 之后 | 前后效果差异大（护肤 / 健身 / 染发） | 用画面直接呈现前后差，字幕标注变化；口播可极简或无 | 单条视频内 ≤1 次（审美疲劳，平台易判低质） |
| 4 | 教程拆解 | 教程 / 步骤 / 怎么用 | 操作有步骤感（彩妆 / 烹饪 / 工具） | 开门见山进入具体步骤，字幕标注部位/手法（参考真人 VO 的高信息密度） | 禁"10 秒教你"类标题党（跑 vo 黑名单） |
| 5 | 痛点共鸣 | 踩雷 / 避坑 / 救命 | 帮用户避坑（护肤 / 母婴 / 家居） | 说中一个具体的真实困扰（越具体越好），用本品类的真实痛点；别用"姐妹们听我说"这种通用热词开场 | 陪伴视角，不居高说教 |
| 6 | 平铺直叙 | 开箱 / 测评 / 体验 | 体验型产品，需要呈现细节（3C / 食品 / 好物） | 用一个具体的真实动作/状态切入，前 3 秒仍须显式落地，别用"今天来开箱X第一眼"套版 | 平铺不等于没钩子——前 3 秒仍须显式落地（口播第一句） |
| 7 | 意外天降（B·情景） | 产品体积小到"飞入/接住"物理可信 | 小件快消 / 彩妆 / 3C 配件 | 产品用一个意外的物理动作进入画面，制造 pattern interrupt；怎么进、博主怎么接由 agent 临场定 | 物理不可信硬做（大件产品"飞入"）显假 |
| 8 | 意外惊喜瞬间（B·情景） | 年轻向、有玩心的产品 | 趣味快消 / 潮玩 / 年轻彩妆 | 开场一个反预期的好玩瞬间，用 surprise 抓注意力再转产品；内核是 surprise 不是 fail | 不做博主翻车出丑（低质、伤品牌） |
| 9 | 荒诞反差（B·情景） | 产品能玩梗、不靠严肃信任背书 | 趣味向、话题性产品 | 正经讲解叠加一个荒诞错位元素，喜剧来自"正经 × 荒诞" | **中文默认跳过**（无厘头易显假，除非产品主打趣味）；偏英文用 |
| 10 | 街访视角（B·情景） | 产品靠"别人也说好"的社会认同 | 口碑驱动 / 爆款验证类 | 用路人真实、意外的反应替代对镜独白，建立社会认同；靠真实反应不靠脚本问答 | 中文落成探店随访/闺蜜随手拍，不做生硬"拦人问你用过吗"的假采访 |

### 匹配流程（brief 提案给用户 5 个 hook 方案选）

1. 从产品品类、用户关键词圈候选（看"适合产品 / 触发关键词"列）。
2. 用 product-grounding 默想的情绪维度过滤。
3. **给出 5 个 hook 方案**，每个一句话：钩子名 + 本产品的具体开场角度（非套版）+ 为什么贴。用户在同一对话里选，不替用户定死。
4. **多样性硬约束**：真香反转 + 痛点共鸣**合计最多占 2 个**，其余从别的钩子出；情绪基调不能 5 个雷同。
5. **B 类情景钩子最多 1 个**，且须命中该母题的"何时适配"；中文视频"荒诞反差"默认跳过。产品不适配任何情景机制 → 5 个全 A 类正常。
6. 适配的钩子不足 5 个时，宁可给 4 个真适配的，不硬凑牵强的。

## 内容形态决策

| 形态 | 选择依据 |
|---|---|
| 真人口播出镜（默认） | 需要信任背书、有人设空间、用户未排斥人脸 |
| hands-only / POV | 用户不要出镜、产品操作性强（工具 / 美食 / 开箱） |
| 纯产品展示 | 用户明确只要产品、或素材只有产品且用户拒绝生成博主 |

用户上传了模特图 = 强出镜信号；用户说"不要人"= 硬约束。未明确时按默认真人口播推荐，在 brief 提案中写为 assumption 供用户批准。

## 博主人设（真人口播形态时）

- **默认给 3 个文字候选，先文字后出图**：brief 提案里给 3 个文字 persona 候选（每个写年龄 / 身份 / 调性 + 为什么这类博主卖这个产品可信），由用户选定。人物锚图在 Assets 阶段、persona 经 Brief 拍板选定后才生成——先出图再被否是纯浪费；只推荐 1 个则用户无从比较，选择会被静默略过。
- 人设-品类-转化匹配由 planner 按产品品类、推断人群、平台调性自行判断（例：高客单香薰 → 都市轻熟女比元气大学生可信），不外挂调研。
- **3 维风格匹配**：平台（小红书偏暖调治愈真实 / 抖音偏快节奏搞笑反转）× 人群（职场女性偏知性 / 学生偏元气 / 妈妈偏实用）× 情绪（治愈 → 自然光慢节奏 / 兴奋 → 高饱和快切）。
- **不列具体博主名**（时效 + 侵权）。persona 候选与产品/人群匹配置信度低、或用户对 3 个候选都不满意时，反问用户要一个参考账号/视频作为锚定，禁止临场胡编风格名。
- **上传模特图不静默短路选择**：用户上传的模特图是强人设信号，但必须在 brief 提案写明 assumption「此图作为出镜博主锚」随 hook 一起经用户确认后，才跳过 persona 候选、只做锚点登记（见 product-grounding）——该图可能只是风格参考或产品合照。

## CTA 收尾

- CTA 语气必须顺着前文情绪自然收（软引导），不从松弛分享跳到叫卖腔——这是 VO 四铁律之一（见 shot-vo-craft）。
- CTA 形态跟平台转化路径：小红书 → 引导评论区 / 搜索关键词 / 收藏；抖音 → 挂车 / 左下角链接口播提一句。用户给了明确 CTA 文案就逐字用，没给就按平台默认软收尾，写进 brief 供确认。
- CTA 出现在尾镜，不抢前 3 秒。

## Anti-patterns

- 跳过卖点提炼直接选钩子（不知道"讲什么"就决定"怎么开场"）。
- 一条视频塞多个卖点 / 多个钩子。
- 把博主风格 / 运镜 / 试穿列为钩子选项。
- 钩子与品类或推断人群错配（食品硬用教程拆解、男性向产品用闺蜜吐槽）。
- 用户已选定钩子后继续生成平行钩子版本。
- 真人出镜时只推荐 1 个 persona 不给候选。
- 上传模特图未经 brief assumption 确认就直接登记为出镜博主锚。
