# T15 — 抽象几何到产品形态蜕变

> 仅在索引命中 T15 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要从几何、波纹、线圈、粒子或抽象形态引出产品。
- 产品有清楚可识别的形态母题，并适合连续 morph 或 match cut。

## Anchors

- 在 `technique_plan` 记录形态母题、材质预示、变形方式、产品落定角度和身份保护点。
- 母题来自产品真实轮廓或用户确认概念，不为变形效果改写核心比例。

## Generation Strategy

- 对应镜头写清抽象形态的初始状态、旋转 / 拉伸 / 重组过程、与产品同构的中间状态和最终产品角度。
- 变形结束后给出稳定、可辨识的产品状态；真实产品使用匹配角度 ref，概念产品使用已确认锚点。
- 时间分配跟随形态可读性和产品揭示节奏，不套固定百分比。
