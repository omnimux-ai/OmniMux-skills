# Era & Identity Guard — 时代、地域与身份连续性

## Activate When

时代、地域、职业、社会身份或技术水平会改变人物、场景、服装、道具和声音设计时读取。现代中性场景、纯抽象视频或用户明确允许自由混搭时跳过。

## Decision Test

- 优先使用用户明示、source 文档、可见参考和已批准 brief；不要凭姓名或宽泛文化标签推断精确身份。
- “复古”“古代”“未来”“东方”等词可能对应多个视觉世界；若不同解释会改变核心设计，先确认时代切片、地域或媒介来源。
- 区分连续性与创作混搭：意外穿帮需要修复；用户批准的架空、拼贴、anachronism 或跨文化融合是设计选择，应被记录并保留。
- 社会身份只约束可见且相关的设计事实。不要用僵化阶层表、族群刻板印象或未经 source 支持的消费符号代替角色塑造。

## Action

为项目建立紧凑 world lock：

| Field | Evidence |
|---|---|
| Era / time slice | 朝代、年代、近未来跨度或架空规则 |
| Region / culture | 地域、气候、建筑与语言环境 |
| Technology / materials | 可出现的交通、通信、制造与材料水平 |
| Social identity | 职业、生活条件、制度身份中会影响画面的部分 |
| Deliberate exceptions | 用户批准的混搭、伪装、落难、梦境或超现实偏离 |

把 world lock 转成正向、具体的可见事实：

- 人物：服装轮廓、面料、发型、装备和使用痕迹；
- 场景：建筑结构、固定设施、照明来源、植被与公共基础设施；
- 物件：材料、工艺、磨损、使用方式和持有者关系；
- 镜头连续性：同一人物 / 地点跨 shot 保持同一 world lock，除非 source 明确发生变化。

只为真实风险写少量 block 条件；通常用目标时代的具体元素比通用禁止清单更有效。无法确认的历史细节保持概括或查证，不要编造精确年代事实。

## Review

检查显著物件、服饰、建筑、技术、气候与角色身份是否互相自洽；检查偏离是否来自 source 或用户批准；检查同一地点 / 状态是否跨镜无理由跳变。发现问题时只修受影响的 anchor 或 work item。

## Boundary

- 时代词歧义由 era-disambiguation failure card 处理，文化标签歧义由 cultural-stereotypes failure card 处理。
- 本文件不建立新的 core anchor kind，不维护历史禁物穷举、固定 prompt 模板、模型路由或 workflow gate。
