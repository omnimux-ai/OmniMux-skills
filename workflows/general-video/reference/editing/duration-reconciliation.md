# 时长对齐（Duration Reconciliation）

## Activate When

- 实测素材、配音、音乐或当前粗剪时长与交付目标不一致。
- Shot Plan 的预计时长与已生成片段出现偏差，需要决定局部修正还是重排结构。

## Decision Test

只基于实测时长决策，不根据提示词、标称时长或文件名猜测。先确认目标是硬上限、近似范围，还是仅供创作参考。

## Priority

按以下顺序保护内容：

1. 用户明确要求的事实、对白、语言和关键动作完整性。
2. 故事因果、解释顺序和情绪落点。
3. 可感知的节奏与观看舒适度。
4. 次要装饰、重复信息和可替代的氛围余量。

## Apply

- 偏差轻微时，先调整镜头 hold、反应余韵、空镜、音乐起落点或无信息冗余。
- 需要缩短时，优先删重复意义、迟到的动作尾巴和无贡献的建立镜头；不要截断句子或动作结果。
- 需要延长时，优先补有新作用的反应、过程、证据或环境观察；不要均匀拉慢所有片段。
- 对白或旁白决定时长时，以自然朗读和可懂度为下限，让画面适配语言，而不是压坏语言来迁就画面。
- 若缺口意味着缺少一个因果环节、解释步骤或场景，回到 Shot Plan 增补或重组 clip group，再生成所需素材。
- 在 Post 工作项中记录目标、实测总长、差值来源和选定操作，避免多轮局部修正互相抵消。

## Boundaries

- 不用统一倍速、统一裁尾或固定比例公式处理全部镜头。
- 不把明显的结构缺口伪装成转场、黑场或循环。
- 不为精确命中一个非硬性数字破坏自然结尾。
- 最终合并和时长测量服从共享视频合并规范与当前工具返回值。

## Check

- 最终时长满足真实交付约束，且误差来源可解释。
- 关键对白、动作、证据和结尾均完整。
- 连续观看没有可感知的赶速、拖沓或重复填充。
