# 发音与读法（Pronunciation）

## Activate When

- 文本含人名、地名、品牌、专业术语、缩写、数字、单位、多音字或跨语言片段。
- 试听发现发音、重音、断句或语义停顿不自然。

## Decision Test

区分一次性修正与项目级规则：只出现一次且无复用价值的词做局部提示；跨多句、多角色或多版本反复出现的词进入项目词典。

## Apply

- 先按上下文确认词义、语言和目标读法，不凭拼写猜专名。
- 读法涉及真实身份、品牌或事实且存在歧义时，再向用户确认；普通表达问题可自主选择最自然方案。
- 数字、日期、缩写和单位按语义改写为适合朗读的形式，同时保留原始含义。
- 使用标点、分句和自然措辞控制停顿；只有当前工具明确支持时，才使用其发音或音素提示能力。
- 多语言句子先决定语言切换边界和口音归属，避免每个外来词都导致整句音色漂移。
- 每次修改后试听完整句和相邻句，确认局部正确没有破坏语气与节奏。

## Project Glossary

项目级词典至少记录：

- 原词与适用语言。
- 目标读法或可听辨的近似说明。
- 重音、连读或停顿要求。
- 适用角色，以及是否允许不同角色有自然差异。
- 已试听通过的证据或仍待确认的不确定点。

## Boundaries

- 不假设固定标记语法在所有语音工具上都有效。
- 不用字符拉长、重复标点或大段拼音墙粗暴控制表演。
- 不为“标准”抹掉角色合理的地域、年龄或情绪特征。

## Check

- 专名、数字和关键信息第一次听就能理解。
- 停顿服务句义，没有逐字朗读或错误重音。
- 相同术语在项目内一致，同时保留角色自然度。
