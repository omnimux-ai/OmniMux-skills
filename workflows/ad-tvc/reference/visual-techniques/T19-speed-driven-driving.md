# T19 — 高速推进与速度感驾驶

> 仅在索引命中 T19 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要行驶、加速、过弯、超车、追逐或连续前向动能。
- 速度感来自真实道路、车辆与环境反馈，而不是随机抖动或无依据的性能宣称。

## Anchors

- 在 `technique_plan` 记录车型与漆色、道路 / 天气、行驶方向、主相机轨迹、速度节点和结束状态。
- 动力、安全、续航、智驾与制动只使用 verified 事实；路线决定是否需要外观、内饰或驾驶员锚点。

## Generation Strategy

- 每个驾驶单元写清起始位置、车辆动作、相机主轴、环境后退 / 掠过、轮胎或风压反馈和可读的结束状态。
- 连续行驶单元保留车辆朝向、道路侧、光线、速度趋势和需要的前段尾帧；方向或场景改变时按自然事件边界分开。
- 声音匹配动力类型和路况，视频 Prompt 不写独立 BGM；镜头数量和驾驶占比由用户方向、总时长与路线判断。
