# 使用说明

本能力包用于把参考视频里的有效结构，改写成用户自己产品、品牌或主题的原创视频方案。重点不是模仿表面风格，而是先看清参考视频为什么有效，再决定哪些结构值得迁移。

## 适用场景

- 用户已经有参考视频，想改成适合自己商品的版本。
- 用户要先判断参考视频和商品是否适配，再决定是否值得做高保真改编。
- 用户需要一份可继续交给脚本、分镜或提示词环节的原创方案。

## 最小输入

至少需要两类信息：

- 一份参考证据：视频、关键帧、转写、脚本摘要，或可验证的用户描述。
- 一份目标信息：商品/主题、核心卖点、目标受众，外加不能说的限制项。

补充以下信息会让结果更稳：

- 目标平台、市场、时长、画幅和风格偏好。
- 参考视频里最想借鉴和最不想借鉴的部分。
- 商品图片、详情页、典型使用场景或现有脚本。

## 标准工作顺序

1. 先判断证据等级。
2. 拆参考视频的 hook、节奏、卖点顺序、证明方式和 CTA。
3. 看这些结构能否映射到用户商品或主题。
4. 给出 A/B/C/D 适配等级。
5. 输出原创脚本方向、分镜骨架、提示词包或交付建议。

## 适配等级建议

- `A`：大结构可以保留，主要改写人物、品牌、文案和场景细节。
- `B`：保留 hook、节奏或 CTA 机制，中段演示要明显重写。
- `C`：只借鉴局部注意力机制，主体逻辑应按商品重新搭建。
- `D`：参考方向不值得继续沿用，应改找更合适的结构。

## 交付建议

按用户目标选择输出重点：

- 只要判断值不值得复刻：给结构拆解 + 适配等级 + 风险清单。
- 要进入创作：给原创脚本方向 + 分镜骨架 + 可替换元素说明。
- 要进入提示词环节：给完整提示词包，并写清禁止复用和主张边界。

## 使用提醒

- 不要把“像原视频”当成成功标准，真正的成功是“更适合用户自己的商品表达”。
- 若参考视频高度依赖特定人物、品牌或强识别画面，优先缩小借鉴范围。
- 若证据只有链接或模糊摘要，先标注限制，再给方向建议，不把猜测写成事实。
