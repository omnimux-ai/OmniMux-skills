# 材质与质感（Materials）

## Activate When

- 玻璃、液体、金属、皮肤、织物、木材、食物或其它表面质感影响真实感、叙事或主体识别。
- 多种材质接触、磨损、变形或受环境影响，是镜头的重要信息。

## Decision Test

先确认材质是否需要被观众看懂。若它只是远景背景，不必堆微观细节；若动作、特写或剧情依赖它，则描述决定其行为的可见属性。

## Material Description

- **身份与尺度**：是什么材料，纹理颗粒相对物体有多大，硬/软、干/湿、透明/不透明到什么程度。
- **表面结构**：光滑、粗糙、拉丝、织纹、毛孔、划痕、气泡、裂纹、纤维或自然不规则。
- **光学行为**：反射环境、透光、折射、吸收、散射或柔和高光；只写该材质真正相关的行为。
- **使用历史**：新、旧、手作、磨损、沾染或被触碰的痕迹，与项目调性匹配。
- **环境交互**：风、雨、温度、重力、压力和动作如何改变表面。
- **接触关系**：材质相遇处的压痕、黏附、渗透、滴落、投影、反射或形变，避免硬贴片边界。

## Material Calibration

| 材质 | 最少要看清什么 | 常见假感与修法 |
|---|---|---|
| 玻璃 / 透明物 | 厚度、边缘高光、背景折射、内部结构和投影 | 像透明塑料贴片：补边缘厚度、环境反射和折射后的背景变化，不靠全身白描边 |
| 金属 | 粗糙度、拉丝/抛光方向、环境反射和边缘磨损 | 像灰色塑料：让高光形状对应光源，让反射内容来自当前环境 |
| 织物 / 皮革 | 纤维尺度、褶皱方向、受力、缝线和不同区域的光泽 | 像硬壳：补重力、压痕、弯折与接触处的软硬变化 |
| 木、石、纸 | 纹理尺度、天然不规则、切面/边缘和使用痕迹 | 像重复贴图：打破等距重复，让纹理随结构、切面和磨损变化 |
| 液体 / 湿润表面 | 黏度、液位、重力方向、边缘张力、反射与流动速度 | 像随机水珠：先说明温度、天气、动作或容器关系，没有依据不加凝水 |
| 食物 | 湿润度、孔隙、纤维、焦化、切面和多材质接触 | 像蜡或玩具：按新鲜度与烹饪状态选少量差异，不把所有表面统一提亮 |
| 皮肤 | 景别对应的微纹理、局部透光、肤色差异和有限高光 | 真人写实转到 `photoreal-skin.md`；不能用普通塑料/橡胶高光处理 |

## Lived-in Realism

- 写实不等于堆瑕疵。只加入与使用历史和当前状态吻合的轻微不完美，如触摸痕、折痕、边缘磨损、局部灰尘、自然不对称或含水量差异。
- 洁净、高端或设计化不等于无物理细节：仍要保留边缘、接触阴影、材料粗糙度差和真实反射，只减少随机磨损。
- 同一物体上不同材料必须可区分，例如玻璃、金属盖、纸标签和液体不能共享同一高光宽度与反射强度。
- 微观纹理只在镜头可见时写；远景优先轮廓、明暗和大尺度材质差，避免细节密度与景别冲突。

## Apply

- 选择少量最能区分该材质的特征，并让光线方向揭示它们。
- 透明物关注厚度、边缘、内部结构、背景变形与投影；不必为每个透明物套同一细节清单。
- 湿润、凝水、油光或露珠必须有温度、食物状态、天气或用户要求作为依据；包装和干燥物体不默认加水珠。
- 写实生活场景可以保留适度不完美，高度洁净或设计化场景则减少磨损；由 brief 决定，不套商业类别规则。
- 连续镜头保持材质的湿度、破损、污渍、液位和受力状态。

## Boundaries

- 不强制物理渲染参数、固定光学数值或产品摄影配方。
- 不把“更多高光”当成解决塑料感的通用办法。
- 不用长负面清单追求真实；优先写正确表面、尺度、光线和交互。
- 本卡不能把普通视频任务升级为产品广告或品牌 KV 流程。

## Check

- 不看物体名称，仅凭表面与受光也能大致辨认材质。
- 多材质接触处有合理形变、阴影或流动关系。
- 跨镜头的磨损、湿度、反射环境和物理状态一致。
- 高光、纹理、变形和使用痕迹各自有物理或叙事来源，不像统一滤镜或随机装饰。
- 过于光滑时先补尺度正确的表面和接触关系；过于脏乱时删掉无依据瑕疵，而不是整体磨皮或降细节。
