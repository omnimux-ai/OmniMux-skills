# T16 — 液体声波与悬浮声学隐喻

> 仅在索引命中 T16 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要用涟漪、液体、悬浮或声波场表达声音、降噪、轻盈或流体质地。
- 隐喻与产品功能或品牌表达有关，并有 verified 事实支撑功能宣称。

## Anchors

- 在 `technique_plan` 记录产品与液面 / 声波场的关系、触发动作、涟漪形态、光线、材质和隐喻含义。
- 产品身份与液体材质分别锚定，避免效果遮挡关键结构或 Logo。

## Generation Strategy

- 对应镜头写清悬浮 / 接近 / 落点动作、液面反馈、同心涟漪扩散、相机跟随和结束状态。
- 运动体现加速、接触、余波等可见因果；若没有已锁定节拍，只写相对节奏和动作 SFX，不承诺与未知 BGM 精确卡点。
- BGM 仍由 Audio / Post 处理，Post 不为该技法重新变速视频。
