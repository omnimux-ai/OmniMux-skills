# 戏剧性停顿（Dramatic Pause）

## Activate When

- 镜头需要让观众消化信息、等待反应、感受反转，或明确跨入下一章节。
- Shot Plan 或 Post 正在判断一个留白、定格、空镜、近静默或黑场是否有叙事价值。

## Decision Test

先问：删掉这段停顿后，情绪、理解或转折是否明显变弱？若只是总时长不足，不启用本卡。

停顿通常承担一种主要功能：

- **呼吸**：密集信息后给理解留空间。
- **悬念**：推迟答案，让观众主动期待。
- **反应**：保留人物、环境或物体对上一动作的余波。
- **转折**：让前后两段的意义发生碰撞。
- **章节边界**：明确时间、地点、观点或情绪已切换。

## Apply

- 优先利用已有表演尾韵、动作完成后的 hold、环境声或反应镜头，而不是人工插入空白。
- 根据对白语义、表演节奏、音乐乐句和前后镜头能量决定长度；不套固定秒数。
- 黑场只在“缺席本身”有意义、章节真正断开或结尾需要回响时使用。
- 声音可以先于画面进入或延后离开，让停顿保持世界连续，而非机械静音。
- 若停顿改变了镜头组结构，在 Shot Plan 中先写清前因、停顿载体和后果；若仅是成片微调，可在 Post 局部处理。

## Boundaries

- 不用黑帧、慢放或定格补足目标时长。
- 不在每个句号、每次转场或每个音乐拍点都制造停顿。
- 不牺牲对白完整性、动作落点或关键视觉信息来换取“氛围感”。
- 具体时线操作服从共享视频合并规范和当前工具能力。

## Check

- 停顿前有可感知的蓄力，停顿后有信息、情绪或方向变化。
- 连续观看时它像一次有意的呼吸，而不是卡顿、素材不足或误剪。
- 声画进入和退出都没有突兀断裂。
