# AI 换装提示设计指南

## 目标

一份好的换装提示，不是把形容词堆满，而是把“保留什么、替换什么、怎么拍、哪些地方不能乱动”说清楚。

## 推荐结构

按下面顺序组织提示：

1. 任务目标
2. 人物保持要求
3. 服装还原要求
4. 场景与镜头
5. 商业或内容用途
6. 负向约束
7. 需要人工复核的假设

## 人物保持

优先写清楚这些点：

- 面部结构
- 发型和发色
- 肤色与年龄感
- 体态比例
- 手部和姿势
- 是否保留背景

## 服装还原

尽量写成可检查的事实：

- 品类
- 颜色
- 材质
- 廓形
- 长度
- 领口、袖口、门襟、腰线、下摆
- 图案、刺绣、纽扣、拉链等关键细节

看不见的部分不要写成确定事实，只能标注为“合理补全”。

## 常见错误

- 把“换装”写成“换人”。
- 同时要求保留原背景又换成全新场景。
- 要求保持服装原色，又同时指定完全不同的颜色。
- 把品牌元素、代言意味或夸大卖点写成默认目标。

## 负向约束建议

常见负向约束可覆盖：

- 不要改变人物身份。
- 不要新增多余肢体。
- 不要错误服装结构。
- 不要扭曲手部或肩颈连接。
- 不要错误文字、图案或 logo。
- 不要把效果图写成真实试穿证明。
