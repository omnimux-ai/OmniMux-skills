# Storyboard Discipline — 分镜与 Shot Plan

## Activate When

视频由 brief、脚本、讲解结构、参考视频或多个素材发展为多个 shot / clip group，需要把内容物化成可执行 shot-plan 文档时读取。用户已有合格 shot plan 时只补缺失字段，不从头重写。

## Decision Test

先判断规划粒度：

- Shot：一个主要视点或独立视觉动作。
- Beat：同一 shot/clip 内的信息、动作或表演变化。
- Clip group：可由一次生成连续承载的相邻 beats。
- Sequence：跨多个 clips 形成的完整段落。

粒度由内容、refs 和当前 vendor 能力决定，不预设逐镜生成，也不要求先有文学剧本；brief、教程步骤、采访提纲和用户 storyboard 都可以成为来源。

## Suggested Document Shape

| 字段 | 作用 |
|---|---|
| id / source range | 追溯到脚本、brief 或用户素材 |
| purpose | 本项带来的叙事、信息或情绪变化 |
| duration intent | 目标时长与节奏理由 |
| visible action | 主体、动作过程、空间与结果 |
| camera / viewpoint | 景别、视点、运动和切换理由 |
| dialogue / audio | 原文、说话者、旁白、环境声或音乐意图 |
| refs / anchors | 当前项实际使用的媒体来源 |
| continuity | start state、end state 与相邻项关系 |
| text overlay | 仅记录用户要求的字幕、标题或画面文字 |

可按项目删减或增加列，不要求固定表头。

## Writing Actions

- 每个镜头开头明确主体和当前状态；多人场景写清谁发起动作、谁回应。
- 抽象意图转成可见行为、构图、光线变化或声音事件。
- 关键道具写操作过程与前后位置，不让它在相邻镜头中突然出现或消失。
- 重要发现、选择或笑点可拆成触发、反应、后果；节奏需要克制时也可留在一个连续镜头中。
- 对白与动作相互对应；长句可以用听者反应、相关动作或环境细节承载声音连续。
- 转场写前一状态如何结束、何种证据连接、后一状态如何开始；无特殊理由时清楚切换即可。
- 用户已有参考节奏时提炼其长短、景别和运动规律，再针对本内容重组，不逐镜复刻。

## Narrative Scale Design

先为每个关键 beat 定义镜头目的，再决定景别：

- **建立**：空间、路径或多人关系优先远景、全景或中景。
- **推进**：人物之间的行动、阻隔与关系变化按可读动作选择中景、中近景或关系镜头。
- **落点**：情绪转折、确认、犹豫、发现、告别与结果余韵优先近景、特写或局部特写。
- **细节**：关键物件、触碰、视线和状态变化优先局部特写。

同一连续段落先保证建立与行动可读，再把关键情绪或信息落点拉近。中景只承担需要同时看清人物关系、动作路径和空间关系的 beat，不替代情绪或细节镜头。

## Grouping

优先把同地点、同主体、动作连续、refs 兼容且声音意图一致的 beats 合成 continuity-first clip group。场景/时间硬切、refs 不兼容、刻意蒙太奇或能力溢出时拆组。分组后仍保留组内 beats，避免把内容压成一句模糊概述。

## Continuity Ledger

跨项追踪人物位置与朝向、表情/身体状态、服装、伤痕、道具、场景光线、天气、时间、正在持续的声音和未完成动作。主动变化写出触发原因；无原因的变化视为需要修正的漂移。

## Review

依次检查：每项是否有唯一目的；关键 beat 是否已按建立、推进、落点或细节分配镜头目的；情绪和信息落点是否拥有与其重要性匹配的近景或特写；中景是否具有明确的关系、行动或空间职责；摄影机是否能拍到描述内容；切换是否带来新信息；对白是否完整；时长是否容纳动作；refs 是否与内容匹配；前后状态是否连续。发现过载时先合并重复信息或拆出冲突 beat，不增加无关 gate。
