# T18 — 物理动力学卡点

> 仅在索引命中 T18 时读取。`anchors` 使用“Anchors”，`storyboard` 使用“Generation Strategy”；Stage 被跳过时对应内容不生效。

## 适用信号

- 用户需要用弹跳、碰撞、旋转、合盖、落点、灯光点亮或 SKU 切换建立节奏。
- 每个卡点都有真实物理事件，而不是仅靠随机快切。

## Anchors

- 在 `technique_plan` 记录动作主体、蓄力、事件点、余波、切换对象和可用声音线索。
- 如用户已提供 BGM 或 beat map，登记可对齐的时间点；没有时只记录相对节奏。

## Generation Strategy

- 对应镜头写清发起者、方向、速度、接触 / 位移、事件点和结束状态，让动作具有可见惯性。
- 已锁定节拍时可把事件点写入时间范围；未锁定时以动作节奏和 SFX 完成，不依赖后续 BGM 精确吸附。
- Post 保持视频原始速度与事件位置，只负责既定拼接和混音。
