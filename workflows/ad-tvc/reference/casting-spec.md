# Casting Spec — 品牌片选角规格

## 触发场景

**触发条件**：
- 品牌形象片选角方向规划
- 分镜脚本中的角色设定

## 一、选角维度表

品牌片选角需要从以下维度全面定义：

| 维度 | 内容 | 必须明确 |
|------|------|---------|
| **年龄** | 具体年龄段（如 28-35），不写"年轻" | 年龄影响品牌受众认同感 |
| **身份** | 真实从业者 vs 演员 | 品牌片偏好真实从业者——"能看出被运动/工作塑造过的身体" |
| **族裔 / 地域呈现** | 与投放地区和目标受众一致 | 不按语言、场景或品牌调性猜测；多地区投放明确各地区代表性 |
| **体态** | 身高/体型/肌肉线条/肤色/手部特征 | 与品牌调性直接相关的身体细节 |
| **气质** | 沉稳/温暖/冷静/野性/知性/克制 | 用具体的行为举止描述，不用形容词 |
| **服装** | 品牌服装+日常搭配规范 | 必须与品牌调性一致 |
| **禁区** | 不能出现的类型/姿态/表演方式 | 红线清单 |

## 二、品牌匹配度校验规则

### 2.1 气质-品牌对齐

选角气质必须回溯到实际 Brief 或已接纳脚本 / 分镜 source 中已确认的品牌性格关键词：

| 品牌性格 | 选角气质方向 | 禁止方向 |
|---------|------------|---------|
| 克制/内敛 | 眼神平静、动作幅度小、面部表情少 | 夸张表演、大笑、摆拍姿态 |
| 匠人感 | 手部有使用痕迹、专注时微微皱眉 | 光滑的手、空洞的眼神 |
| 野性/自由 | 不修边幅但不邋遢、被日晒的皮肤 | 精致妆容、城市白领感 |
| 温暖/亲和 | 自然微笑、放松的肢体 | 冷漠疏离、紧绷表演 |
| 专业/权威 | 姿态挺拔、目光稳定 | 萎靡、犹豫的姿态 |

### 2.2 身份真实性优先

品牌形象片的选角黄金法则：**优先选择真实从业者，其次是能让人相信他是从业者的演员**。

判断标准：
- 手部——是否有长期从事该活动的使用痕迹
- 肌肉——是否有专项运动塑造的线条（不是健身房肌肉）
- 皮肤——是否有户外活动的日晒痕迹
- 眼神——是否有对所做事情的自然熟悉感

### 2.3 人数与关系

| 类型 | 适用 | 注意 |
|------|------|------|
| 单人 | 内心叙事、个人成长 | 不等于孤独，可以有环境中的"他人" |
| 双人 | 关系/对话/传承 | 两人之间的关系必须可信 |
| 群像 | 社群/多元/力量 | 每个人的特征需有差异化 |
| 无人 | 纯物/环境/意象 | 通过物品暗示人的存在 |

### 2.4 投放地区对齐

- `generated_virtual_model` 必须同时依据投放地区与目标受众确定族裔 / 地域呈现；单一市场使用当地受众可自然认同的人物，多地区或多族群市场明确各人物的代表关系。
- 投放地区或受众范围不足以确定选角时，返回来源缺口，不根据旁白语言、拍摄场景、品牌来源或刻板印象自行推断。
- `user_model_reference` 保持用户人物的真实身份与族裔呈现；若它与明确的投放要求冲突，先向用户说明并确认保留该人物或改用其他模特，不通过图像生成改变其族裔。

## 四、常见选角禁区（品牌片通用）

- 模特式摆拍姿态
- 过度精致的妆容（除非品牌调性要求）
- 空洞/无内容的"好看"
- 与品牌受众年龄差距过大
- 人物族裔 / 地域呈现与投放地区或目标受众无依据地错位
- 体态/气质与品牌性格矛盾
- 刻意"表演"某种情绪（品牌片要的是自然流露）
