# TVC Direction 索引

只根据 Intake 已确认的广告方向选择一张卡，不通读本目录。`visual-research` Stage 使用 `creative-research` section；Anchors 与 Storyboard 只应用各自同名 section。

| 用户目标 | Direction | 路径 |
|---|---|---|
| 建立品牌价值、情绪或长期认知 | `brand-ad` | `<workflowsDir>/ad-tvc/direction/brand-ad.md` |
| 展示产品外观、材质、功能或卖点 | `product-ad` | `<workflowsDir>/ad-tvc/direction/product-ad.md` |
| 用人物 / 主体变化讲完整故事 | `story-ad` | `<workflowsDir>/ad-tvc/direction/story-ad.md` |
| 以反转、爆点或可分享事件传播 | `viral-ad` | `<workflowsDir>/ad-tvc/direction/viral-ad.md` |

用户已明确方向时直接命中；只有目标互相冲突且会改变成片结构时才交给用户选择。
