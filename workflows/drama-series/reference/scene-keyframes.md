# 场景关键帧宫格参考

> 当 `drama-series` 规划 `scene-keyframes` 阶段时读取：把每个已确认镜头组转换为一张分镜宫格图，预先构图其 clip 后续要生成的镜头。**1 组 = 1 宫格 = 1 clip**，宫格数量与已确认镜头组和 Visual Gen clip 1:1 对齐。

## 目标与范围

`bw_blockout` 使用黑白 2×4 八格 16:9；`full_color` 使用真彩 3×3 九格 1:1。宫格只规划景别、站位、镜头投影和动作顺序，不进入最终视频画面。

- 角色/场景/道具锚点锁定身份和空间；宫格锁定一个镜头组内每个 beat 的构图、画面左右、景别和连续动作。
- 宫格 Prompt 的唯一结构来源是下方“唯一可执行填空骨架”。分镜列表、站位记忆、资产 refs 和风格锁只提供变量，不提供另一套宫格 Prompt 结构。
- Planner 必须复制完整骨架，再按 8 格或 9 格逐格填空；不能只写首格后用“同上”、摘要或上一张宫格补齐其他格。
- 缺少镜头行、起始快照、目标末态、可见角色或真实 refs 时先补来源并返回 `stage_blocked`，不能猜测或减少格子。

## Questions

Storyboard 审阅完成且宫格范围缺失时，调用一次 `question`；每项使用独立 question 对象，推荐项放第一位。范围不是 `skip` 且样式缺失时再调用一次样式 question；已有值不重复询问。

| 问询项 | 选项 | 结果写入 |
|---|---|---|
| 宫格范围 | 跳过宫格（推荐：省钱、省时间，适合快速生成和验证）/ 仅关键镜头组（为冲突、反转、高潮等重点镜头提供更强构图约束，成本和耗时适中）/ 全部镜头组（为每个镜头提供最强构图约束，但成本和耗时最高） | `stage_fields.keyframe_scope` |
| 宫格样式 | 黑白八宫格（推荐）/ 彩色九宫格 | `stage_fields.storyboard_style` |

选择“跳过宫格”时两个字段均写 `skip`，省钱且更快，省略 Scene Keyframes Stage，不进行二轮样式问询；选择“仅关键镜头组”时覆盖冲突、反转、hook 和 payoff 镜头组；选择“全部镜头组”时覆盖全部已确认镜头组。

## 宫格风格与输入 refs

| 槽位 | A `bw_blockout`（推荐） | B `full_color` |
|---|---|---|
| 观感 | 黑白火柴人构图稿：简化头部、单线肢体、概括躯干；白底，浅灰块表示纵深；用发型、头饰、服装外轮廓、身高体型和标志性道具区分角色 | 真彩成片风格；Mode A 保持写实身份，Mode B 保持制作计划锁定的漫画画风、线条、色彩和材质 |
| 布局 | 2×4 = 8 格，16:9 横版 | 3×3 = 9 格，1:1 方版 |
| 阅读顺序 | 从左到右、从上到下：1/2/3/4 → 5/6/7/8 | 从左到右、从上到下：1/2/3 → 4/5/6 → 7/8/9 |
| 固定风格行 | `生成一张16:9横版2×4八宫格黑白火柴人分镜构图稿。人物由简化头部、单线肢体和概括躯干构成；用发型、头饰、服装外轮廓、身高体型和标志性道具轮廓区分角色。纯白背景、黑色线条，浅灰色块只表示前中后景和场景锚物，不渲染真实五官、皮肤纹理、布料材质或摄影光影。` | `生成一张1:1真彩成片风格3×3九宫格构图参考，按制作计划的风格锚点、角色锚点和场景锚点保持身份、光影、画风。` |
| 禁用 | 写实真人、黑白照片风、photoreal 真人质感 | Mode B 禁用 photoreal、cinematic photo、大光圈浅景深等实拍词 |

模式 A 必须逐字使用黑白风格行；模式 B 必须逐字继承 Medium lock。Mode B 的 Medium lock 为按参考图/用户描述统一画风时，风格参考图放入真实 refs，并在骨架开头写 `Style reference = 图N。参考图只用于画风、线条、明暗、材质和构图节奏,不要复制参考图主体。`。宫格自身不能渲染分隔线、网格、草图感或火柴人观感到最终 clip。

每个 work item 只绑定一个已确认镜头组：`scene_id` 标明场景，`source_scene_range` 标明镜头组，稳定输出 id 与 Visual Gen 使用相同的 clip/group id。refs 按真实顺序排列：Mode B 风格图（如适用）→ 当前状态角色和 on-scene witness → 本组场景 → 本组可见道具/状态。不能传入未出现角色、其他地点场景或互斥状态卡；text-only role 直接在格子 prose 写类型、数量、服装、位置和动作，不编造无路径 ref。

## 唯一可执行填空骨架

```text

图1 = <按真实 refs 顺序的第一个角色 / 风格 / 场景 / 道具参考>，锁定<身份、状态或空间属性>
```

## 骨架填空知识与连续性

1. `图N` 必须与实际 refs 顺序一致；已有角色、场景和状态资产要真实可解析。黑白模式只提取身份、服装/道具外轮廓、身高体型和标志性轮廓，不继承真人五官、皮肤材质或摄影光影。
2. 起始快照、变化和目标末态来自站位记忆；没有站位记忆的简单静态场景才从分镜 blocking 填写。量化坐标翻译为具体锚物和相对位置，不写“主锚”、坐标、指南针或“保持不变”。
3. 镜头行逐格保留来源中的景别、角度和运镜意图：低机位、俯拍、仰拍、跟拍、手持、OTS 和 POV 不能只剩景别名称。OTS 写前景左右肩、目标、目标景别、目标原位置和可辨背景；POV 写视点属于谁。
4. 每格的 `画面` 写动作阶段、情绪/微表情、嘴型但不写对白原文、视线和听者反应；每格的 `站位` 写所有可见角色和旁观者，即使某人暂时在画外也要说明其具体原位。
5. 从本组镜头计划分配格子：1 镜头时在起手、早中、关键、末态和余韵之间展开；2～4 镜头时每个来源镜头都必须得到起/中/关键/末的代表格；5～7 镜头时每镜至少保留关键瞬间，其余格给戏剧最强镜头的起/中/末。不能跨组借用，也不能多画或少画。
6. 宫格按从左到右、从上到下构成一个连续镜头序列，相邻格的景别或角度变化必须有来源依据；第1格对应起始快照，最后一格对应目标末态。
7. 同一场景第二张及之后的宫格：新宫格第1格逐项等于上一组末态，构图拉开至少一级景别或约 30° 机位角度，并选择景别跨档、OTS、视点转移或局部特写；改变画面投影不改变角色世界位置。跨场景重新读取新场景快照。
8. 宫格作为 clip reference 时只传本镜头组自己的 grid，不能传其他组；grid 只指导动作、空间、景别和顺序，不能替代 clip 的角色/场景锚点或连续性 prose。

## 宫格定稿检查

- 固定风格行、`What to generate`、refs、【场景与站位】、【8格内容 / 9格内容】和【画面要求】顺序不变。
- 黑白正好 8 格，真彩正好 9 格；每格都有独立的 `镜头：`、`画面：`、`站位：` 三行和来源镜头/阶段。
- 所有尖括号都已填完；没有“同上”“按站位表”“延续上一格”“已体现在剧情”等摘要占位。
- 每格都有景别、角度、轴线机位/POV、画面投影、动作/情绪/视线、听者或旁观者反应、完整站位和状态承接。
- 第1格与起始快照一致，最后一格与目标末态一致；跨宫格起始快照与上一组末态一致，构图变化不改写世界位置。
- 没有对白原文、字幕、气泡、序号、Panel 标签、水印或其他可读文字；每个角色没有同格 duplicate/twin/clone。
- 任一项不满足时返回 `stage_blocked`，先补齐站位、分镜、refs 或骨架变量，不能缩成摘要再派发。
