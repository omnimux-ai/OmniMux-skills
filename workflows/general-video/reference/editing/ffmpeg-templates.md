# 确定性后期操作选择（Deterministic Post Operations）

## Activate When

- Post 需要合并、裁切、变速、转码、画幅处理、文字叠加、音频替换或混音。
- 需要判断应使用专用后期能力，还是使用更通用的媒体处理入口。

## Decision Test

先把创作决定写清，再选工具。若一句话仍无法说明输入、顺序、目标和保留内容，暂时不要执行。

## Selection Order

1. 当前工具已有覆盖该操作的专用能力时，优先使用专用能力。
2. 只有专用能力无法表达所需滤镜、映射或组合时，才使用通用媒体处理入口。
3. 参数名、支持格式、输出字段和限制一律以当前工具 schema 为准，不从旧示例抄写。

## Operation Card

执行前明确：

- **Inputs**：来自当前 runtime refs 的绝对路径，以及它们的真实时长、画幅、帧率、声轨状态。
- **Order**：素材的确定顺序；不得依赖文件系统排序或展示名称猜测。
- **Transform**：只列必要操作，并说明每项保护什么内容。
- **Audio policy**：保留、静音、替换或混合原声；未要求时不擅自移除生成片段音频。
- **Text policy**：只有用户明确要求时才加字幕、标题或水印。
- **Output**：可辨识的最终用途、容器要求和交付位置。

## Boundaries

- 不把未经核验的模板、参数串或固定编码预设当作事实。
- 不在同一次处理里顺便加入未批准的视觉效果、字幕或响度目标。
- 不覆盖源素材；每次输出都应可回溯到输入和操作意图。
- 简单拼接遵循共享视频合并规范；独立音频与混音遵循共享音频规范。

## Check

- 输出可打开，时长、画幅、声轨和素材顺序符合计划。
- 首尾、切点、文字和音频不存在截断、黑帧、爆音或意外静音。
- 重新执行同一工作项不会改变素材顺序或悄悄扩大修改范围。
