# 电商合规红线（AI 禁生成认证 / 检测 / 功能数字）

> **何时 read**：写涉及"认证 / 检测 / 功能宣称"的品类 brief 之前必读。
> **覆盖品类**：母婴、保健品、个护、美妆、运动户外、3C、食品 / 饮料 等。

## 红线条款

**禁止 AI 生成以下元素**：

- **认证标识**：FDA / CE / 有机 / 国标 / 3C / 食品级 / 婴儿安全 / UV 防晒 等任何 logo / 编号 / 证书图案
- **检测报告 / 批文 / 检验合格证**：任何形式的"第三方测试通过"图样
- **功能效果数字**：防水等级（IPX7 / IP68）、UV 指数、SPF 值、容量、能效等级、抗菌率（"99% 抑菌"）、保湿持续时间（"24h 保湿"）、临床见效时间（"30 天见效"）等任何带数字的功能宣称
- **绝对化宣称**：成分含量（如"含 1000mg DHA"）、临床数据、"见效"承诺等

## 处理流程

1. **必须**来自用户提供的真实素材：用户给真实证书 / 包装 / 检测报告，AI 仅做版式呈现 / 局部合成
2. 用户没给真实素材 → **留空**或**不画该图**，或改为**非声明式视觉证据**（如运动户外的"防水"用"水珠在面料上滚落"演示，而非"IPX7"标识）
3. 后期 post-process 把真 logo / 真文字合成上去

## 后果（违反 = 高代价）

- **退货**：shopper 收到货发现与图不符
- **平台投诉**：shopper / 竞品举报"虚假宣传"
- **监管处罚**：保健品 / 母婴 / 美妆品类的虚假宣称受 FDA / SFDA / 市监等监管
- **品牌信任崩塌**：一次假宣称足以毁掉品牌的长期信任

## 各品类典型违规场景

| 品类 | 典型违规 | 替代方案 |
|---|---|---|
| 母婴 | AI 编造"3C 安全认证 / 食品级 / 国标 GB 30604"标识 | 用户提供真实证书素材；或不画认证图，改为材质特写 |
| 保健品 | AI 生成"GMP / 蓝帽子 / FDA"logo + 编造"含 1000mg DHA"含量 | 用户提供真实包装高清图原样保留；或留空数字 |
| 美妆 | AI 编造"焕白 30%" / "紧致" / "见效 14 天"功效百分比 | 改为感性描述（"水润持久"）或真实临床数据 |
| 个护 | AI 编造"99% 抑菌" / "24h 保湿" 抗菌率 | 改为感性描述或真实第三方检测依据 |
| 运动户外 | AI 编造"IPX7 防水" / "UPF 50+" / "SPF 30" 等级数字 | 用真实检测吊牌；或改为视觉证据（水珠滚落 / 面料背光透气） |
| 3C | AI 编造"3C 认证 logo" / "能效一级"标识 | 用真实包装 / 吊牌素材 |
