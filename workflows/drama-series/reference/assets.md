# 短剧资产编写参考

> 当 `drama-series.md` 规划角色、场景或道具锚点，并需要确定每个锚点内容的设计深度时读取。

## 范围

为 asset-anchors 的 image work items 编写身份、时代、叙事事实和生成 prompt；具体布局、Lock Card、Blocking Sheet 和状态连续性按 `assets-blocking.md` 执行。

- 只有当锚点会跨镜头/状态复用时才创建。短剧的角色设定图有专用形式：每个角色一张 16:9 双区图，左侧 50% 为大幅正脸特写（锁身份），右侧 50% 为正面/侧面/背面全身三列；每个角色一张，每个明显外观/状态一张（见 `assets-blocking.md`），这样脸足够大，能在下游保持稳定。
- 最小锚点结构（Lock Card 字段、场景布局事实）、Blocking Sheet 和状态连续性规则在 `assets-blocking.md`。
- 本文补充 profile 维度、选角/服装设计、场景描述结构、道具分级和建卡启发式规则，这些内容会喂给上述锚点。

## 时代与身份一致性

编写任何角色、场景或道具锚点前，先锁定共享的一致性框架，让三类资产互相匹配：

- 时代锚点：故事所处年代（古代 / 现代 / 近未来 / 具体年代）。建筑、材质、服装和道具都必须落在这个年代中。要把时代转换成每个角色/场景/道具 prompt 中的**具体禁用元素列表**（古装剧禁手表、拉链、现代发型、眼镜、印刷 logo；现代剧禁错时代服饰），并作为 prompt 尾部的负面子句携带，而不只写一句“符合时代”。每张生成卡都要按它回查。
- 社会阶层 / 身份层级：明确每个角色的地位，让面料等级、道具工艺和地点富裕程度与其身份匹配。也要写出需要避免的阶层错配元素（贫苦角色不携带奢华丝绸或精细珠宝）。
- 人种 / 人类特征：遵循剧本语言和故事设定的默认值；只有用户或剧本明确要求时才改变。

将时代、阶层和人种锁项写入所有相关角色、场景和道具 prompts；发现冲突时先修正资产描述再 author work item。

## 角色 Profile 维度

为需要重要露脸、跨镜/跨场身份稳定或状态连续的角色填写以下紧凑字段。一次性次要角色即使有少量台词或动作，也可作为 text-only role，直接在分镜和 prompt 中写清身份、数量、服装、位置与动作，不生成角色卡。

| 板块 | 需要捕捉的内容 |
|---|---|
| 世界观 | 世界设定、时代/年代、地域、题材和故事背景 |
| 基础设定 | 年龄或年龄段、人种/族裔、性别、身份/职业/社会角色 |
| 姿态状态 | 站立/坐下/动作状态；除非剧本/状态要求动作，否则默认站立、双手自然下垂 |
| 面容妆造 | 气质、脸型、眉毛走势、眼型、鼻型、唇形、皮肤状态、妆造 |
| 专属记忆锚点 | 脸、发型、体态、服装、配饰或道具中最强的跨镜头识别锚点 |
| 发型头饰 | 发长/发色/发质/发型和头饰，匹配时代与阶层 |
| 上身/连衣服饰 | 上装或连体服饰：轮廓、面料、颜色、合身度、穿着习惯 |
| 下身服饰 | 分体下装：轮廓、面料、颜色、状态 |
| 足部鞋履 | 鞋履类型、材质、颜色、状态 |
| 穿戴配饰 | 穿戴/携带配饰及其叙事功能；没有则写无 |

每个人物必须编写一个专属记忆点。编写角色 work items 前，先按基础设定、面容妆造、发型头饰、上身服饰、下身服饰逐对比较角色。任意两名角色必须满足：基础设定有可见的年龄段、体型或身份差异；脸型/骨相不同，且眉眼鼻唇至少 2 项不同；发型轮廓或头饰不同；上、下装分别在轮廓、主色/材质上不同。Mode B（漫剧）还须使用夸张发型轮廓和符号化配饰拉开识别差异，且发色、瞳色、服装主色至少 2 项不同。撞项时先重写对应字段，再 author work item。不得改动剧本已锁定事实。

**群演/同类群体按连续性决定是否建卡**。需要跨镜保持同一群体身份、服装或状态时，生成**一张**代表性角色设定图；一次性仆从、轿夫、路人等可作为 text-only role，以群体身份 + 数量 + 年龄层 + 统一服饰 + 位置/动作直接写入 prompt。text-only role 不进入媒体 `refs`；即使旧计划已有 `char_*` 但没有实际文件，也降级为文字描述，不创建无路径资产或文字 `ref_capsule` 冒充参考。

## 外观与选角参考

在 profile 上逐面构建外观：骨相和面部轮廓、肤色和质感、发型，再到体型和姿态习惯。每个面向都先和用户确认，再进入下一面向，让身份有意识地沉淀，而不是一次性混在一起。

- 选角参考（对标选角）是设计输入，不是最终肖像。当某个角色适合借鉴真实演员时，收集几张符合年龄、气质和职业的参考，把它们的骨相和特征融合成一个新的虚拟身份，不要复制某一个真人。
- 写设定图前先解析人种/族裔：剧本明确写了就用剧本值；否则从用户输入、故事设定、姓名、时代和地域推断。最终只把具体解析值写进 `【基础设定】`，不要把推断规则写进 prompt。发型和肤色遵循解析后的人种/族裔以及时代/阶层框架。把发型作为独立决策（长度、颜色、质感、造型、配饰），因为它和脸一样承担识别重量。
- 一旦选定融合后的面部锚点，它就是角色在所有后续卡片和镜头中保持的脸部参考。
- **写实角色必须携带真实感句。** 真人实拍 / 写实角色设定图使用 `assets-blocking.md` 的 Character Sheet Prompt Template 中的真实感句作为唯一事实源。漫画 / anime / Q版 / 手办风格则删除写实句，改引用已锁定的漫画/动画风格。

## 服装与状态

服装编码身份和心理，编写时要像脸一样有意识：

- 整体风格和颜色：颜色映射内心状态（冷色 = 克制或压抑，暖色 = 开放，黑/灰 = 权力或阴郁，白 = 纯洁或伪纯洁）。根据角色感受选择色盘，不按装饰好看选择。
- 面料匹配地位：有权势者用高支面料，劳动者用粗糙工装面料；面料等级就是阶层信号。
- 穿着习惯和标志性配饰：角色如何穿衣（领口扣紧、袖子总卷起、领带松散）以及标志性配饰都带有叙事重量。标明配饰是纪念物、身份标记还是情感锚点。
- 服装跟随剧情状态：当故事改变角色状态（崩溃、伪装、受伤、疲惫）时，服装也要随之改变。记录哪个 beat 引入了每个服装状态，并把它作为状态变体，让后续镜头继承变化后的外观而不是重置；触发集合和向后携带规则在 `assets-blocking.md` 的 state variants 和 State Continuity 中。
- Alternate persona vs state variant：当角色的另一个形态以完全不同外观出现在屏幕上，尤其会与基础形态同框时（意识空间、闪回、梦境、投射、分裂自我），给它**独立**锚点图；这个形态要同时跨时代、服装和发型区别于基础形态。Alternate sheet 默认保持与基础形态**同一张脸**（同一个演员出演两个形态，这是让观众理解接管/闪回仍是同一人的短剧惯例）：它加入 base-first dependency chain，引用基础脸图，只改变时代造型、服装和发型。只有当剧本明确写成“另一个人的外貌”时，才重新选一张新脸。当角色只是表情、姿态、气场或伤势变化，而外在造型仍相同（接管仍穿原服装、真人镜头中同一张脸回归）时，保留为 state variant，不要拆成新脸。

## 参考图与剧本的仲裁

任何外部参考（搜索或用户提供的人脸、服装、场景、道具图片）都可能把设计拉离剧本。提交参考图派生描述前，要把它和 profile 以及时代/阶层框架对比，检查年代、阶层、职业、气质或场景需求上的冲突。

### Questions

外部参考与剧本存在实质冲突时，调用一次 `question`；每项必须使用独立 question 对象，推荐项放第一位，不允许将多项问询混在一起。

| 问询项 | 选项 | 结果写入 |
|---|---|---|
| 参考与剧本冲突 | 跟随剧本（推荐）/ 跟随参考 / 融合 | 制作计划.物料质检与对应锚点约束 |

备注：问询中展示具体冲突；没有冲突时不问，参考图直接进入锚点描述。

## 场景描述维度

每个值得建卡的场景锚点按四个板块编写；这些板块进入场景图片 prompt，而布局事实（入口、区域、光线）由 `assets-blocking.md` 负责。

| 板块 | 需要捕捉的内容 |
|---|---|
| Subject（主体） | 场景本质加上时代/地域专属建筑、材料、家具、照明、标识、空间地标和穿帮禁用元素 |
| Environment modifier（环境修饰） | 时段（决定光线方向和色温）、天气/氛围、季节线索 |
| Art and style（艺术控制） | 媒介，以及与该地点和时段相关的 palette/lighting 切片，让场景匹配已确认风格，同时不导入其他场景的光照 |
| Composition（画面与技术参数） | 2×2 四视图网格布局（同一空间正面 / 背面 / 左侧 / 右侧，按 `assets-blocking.md`）；只描述环境物件与相对布局；空场景 |

## 建卡启发式规则

场景或道具锚点用于阻止地点/物件在大量镜头和角度切换中断裂。真实复用时才创建；一次性和可抛弃元素保留为 beat prompt 文本。

- 当一个场景中有三个或更多镜头、某地点跨两个或更多场景，或该地点作为主要舞台占据本集较大篇幅时，创建场景卡。
- 当某道具跨两个或更多场景并有特写、在一个场景中被拍三个或更多角度，或是角色反复操作的关键叙事信物时，创建道具卡。
- 保留为文本：只在一个短镜头出现、没有角度切换的地点或道具；闪回/蒙太奇中一带而过的元素；没有独特外观也没有关键互动的普通日用品。已经出现在场景卡里的固定大物件不需要单独道具卡。
- 边界情况要放到画布上向用户提问，而不是静默猜测。

## 资产 Prompt 的风格相关性

资产 prompts 只按相关性继承项目风格，不要把完整视觉风格锚点粘进每个 item。

- Mode A 资产 prompt 按资产类型强制组装：角色卡继承通用环境层和人物外观层；场景锚点只继承通用环境层，并明确写“空场景”；道具卡只继承通用环境层。
- 场景锚点将来源中的人物语义改写为非人类环境事实：人数或容量改为家具数量、相对布局与空地；角色归属或身份改为中性场景类型；走位、动作和视线不写入场景 prompt，留给后续站位记忆、宫格和视频镜头。
- 角色卡和道具卡保留已确认媒介、时代/阶层框架、材质/面料线索、相关色彩词和具体禁用元素。它们的 sheet/card 背景和光照来自卡片规范：中性 `#7c7c7c` 背景和柔和棚拍光，除非该 item 明确是场景状态参考。道具 prompt 只描写物件本体并独立陈列；持有者身份只用于材质和工艺判断，不写人物、手部或手持动作。
- Alternate-persona 卡只继承该 persona 可见世界的风格切片。意识空间现代形态可以使用白色虚空/冷光例外；古装状态不能继承现代或意识空间光照。
- 场景锚点、keyframe grids 和视频 prompts 使用当前地点/时间/空间的光照切片。灵堂 prompt 使用灵堂烛光/夜间光照；意识空间 prompt 使用意识空间光照；两者互不导入对方光线。
- 当媒介措辞出现在 prompts 中时，保持完全一致；但要删掉不会影响当前产物的 palette/lighting prose。

## 道具建卡判断

道具锚点只用于会跨多个镜头或角度切换、或会被角色反复操作的关键物件。只一闪而过的道具保留为 clip prompt 文本，不需要建卡。

满足任一条件时，创建道具主卡：

- 道具出现在两个或更多场景中，且至少有一次特写。
- 道具只停留在一个场景，但有三个或更多角度镜头。
- 道具是角色反复互动的关键叙事信物。

以下情况不要建卡：短暂出现一次、闪回/蒙太奇一带而过、已包含在场景锚点里的固定大物件、没有独特外观也没有关键互动的普通日用品。

闪回道具默认不建卡，除非它同时也是现在时间线中的主线信物，或有独立持续特写（≥5 秒）锚定关键戏剧转折。

道具材质和工艺必须匹配故事时代与持有者身份；道具主卡形式、Prop Lock 和派生引用规则见 `assets-blocking.md`。
