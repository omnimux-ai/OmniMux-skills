# 示例输入：分镜型

## 适合什么情况

- 用户已经写好分镜块
- 每个镜头都带有景别、动作或视觉重点

## 示例

项目：无线耳机开盒展示

分镜：

镜头 1
- 景别：近景
- 画面：耳机盒放在极简桌面中央
- 动作：镜头缓慢推近

镜头 2
- 景别：特写
- 画面：手打开耳机盒
- 动作：耳机 reveal

镜头 3
- 景别：中近景
- 画面：取出耳机并戴入耳中
- 动作：手部动作自然清楚

镜头 4
- 景别：定格近景
- 画面：耳机与充电盒整齐收尾

补充要求：

- 目标模型：`generic`
- 风格：极简、现代、冷静
- 避免：产品外观变形、边缘模糊、背景杂乱
