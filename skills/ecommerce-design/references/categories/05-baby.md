## 二、整体风格与质感

| 维度 | 要求 |
|------|------|
| **风格方向** | 柔和温馨、安全可信。色调清新不刺激，传递"安全放心"的信任感 |
| **色调** | 暖白色调为主，色温 5000-5500K；柔和粉彩色系（淡粉/浅蓝/鹅黄） |
| **背景** | 白底/浅色系背景；场景图用婴儿房/客厅等柔和家居环境 |
| **光线** | 柔光为主，**绝对避免硬阴影**；光比 ≤ 1:1.5 |
| **安全传达** | 每张图都要传递"安全"信号 —— 圆角、柔软、无锐边 |
| **模特** | 真实宝宝（非过度 PS 的完美婴儿）；亲子互动更有感染力 |

## 六、易错点（Watch For）

- **婴儿脸部自然度** —— 任何 uncanny-valley 脸都会摧毁整个 listing 的信任。**不确定时不要从零生成婴儿脸**，合成真实参考照。
- 婴儿手部 / 手指数 / 关节
- 整组使用柔和暖调，**禁止诊所感冷白**
- **【合规红线】认证标识 / 检测报告 / 安全编号 AI 不生成** —— 母婴是合规高危品类，伪造 3C / CCC / FDA / 国标 / 婴儿安全等任何认证 logo / 编号 / 证书 = 退货 + 平台投诉 + 监管风险。**资质图必须用用户提供的真实证书素材**，AI 仅做版式呈现 / 局部排版；用户没给真实素材就**留空 / 不画该图 / 改用文字说明**，不要"看起来像样"地编造。功能宣称数字（如"减震率 50%"、"含 X mg DHA"）同理——必须有真实检测依据。
