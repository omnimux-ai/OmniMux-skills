# 转场判断（Transition Decision Tree）

## Activate When

- 相邻镜头之间需要决定硬切、叠化、淡入淡出、黑场、匹配剪辑或声音桥。
- 当前转场显得突兀，但原因尚未明确。

## Decision Test

默认使用 **cut**。只有当转场本身表达了时间、空间、情绪或意义，才增加可见效果。

按顺序判断：

1. **动作、目光、声音或构图可以自然接续吗？** 使用 cut 或 match cut。
2. **时间在流逝、记忆在渗入，或两个状态需要柔和重叠吗？** 考虑 dissolve。
3. **章节、时空或情绪发生明确断裂吗？** 考虑 fade 或短黑场。
4. **画面应突然中断以制造冲击、喜剧或不安吗？** 使用直接 cut、jump cut 或有意的不连续。
5. **视觉变化很大但听觉世界应连续吗？** 使用 J-cut、L-cut 或环境声桥，而不是堆视觉特效。

## Apply

- 先确定转场前后的叙事关系，再选择视觉和声音手段。
- 优先利用形状、运动方向、色彩、主体位置或语义完成匹配。
- 转场长度由动作速度、音乐乐句、语言边界和情绪决定，不套固定时长。
- 同一段落保持一套可识别的转场语法；需要打破时，让变化对应结构变化。
- 若突兀来自缺镜头、错误顺序或连续性漂移，修复源问题，不用特效遮盖。

## Boundaries

- 不为展示技巧而轮换多种转场。
- 不用叠化掩盖每一次身份、场景或动作不连续。
- 不把黑场当作补时长工具。
- 不要求所有转场跟随音乐节拍；语义和动作可以优先。

## Check

- 能说清“为什么是这个转场，而不是 cut”。
- 转场没有吞掉对白、动作落点、关键文字或主体识别。
- 连续观看时，观众首先感到的是关系变化，而不是效果本身。
