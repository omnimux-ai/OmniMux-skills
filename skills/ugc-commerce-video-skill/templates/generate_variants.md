# Generate Variants Template

## Use Case
Use this template when the user wants to:
- create multiple short-form video concepts for testing
- generate several hooks, angles, proof sequences, or CTA directions
- build A/B/C creative plans for ecommerce video
- compare different selling approaches for the same product
- test which message or structure performs best before production
- create a controlled creative exploration set instead of one single concept

This template is designed for structured variation planning, not random idea dumping.

## Template Rules
1. Do not generate random variants with no testing logic.
2. Keep a clear shared core so comparisons remain useful.
3. Make each variant meaningfully different.
4. Change only the dimensions that matter for the stated goal.
5. Define a hypothesis for every major variation.
6. Avoid mixing too many variables at once unless the user wants broad exploration.
7. Keep product truth, proof requirements, and CTA goals aligned across the set where appropriate.
8. Recommend a test order when useful.
9. Explain what outcomes would actually mean, not just what the variants are.
10. The variant set should help the user learn something actionable, not just create more options.
