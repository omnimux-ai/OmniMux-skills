# 模型适配说明

同一份脚本或分镜，换不同模型时，真正变化的不是创意方向，而是信息组织方式。

## Generic

适合：

- 用户没有明确模型
- 结果要方便后续迁移
- 当前重点是把内容整理清楚

写法重点：

- 主体明确
- 动作顺序明确
- 少用专属术语
- 保证跨模型可读性

## Sora

适合：

- 强调连续动作
- 强调环境和主体关系
- 需要更完整的场景连贯感

写法重点：

- 让动作像连续发生的事件链
- 说明空间和光线如何保持稳定
- 少写彼此割裂的镜头碎片

## Veo

适合：

- 商业短片
- 产品展示
- 美妆、时尚、科技、食品类质感内容

写法重点：

- 强化镜头可读性
- 明确质感、光线、构图和重点特写
- 保护产品外观和主体一致性

## Seedance

适合：

- 节奏更快的短视频
- 钩子明确的卖点内容
- 需要首屏就看懂重点的画面

写法重点：

- 开头尽快出现可见利益点
- 镜头描述短而具体
- 让每个镜头都有明确目的

## 共同原则

- 模型适配只影响写法，不影响业务边界。
- 不能因为模型不同，就擅自改掉用户核心创意。
- 没有真实生成证据时，不要把模型偏好写成结果保证。
