# Character Guard — 人物参考图守卫

## Activate When

- 需要生成 reusable character / presenter anchor、选角参考或角色设定图。
- 参考图要跨多个 video work item 复用，且身份漂移会改变交付。

一次性人物、用户已提供合格身份 ref，或当前 Stage 只消费现有 ref 时跳过。

## Decision Test

先确认人物身份是否已经足够明确。性别、年龄、身份或身体特征只有在会改变资产内容或下游表演时才询问；不因为守卫本身强行增加一轮确认。每条规则只约束会影响识别和复用的可见事实。

## Guard Rules

1. **可识别的完整身份**：用于 reusable anchor 时，六视图全身格必须保留头顶、双手、双脚、鞋和四周留白；脸部近景必须能读出骨相、五官关系、发型和肤色。不要用半身照代替需要全身连续性的 anchor。
2. **中性资产背景**：角色锚点使用统一的中性灰摄影棚背景和柔和均匀光线；车辆、建筑、家具、地面、剧情场景和一次性氛围留在 supporting ref 或 shot prompt，除非用户明确要求关系图。
3. **不冻结表演**：基础角色卡使用中性表情和自然站姿；哭泣、愤怒、喊叫、临时伤痕、汗水、镜头光效和一次性动作不写进基础身份卡。
4. **控制随机配饰**：只保留用户、source 或真实 ref 证明的饰品与装备；对不应出现的帽子、围巾、项链、手表、腰包等，用明确的正向状态表达，不堆固定 negative boilerplate。
5. **皮肤与表演自然**：生成真人写实 anchor 时必须读取 `photoreal-skin.md`，保留自然肤色、景别匹配的局部纹理、有限高光和轻微不对称；六宫格各格使用一致的中性光线、曝光与肤色基线，避免塑料感、过度磨皮、全脸油亮或刻意添加密集瑕疵。
6. **逐人隔离**：多人物分别记录 identity、状态和 ref 顺序；每个 work item 只传本镜头实际出现的人物，不能让一人的脸、服装或标记扩散给另一人。

## Prompt and Review

生成 prompt 至少写清身份 ref 的贡献、视图用途、持续服装 / 装备、背景约束和允许变化；静态外观由 ref 承载时不要在 prompt 里重复一篇未经依据的角色档案，但要保留会影响一致性的可见身份字段。

检查：身份可辨识、全身关键部位未被裁切、背景没有场景污染、无未经要求的道具或配饰、人物之间没有混脸或混服装、皮肤和光线没有明显塑料感。失败时只修受影响的 anchor 或 work item。

## Boundaries

本卡只约束同一 Assets work item 的人物主输出，不创建新的人物 work item 或单独图片；不替代共享 Asset Pipeline 或 character-consistency；不规定固定画幅、视图数量、模型、重试次数或用户审批 Gate。
